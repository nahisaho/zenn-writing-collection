# Copilot Chatへのアクセスと基本操作

## この章の目的

Copilot Chatへの安全なアクセス方法と基本的な操作方法を習得し、大学職員として適切に活用するための第一歩を踏み出します。本章では、技術的な詳細よりも実践的な使い方に焦点を当て、明日からすぐに業務で活用できる基礎スキルの習得を目指します。

:::message
重要: 本章の内容は2025年1月時点の情報に基づいています。Microsoft 365 Copilot Chatは継続的に更新されているため、画面構成や機能の詳細は変更される可能性があります。最新情報は組織のIT部門にご確認ください。
:::

## 3.1 アクセスと基本操作

### 3.1.1 Copilot Chatへのアクセス方法

大学職員がCopilot Chatを利用する際は、必ず組織アカウントでアクセスすることが重要です。個人アカウントでのアクセスは、エンタープライズデータ保護（EDP）が適用されず、セキュリティリスクが生じるため避けてください。

#### Web版でのアクセス（推奨）

Web版は最も簡単で確実なアクセス方法です。特別なソフトウェアのインストールが不要で、どのパソコンからでも利用できます。

**アクセス手順**：
https://m365.cloud.microsoft.com/chat に直接アクセスし、組織アカウントでサインインしてください。このURLをブックマークに登録しておくと便利です。なお、https://office.com、https://portal.office.com、https://copilot.microsoft.com（旧URL）といったURLにアクセスした場合でも、すべて自動的にこのURLにリダイレクトされます。

**推奨ブラウザ**：
最も互換性が高いのはMicrosoft Edge（最新版）ですが、Google Chrome（最新版）、Firefox（最新版）、Mac利用者向けのSafari（最新版）でも快適にご利用いただけます。

:::message alert
Internet Explorer 11はサポート終了のため使用できません。必ず最新のブラウザをご利用ください。
:::

#### モバイルアプリでのアクセス

外出先や移動中でも利用できるモバイルアプリが提供されています。ただし、機密情報を扱う場合は、Intune で管理されていない端末の場合には、紛失・盗難リスクを考慮し、使用を控えることをお勧めします。

**インストール方法**：
iOSをご利用の場合はApp Store、Androidをご利用の場合はGoogle Playで「Microsoft 365 Copilot」を検索してください。なお、2025年1月に旧Microsoft 365アプリから名称変更されています。インストール後は必ず組織アカウントでサインインしてご利用ください。

#### Microsoft 365アプリ内でのアクセス（2025年5月以降）

2025年5月1日以降、段階的なロールアウトにより、Microsoft 365 Copilot Chat がMicrosoft 365 Copilotアプリ、Teams、Outlookのナビゲーションバーに既定でピン留めされます。2025年7月以降は、Word、Excel、PowerPoint、OneDrive等の他のMicrosoft 365アプリにも展開される予定です。これにより、作業中のアプリを離れることなくAI支援を受けられます。

### 3.1.2 画面構成と主要機能

Copilot Chatの画面は、シンプルで直感的に設計されています。初めて使用する方でも迷わず操作できる構成になっています。

#### 基本画面の構成要素

**1. チャット入力エリア（画面下部）**
ここに質問や依頼を入力します。文字数制限はライセンスや時期により変動する可能性があり、改行も使用できるため、複雑な指示も分かりやすく記述できます。制限に達した場合は、複数回に分けて送信してください。

**2. 会話表示エリア（画面中央）**
あなたの質問とCopilotの回答が時系列で表示されます。過去の会話を参照しながら、文脈を保った対話が可能です。

**3. セキュリティインジケーター（画面上部）**
緑色のシールドアイコンが表示されていれば、エンタープライズデータ保護（EDP）が有効です。このアイコンが表示されていることを必ず確認してください。

**4. 新しいチャットボタン**
新しい会話を開始する際に使用します。前の会話の文脈をリセットし、新たなトピックについて質問できます。

**5. 機能メニュー**
画面上部には各種機能メニューが配置されています。ファイルアップロード機能では、PDF、Word、Excel、PowerPointなどのファイルを分析できます。画像生成機能により、テキストから画像を生成することも可能ですが、著作権には十分注意してください。また、ContextIQという機能では「/」を入力すると、関連するファイルや人物を提案してくれます。

#### 重要な表示確認

業務で使用する前に、必ず確認すべき表示があります。まず、緑色のシールドアイコンが表示されていることを確認してください。これはEDP（エンタープライズデータ保護）が有効であることを示しています。次に、組織名の表示を確認し、サインインしているアカウントの組織名が正しいかを確認してください。最後に、「保護されています」という文字が表示されていることで、データ保護が適用されていることを確認できます。

### 3.1.3 基本的な会話の流れ

効果的にCopilot Chatを活用するためには、適切な会話の進め方を理解することが重要です。AIとの対話は人間同士の会話とは異なる特性があり、それを理解した上で活用することで、より良い結果を得られます。

#### 効果的な会話開始の方法

**1. 明確な目的設定から始める**
最初に何を達成したいかを明確に伝えることで、的確な回答を得やすくなります。

**良い例：**
```
## あなたの役割
○○大学教務課の職員として、新入生の履修登録を支援する立場

## 作成内容
履修登録説明会の案内メール

## 対象・目的
- 対象：2025年度新入生
- 目的：4月履修登録説明会への参加促進

## 含める要素
- 日時：4月8日（火）13:00-15:00
- 場所：大講堂
- 持ち物：学生証、筆記用具
- 事前準備：シラバス確認

## スタイル
- トーン：親しみやすく、不安を和らげる
- 長さ：300-400文字
- 形式：メール（件名含む）
```

**避けるべき例：**
```
メール作って
```

**2. 段階的な情報提供**
一度にすべての情報を詰め込むのではなく、段階的に情報を追加していくことで、より精度の高い結果を得られます。

- 初回の質問：基本的な要件を伝える
- 追加の指示：詳細な要件や修正点を伝える
- 最終調整：細かい表現や形式の調整

**3. 文脈を活用した継続的な対話**
Copilot Chatは会話の文脈を記憶しているため、前の回答を踏まえた追加質問や修正依頼が可能です。

例：
- 「先ほどの文書の語尾を敬語に修正してください」
- 「3番目の段落をもう少し詳しく説明してください」
- 「箇条書きの部分を文章形式に変更してください」

#### 会話終了時の重要な確認事項

**1. 個人情報の確認**
生成された内容に、意図せず個人情報が含まれていないか必ず確認してください。特に例示で使用した情報が残っていないか注意が必要です。

**2. 事実確認の必要性**
生成された内容の事実関係、特に日付、数値、制度名などは必ず原資料と照合してください。

**3. 保存と記録**
有用な回答は、適切な方法で保存してください：
- テキストファイルとして保存
- 部署共有フォルダーへの保管（個人情報を除去後）
- 今後の参考のためのプロンプト記録

## 3.2 効果的なプロンプトの基礎

プロンプトとは、AIに対する指示や質問のことです。プロンプトの質が、得られる回答の質を大きく左右します。ここでは、大学職員の業務に適した効果的なプロンプトの作成方法を学びます。

### 3.2.1 良いプロンプトの6つの要素

効果的なプロンプトには共通する6つの要素があります。これらを意識することで、期待する回答を得やすくなります。

#### 1. 明確な目的・ゴールの設定

何を達成したいかを具体的に記述することが最も重要です。曖昧な指示では、期待とは異なる回答が返ってくる可能性が高くなります。

**良い例**：
```
## あなたの役割
○○大学学生課の職員として、学費支援制度を熟知し、保護者の不安に寄り添う立場

## 作成文書
後期授業料納入期限延長申請の手続き説明書

## 対象読者
学生の保護者

## 含める項目
- 申請条件：経済的困窮の証明が必要
- 必要書類：申請書、所得証明書、理由書
- 提出期限：2025年9月30日（月）17:00まで
- 提出先：学生課窓口（1号館2階）

## 仕様
- 分量：A4用紙1枚以内
- 形式：見出し付きの説明文
- トーン：丁寧で分かりやすい
```

**改善が必要な例**：
```
授業料の説明を作成してください。
```

#### 2. 適切なコンテキスト（背景）情報の提供

AIは与えられた情報の中で最適な回答を生成します。背景情報を提供することで、より適切で実用的な回答を得られます。

**コンテキストに含めるべき情報**：
- 文書の対象者（学生、保護者、教員、一般の方など）
- 使用場面（説明会、メール、掲示物など）
- 大学の特性（国立、私立、規模、学部構成など）
- 時期的な要因（入学時期、試験期間、長期休暇など）

#### 3. 具体的な指示と制約条件

実行してほしい作業を詳細に指定し、同時に避けてほしい内容も明示します。

**指示の例**：
```
## あなたの役割
○○大学学生支援課の職員として、新入生の不安を解消し、大学生活への期待を高める立場

## 作成文書
新入生オリエンテーション案内文

## 対象・条件
- 対象：2025年度入学予定者
- 文字数：400-500字

## 必須項目
- 日程：4月5日（土）9:00-16:00
- 場所：○○キャンパス学生会館
- 服装：私服（動きやすい服装）
- 昼食：学食利用可（現金・電子マネー対応）

## 制約事項
- 避ける：専門用語、堅い表現
- トーン：歓迎の気持ちが伝わる温かい表現
- 形式：案内文書（見出し付き）
```

#### 4. 期待する品質と形式の明示

どのような形式で、どの程度の品質を求めているかを明確にします。

**形式指定の例**：
- 箇条書き形式
- 段落形式の説明文
- Q&A形式
- 表形式
- メール形式（件名、本文、署名を含む）

#### 5. 検証可能な出力仕様

生成された内容が要件を満たしているか確認できるよう、具体的な基準を設定します。

**検証基準の例**：
- 「必ず連絡先電話番号を含めてください」
- 「締切日を太字で強調してください」
- 「全体を3つのセクションに分けてください」

#### 6. 出力サンプルの提示

期待する出力の具体例を示すことで、より意図に近い文書を作成できます。

**出力サンプル付きプロンプトの例**：
```
## 作成内容
学生向け奨学金申請締切リマインドメール

## 出力サンプル
件名：【重要・締切3日前】○○奨学金申請について

○○さん

お疲れさまです。学生支援課の△△です。

○○奨学金の申請締切が近づいていますので、お知らせします。

【重要】
・申請締切：○月○日（○）17:00まで
・提出方法：学生ポータルサイトからオンライン申請
・必要書類：所得証明書、成績証明書

まだ申請がお済みでない方は、お早めに手続きをお願いします。

## 作成要件
- 上記サンプルの形式・構成に従う
- 具体的日付は「○月○日（○）」で表記
- 緊急度を適切に表現
- 親しみやすいが丁寧な敬語
```

このように具体的な出力例を示すことで、文体・構成・情報の配置まで意図通りに生成できます。

### 3.2.2 大学業務に特化したプロンプト作成法

大学という教育機関特有の価値観や制約を踏まえたプロンプト作成が重要です。

#### 教育機関としての配慮を含める

大学は教育機関として、営利企業とは異なる価値観や使命を持っています。この点をプロンプトに反映させることで、より適切な回答を得られます。

**配慮すべき要素**：
- 教育的価値の重視
- 公平性・透明性の確保
- 多様性への配慮
- 学生の成長・発達支援の視点

**プロンプト例**：
```
## あなたの役割
○○大学学生支援課のカウンセラーとして、学生の経済的困窮と学業継続の両立を支援する専門職

## 作成内容
学業と経済的事情に悩む学生への返信メール

## 基本方針
教育機関として学生の学びを最優先に支援する姿勢を表現

## 含める支援制度
- 奨学金：日本学生支援機構、大学独自奨学金
- 分納制度：授業料の分割納付
- 学内アルバイト：図書館、事務補助等

## 表現要件
- トーン：学生の不安に寄り添う温かい表現
- 必須項目：学生相談室連絡先を明記
- 形式：メール（件名・本文・署名）
```

#### リスク回避のための制約設定

個人情報保護や法的リスクを避けるため、明確な制約を設定します。

**必須の制約事項**：
```
## 禁止事項
- 個人名、学籍番号の記載
- 具体的な成績情報の記載
- 「必ず」「絶対」等の断定的表現

## 避けるべき内容
- 法的助言と受け取られる表現
- 医学的助言と受け取られる表現

## 必須項目
- 最終判断は担当部署確認を促す文言
- 問い合わせ先の明記
```

### 3.2.3 プロンプトの改善と調整

初回のプロンプトで完璧な回答を得られることは稀です。段階的に改善・調整することで、より良い結果を得られます。

#### 段階的な改善アプローチ

**Step 1: 基本プロンプトで大枠を確認**
まず簡潔なプロンプトで基本的な回答を得て、方向性を確認します。

**Step 2: 詳細な要件を追加**
基本的な回答を見て、不足している要素や修正が必要な部分を特定し、追加指示を出します。

**Step 3: 細部の調整**
表現のトーン、専門用語の使用、文章の長さなど、細かい調整を行います。

**実例**：
```
初回：「留学プログラムの説明文を作成してください」
↓
追加：「対象を2年生に限定し、応募締切と選考基準を追加してください」
↓
調整：「もう少しカジュアルな表現にして、メリットを具体的に3つ挙げてください」
```

## 3.3 初歩的な活用例

実際の業務でよく使用される基本的な活用例を、具体的なプロンプトとともに紹介します。これらの例を参考に、自分の業務に応じたプロンプトを作成してみましょう。

### 3.3.1 簡単な文書要約

長い文書を短くまとめる作業は、Copilot Chatが得意とする分野の一つです。ただし、機密文書や個人情報を含む文書は使用しないよう注意してください。

#### 会議資料の要約

**プロンプト例**：
```
## あなたの役割
○○大学教務課の職員として、委員会の決定事項を正確に記録し、関係部署に伝達する責任者

## 作成内容
教務委員会議事メモの要約

## 形式・制約
- 形式：箇条書き（5項目以内）
- 分類：決定事項と継続審議事項を明確に区分
- 各項目：簡潔で要点を含む

## 添付資料
[ここに議事メモの内容を貼り付け]

## 注意事項
- 個人名は役職名に置換
- 具体的な金額等の機密情報は「○○万円」等に置換
```

**活用のポイント**：
- 要約の長さを明確に指定する（項目数、文字数など）
- 重要な観点を指定する（決定事項、アクション項目など）
- 個人名が含まれる場合は事前に削除または仮名に置換

### 3.3.2 メール文面の改善

日々のメール作成を効率化し、より適切な表現に改善できます。

#### 学生への連絡メール改善

**プロンプト例**：
```
## あなたの役割
○○大学教務課の職員として、新入生の大学生活を丁寧にサポートし、分かりやすく親切な対応を心がける立場

## 修正内容
大学1年生向けメール文面の改善

## 対象読者
大学1年生（初学者）

## 修正方針
- 専門用語を避ける（必要時は簡単な説明追加）
- 親しみやすいトーン
- 重要情報の明確化

## 修正対象文面
件名：履修登録について
本文：履修登録システムにおける科目登録の期限が迫っております。
速やかに所定の手続きを完了させてください。

## 期待する改善点
- 「履修登録」の簡単な説明
- 具体的な期限日時
- 操作方法のサポート案内
```

**改善後の例**：
```
件名：【重要】履修登録の締切が近づいています（○月○日まで）

○○さん

こんにちは。教務課の○○です。

履修登録（受講する授業を決めて登録すること）の締切日が近づいていますので、
お知らせします。

締切：○月○日（○）17:00まで
方法：学生ポータルサイトから登録

まだ登録が済んでいない方は、早めに手続きをお願いします。
操作方法が分からない場合は、教務課窓口（○号館1階）でサポートしますので、
遠慮なくお越しください。

ご不明な点があれば、お気軽にお問い合わせください。
```

### 3.3.3 よくある質問（FAQ）の作成

学生や保護者からの問い合わせ対応を効率化するFAQを作成できます。

**プロンプト例**：
```
## あなたの役割
○○大学学生課の窓口職員として、学費に関する質問に正確で親切な対応を行う専門スタッフ

## 作成内容
大学学費納入FAQ（5項目）

## 形式
- Q: 質問（学生・保護者目線）
- A: 回答（大学職員として丁寧に）

## 含めるトピック
1. 納入期限
2. 分納制度
3. 延納申請  
4. 振込方法
5. 領収書発行

## 回答要件
- 具体的で分かりやすい説明
- 必要時は問い合わせ先を明記
- トーン：丁寧で親しみやすい
- 各回答：100-150文字程度
```

### 3.3.4 出力サンプル付きプロンプトの実践例

出力サンプルを提示することで、より意図に近い文書を作成できる実践例を紹介します。

**プロンプト例**：
```
## あなたの役割
○○大学学務課の職員として、入学式を格調高く運営し、新入生とその家族を温かく迎える責任者

## 作成内容
入学式案内状（保護者向け）
```

## 3.4 基本操作における注意事項

### 3.4.1 してはいけないこと

Copilot Chatを安全に利用するため、以下の行為は絶対に避けてください。

#### 絶対に入力してはいけない情報

1. **個人を特定できる情報**
   - 学生の氏名、学籍番号
   - 教職員の個人情報
   - 保護者の連絡先

2. **機密情報**
   - 未公開の入試情報
   - 人事評価、給与情報
   - 理事会、教授会の非公開審議内容

3. **第三者の創作物**
   - 他大学の資料をそのままコピー
   - 書籍や論文の長文引用
   - 著作権で保護された画像やデータ

### 3.4.2 常に意識すべきセキュリティ

#### 利用前の確認事項

Copilot Chatを利用する前に確認すべき重要な点があります。まず、緑色のシールドアイコンが表示されているかを確認し、組織アカウントでサインインしているかを確かめてください。また、公共の場所では画面を他人に見られないよう注意することも重要です。

#### 利用後の確認事項

Copilot Chatを利用した後にも重要な確認作業があります。生成された内容に個人情報が含まれていないか、機密情報が意図せず含まれていないかを必ずチェックしてください。さらに、生成された内容を保存する場合は適切な場所に保管されているかも確認が必要です。

### 3.4.3 効果的な活用のためのヒント

#### 時間帯による使い分け

Copilot Chatの効果的な活用には時間帯による使い分けが有効です。朝の時間帯には1日の業務計画やToDoリストの作成に活用し、日中は即座の文書作成や情報整理に役立てることができます。夕方には1日の振り返りや翌日の準備を行う際の支援ツールとして活用するのが効果的です。

#### プロンプトのテンプレート化

よく使用するプロンプトはテンプレートとして保存しておくと便利です。具体的には、メール返信用テンプレート、議事録作成用テンプレート、FAQ作成用テンプレートなどを事前に用意しておくことで、効率的な作業が可能になります。

## 3.5 この章のまとめ

### 重要ポイント

この章で学習した重要なポイントを振り返ります。第2章で学んだ認知負債の予防策を前提として、第3章では実際の操作方法を習得しました。アクセス方法については必ず組織アカウントでサインインし、EDPが有効であることを確認することが基本です。基本操作では画面構成を理解し、セキュリティ表示を常に確認する習慣をつけることが大切です。プロンプト作成においては6つの要素を含む明確な指示を心がけ、一度で完璧を求めず段階的に調整していくことが効果的です。そして何より重要なセキュリティ面では個人情報や機密情報は絶対に入力してはいけません。これらの基本操作を習得することで、安全で効果的なAI活用の基盤が構築されます。
