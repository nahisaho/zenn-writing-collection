# 付録A: Microsoft Learn学習パス・モジュール一覧

本書で学習したCopilot Chatの基礎知識をさらに深めるために、Microsoft Learnで提供されている公式の学習パスとモジュールを活用することをお勧めします。以下に、2025年時点で利用可能な主要な学習リソースを整理しました。

:::message
**更新情報について**  
Microsoft Learnのコンテンツは随時更新されています。最新の情報と利用可能なモジュールについては、必ず公式のMicrosoft Learn（https://learn.microsoft.com/ja-jp/copilot/）で確認してください。
:::

## A.1 主要学習パス（Learning Paths）

### A.1.1 Explore Microsoft 365 Copilot Chat
**📚 学習パス名**: Explore Microsoft 365 Copilot Chat  
**🔗 URL**: https://learn.microsoft.com/en-us/training/paths/explore-microsoft-365-copilot-business-chat/

**📝 概要**：  
Microsoft 365 Copilot Chatの使い始め方から効果的なプロンプト作成、AI機能を活用した生産性向上まで、安全なリアルタイム協働環境での実践的活用方法を学習します。

**⏰ 学習レベル**: 初級（Beginner）  
**👥 対象ロール**: ビジネスユーザー  
**🛠 対象製品**: Microsoft 365 Copilot Chat  
**📋 前提知識**: Microsoft 365へのアクセスと基本的な利用経験

**📖 含まれるモジュール**：
1. Get started with Microsoft 365 Copilot Chat（Microsoft 365 Copilot Chatの開始）
2. Write effective prompts to achieve optimal results（最適な結果を得るための効果的なプロンプト作成）
3. Work smarter with Microsoft 365 Copilot Chat（Microsoft 365 Copilot Chatでより賢く作業）

**🎯 学習成果**：
- Microsoft 365 Copilot Chatの基本的な操作方法の習得
- 効果的なプロンプト設計技術の理解
- 安全なAI活用による生産性向上の実践

---

### A.1.2 Get started with Microsoft 365 Copilot
**📚 学習パス名**: Get started with Microsoft 365 Copilot  
**🔗 URL**: https://learn.microsoft.com/en-us/training/paths/get-started-with-microsoft-365-copilot/

**📝 概要**：  
Microsoft 365 Copilotの基礎から始まり、Microsoft 365アプリケーション全体での多様な活用方法と、その可能性を最大限に活かすためのアドバイスを3つの主要モジュールで体系的に学習します。

**⏰ 学習レベル**: 初級（Beginner）  
**👥 対象者**: すべてのプロフェッショナル（AIの専門知識は不要）  
**📋 前提知識**: Microsoft 365の基本的な利用経験

**📖 含まれるモジュール**：
1. Introduction to Microsoft 365 Copilot（Microsoft 365 Copilotの紹介）
2. Explore the Possibilities with Microsoft 365 Copilot（Microsoft 365 Copilotの可能性を探る）
3. Comprehensive best practices for Microsoft 365 Copilot and key extension methods（包括的なベストプラクティスと重要な拡張方法）

**🎯 学習成果**：
- Microsoft 365 Copilotの目的と機能の理解
- 責任あるAI実践に対するMicrosoftの取り組みの理解
- Microsoft 365アプリ全体でのCopilot活用方法の習得

## A.5 学習の進め方とレベル別推奨パス

### A.5.1 初心者向け推奨学習順序
大学職員でAI初心者の方には、以下の順序での学習をお勧めします：

1. **Introduction to Microsoft 365 Copilot**  
   → Copilotの基本概念と責任あるAI実践の理解

2. **Get started with Microsoft 365 Copilot Chat**  
   → 実際の操作方法とインターフェースの習得

3. **Enhance Teaching and Learning with Microsoft 365 Copilot Chat**  
   → 教育機関特有の活用方法の学習（該当者のみ）

4. **Work Smarter with Microsoft 365 Copilot Chat**  
   → より高度な活用技術の習得

### A.5.2 中級者向け発展学習
本書の内容を習得した後の発展学習として：

1. **Explore the Possibilities with Microsoft 365 Copilot**  
   → Office統合機能の理解

2. **Empower your Workforce with Microsoft 365 Copilot: Executives Use Case**  
   → 組織展開と管理視点の学習（管理職の方）

3. **完全なExplore Microsoft 365 Copilot Chat学習パス**  
   → 包括的なスキル習得

### A.5.3 管理職・IT担当者向け
組織導入を検討されている方には：

1. **Overview of Microsoft 365 Copilot Chat**  
   → 全体像の把握

2. **Manage Microsoft 365 Copilot Chat**  
   → 管理・セキュリティ要件の理解

3. **Empower your Workforce with Microsoft 365 Copilot: Executives Use Case**  
   → 導入戦略と効果測定
