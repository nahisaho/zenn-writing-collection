本付録では、AI活用教育の質を継続的に向上させるための評価・改善ツールを提供します。これらのツールは、認知負債の防止と教育効果の最大化を目的として設計されており、日常的な自己点検から組織的な改善活動まで幅広く活用できます。

# 日常使用セルフチェックリスト

## AI活用前チェックリスト

### 目的・計画の明確化
**使用前必須確認項目**

□ **明確な教育目的**
- [ ] 具体的な学習目標が設定されている
- [ ] AI活用の必要性・理由が明確である
- [ ] 期待する教育効果が具体的に定義されている
- [ ] 成功の評価基準が設定されている

□ **適切性の確認**
- [ ] 対象学習者のレベル・特性に適している
- [ ] 教育内容・分野に適したAI活用である
- [ ] 利用可能な時間・リソースに見合っている
- [ ] 学習環境・条件に適している

□ **代替手段の検討**
- [ ] 従来手法との比較検討を行った
- [ ] AI以外の選択肢も検討した
- [ ] 最適な手法を選択した根拠がある
- [ ] 混合アプローチの可能性を検討した

□ **リスク評価**
- [ ] 認知負債のリスクを評価した
- [ ] プライバシー・セキュリティリスクを確認した
- [ ] 学術的誠実性への影響を検討した
- [ ] リスク軽減策を準備した

### 倫理・コンプライアンス確認
**責任ある活用のための確認**

□ **透明性の確保**
- [ ] AI使用の範囲・方法を明確にした
- [ ] 学習者にAI活用を適切に説明する
- [ ] 保護者・関係者への説明準備ができている
- [ ] 記録・文書化の準備ができている

□ **公平性・包摂性**
- [ ] すべての学習者への公平な配慮を確認した
- [ ] 多様性・個人差への配慮を計画した
- [ ] アクセシビリティを確保した
- [ ] 格差拡大の可能性を検討・対策した

□ **制度・規程遵守**
- [ ] 所属機関のポリシーに準拠している
- [ ] 法的要件・規制を確認した
- [ ] 知的財産権への配慮を行った
- [ ] データ保護規程を遵守している

□ **個別ニーズへの対応**

- [ ] 困難を抱える学習者への支援がある
