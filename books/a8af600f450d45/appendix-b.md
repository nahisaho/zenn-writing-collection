# 教育機関向けZero Trustセキュリティ設定チェックリスト

本チェックリストは、教育機関でのMicrosoft 365 Zero Trust実装において、NIST SP800-207準拠の設定が適切に行われているかを確認するためのツールです。段階的な実装アプローチに対応し、優先度別に整理されています。

## 使用方法

- ☑️ 実装済み・設定完了
- ⚠️ 部分実装・要改善  
- ❌ 未実装・要対応
- N/A 組織に該当せず

各項目の右側に確認日と担当者を記録してください。

## 注意事項・運用指針

1. **段階的実装**: すべての項目を一度に実装する必要はありません。Phase 1から順次進めてください
2. **組織適合性**: 教育機関の規模・特性に応じて、該当しない項目は N/A としてください
3. **定期見直し**: 最低でも年1回は全項目のレビューを実施してください
4. **文書化**: 設定変更・例外承認は必ず文書化し、変更履歴を残してください
5. **継続的学習**: Microsoft Learn・技術コミュニティで最新情報を継続的に収集してください

このチェックリストは、教育機関でのZero Trust実現における基本的な指針です。組織固有の要件については、専門家またはMicrosoft認定パートナーにご相談ください。
