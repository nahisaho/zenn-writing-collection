```
「高齢者が困っているらしい」
「バスが不便だと思う」
これでは、説得力がありません。

【データがある場合を指して】
データがあると、提案が具体的になります。
「高齢者の75%が週1回以上の通院に困難を感じている」
「路線バスの利用者数は3年で40%減少」
```

### スライド12: アンケート設計の基本
**ページタイトル**: 良いアンケートの条件

**ページの内容**:
- **良いアンケートの5つの条件**:
  1. **目的が明確**: 何を知りたいのか
  2. **質問が具体的**: 曖昧な質問は避ける
  3. **回答しやすい**: 選択式を基本に
  4. **バイアスがない**: 誘導的な質問は避ける
  5. **プライバシーに配慮**: 個人情報の扱い

**トークノート**:
```
アンケート設計の基本です。

良いアンケートには、5つの条件があります。

【各項目を読み上げながら】

1. 目的が明確。
   「何を知りたいのか」が明確でないと、良い質問は作れません。

2. 質問が具体的。
   「どう思いますか？」ではなく、「どの程度困っていますか？」

3. 回答しやすい。
   自由記述ばかりだと、回答者が疲れます。選択式を基本に。

4. バイアスがない。
   「バスは不便ですよね？」これは誘導です。

5. プライバシーに配慮。
   年齢や住所を直接聞くのは避ける工夫が必要です。

この5つ、覚えてください。
```

### スライド14: 悪いアンケートの例
**ページタイトル**: ❌こんなアンケートはダメ

**ページの内容**:
- **例: AI生成アンケート（問題あり）**:

```
1. あなたの年齢を教えてください
2. 普段どのような交通手段を使いますか？
3. 移動に困っていることはありますか？
4. どのような支援があれば便利だと思いますか？
5. 1ヶ月にどれくらい外出しますか？
```

- **問題点**:
  - ❌ 質問が抽象的すぎる（「困っている」とは？）
  - ❌ 選択肢がない（自由記述のみでは集計困難）
  - ❌ 政策立案に必要な情報が不足（具体的な距離、頻度、理由）
  - ❌ 年齢を直接聞く（プライバシー配慮不足）

**トークノート**:
```
悪いアンケートの例を見ます。

これは、実際にAIが生成したアンケートです。

【アンケートを読み上げながら】
一見、普通に見えますよね。

でも、問題があります。

【問題点を指して】
1. 質問が抽象的。「困っている」とは、具体的にどういうこと？
2. 選択肢がない。全部自由記述では、集計できません。
3. 政策立案に必要な情報が不足。「何km離れているか」「週何回か」がわかりません。
4. 年齢を直接聞いている。「60代」「70代」という選択肢の方が良い。

AIは、このような「一見普通だけど、実は問題がある」アンケートを作ります。

だから、批判的に検証する必要があるんです。

後ほど、この演習をします。
```

### スライド17: AIを使ったデータ分析の例
**ページタイトル**: Edge Copilotでのデータ分析

**ページの内容**:
- **例: アンケート結果の分析**:

  **プロンプト**:
  ```
  以下のアンケート結果（n=50）を分析してください：
  - 60代: 10名
  - 70代: 25名

  - 交通手段がない: 30名（60%）
  ```

## 総評・運用ノート

### スライドデザインの原則
1. **第1コマとの一貫性**: 信号の色、フォント、レイアウトを統一
2. **演習重視**: 批判的検証演習のスライドは見やすく
3. **グループワーク支援**: ステップごとのポイントを明示
4. **ビジュアル重視**: 問題のあるアンケート、良いアンケートの対比を明確に

### トークの原則
1. **第1コマとのつながり**: 復習を丁寧に
2. **演習の重要性を強調**: 批判的検証演習が今日の目玉
3. **具体例を多用**: 悪い例・良い例の対比
4. **グループワークの促進**: 巡回時の声かけを積極的に

### 批判的検証演習の運営
1. **時間管理**: 10分個人、5分グループ共有、厳守
2. **ヒントの出し方**: 5分後、8分後に段階的に
3. **答え合わせ**: 問題点を明確に、改善案も示す
4. **学生の気づきを尊重**: 正解以外の視点も評価

### グループワーク中の教員の役割
1. **巡回**: 全グループの様子を確認
2. **介入**: 困っているグループを助ける
3. **促進**: 議論が浅いグループに深掘りを促す
4. **記録確認**: Loopに記録が残っているか確認

### 成功の指標
- 学生が批判的検証演習で5つ中3つ以上の問題点を発見
- グループワークで全員が参加（一部の人だけが作業していない）
- 「批判的検証の重要性を理解した」と感じる学生が90%以上
