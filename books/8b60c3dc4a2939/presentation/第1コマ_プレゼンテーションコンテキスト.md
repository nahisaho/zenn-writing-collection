### スライド8: AI活用の4原則
**ページタイトル**: AI活用の4原則

**ページの内容**:
- **1. 透明性（Transparency）**
  - AI使用箇所を明示する義務
  - 「AI支援あり」と記載

- **2. 責任（Responsibility）**
  - 最終的な判断と責任は自分にある
  - AIのせいにしない

- **3. 倫理（Ethics）**
  - 剽窃・不正使用の禁止
  - 丸ごとコピペ禁止

- **4. プライバシー（Privacy）**
  - 個人情報をAIに入力しない
  - インタビュー内容の入力禁止

**トークノート**:
```
AI活用の4原則です。この4つは絶対に守ってください。

【1. 透明性】
AIを使ったら、必ず「AI支援あり」と明記してください。
隠すのはダメです。評価の対象は「適切に使えたか」であって、
「使ったかどうか」ではありません。

【2. 責任】
AIが間違った情報を出しても、それを使った責任は皆さんにあります。
「AIがそう言った」は通用しません。

【3. 倫理】
AI生成文章をそのまま提出するのは剽窃です。
必ず自分の言葉で書き直してください。

【4. プライバシー】
インタビューで聞いた個人情報をAIに入力してはいけません。
特に、地域課題解決では、地域の方の生の声を聞くことがあります。
その内容をそのままAIに入力するのはNGです。

この4原則、覚えてください。
```

### スライド17: なぜ「問題定義」はAI禁止なのか？
**ページタイトル**: 🔴赤信号の理由

**ページの内容**:
- **問題定義とは**:
  - 「何が本当の問題なのか」を見極めること
  - 表面的な現象と根本的な原因を区別すること

- **AIに任せると**:
  - 一般的な答えしか出てこない
  - 地域固有の文脈が反映されない
  - 「自分で考える」機会を失う

- **例**:
  - ❌「沖縄の高齢化問題の解決策を教えて」→ 一般論
  - ✅「なぜこの地域で高齢者が移動に困っているのか？」→ 自分で現場を見て考える

**トークノート**:
```
では、なぜ「問題定義」は赤信号なのか。

【問題定義とは、を指して】
問題定義とは、「何が本当の問題なのか」を見極めることです。

例えば、「高齢者が買い物に困っている」という現象があったとします。
でも、本当の問題は何でしょうか？
・店が遠いから？
・バスがないから？
・それとも、一人暮らしで誰も助けてくれないから？

これを見極めるのが問題定義です。

【AIに任せると、を指して】
これをAIに聞くと、一般的な答えしか返ってきません。
「交通手段の不足」「地理的要因」など。
でも、その地域固有の文脈は、AIにはわかりません。

だから、問題定義は、自分で現場を見て、考えないといけないんです。
```

### スライド18: なぜ「情報収集」は緑信号なのか？
**ページタイトル**: 🟢緑信号の理由

**ページの内容**:
- **情報収集とは**:
  - 既存の知識・データを集めること
  - 事実関係を確認すること

- **AIが得意なこと**:
  - 大量の情報から関連情報を抽出
  - 複数の視点を提示
  - 時間の大幅短縮

- **ただし**:
  - ⚠️ 必ず出典を確認
  - ⚠️ 複数の情報源でクロスチェック
  - ⚠️ 最新性を確認（いつのデータか）

**トークノート**:
```
逆に、なぜ「情報収集」は緑信号なのか。

【情報収集とは、を指して】
情報収集は、既に存在する知識やデータを集める作業です。

【AIが得意なこと、を指して】
これは、AIが得意な領域です。
大量の情報から関連情報を抽出して、
複数の視点を提示してくれます。
時間も大幅に短縮できます。

【ただし、を指して】
ただし！ 必ず出典を確認してください。
AIは時々間違えます。
```

## 総評・運用ノート

### スライドデザインの原則
1. **1スライド1メッセージ**: 情報を詰め込みすぎない
2. **ビジュアル重視**: 図、アイコン、色を効果的に使う
3. **信号の色**: 🟢🟡🔴は常に同じ色で統一
4. **フォントサイズ**: 後ろの席からも読める大きさ

### トークの原則
1. **学生に語りかける**: 一方的な講義ではなく、対話的に
2. **具体例を多用**: 抽象的な説明は避ける
3. **「なぜ」を説明**: ルールだけでなく、理由を伝える
4. **時間管理**: 各パートの時間を守る

### 実習中の教員の役割
1. **巡回**: 全学生の様子を確認
2. **問いかけ**: メタ認知を促す質問をする
3. **個別支援**: 困っている学生を助ける
4. **時間管理**: 適宜、全体に進捗を伝える

### 成功の指標
- 学生が「課題解決に近づいた」と感じる（平均4.0以上/5.0）
- 90%以上の学生が信号ルールを理解
- 実習で全学生が批判的検証を実践
