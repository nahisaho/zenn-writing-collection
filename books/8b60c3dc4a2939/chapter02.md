# 琉球大学での実践事例と気づき

**この章で学べること**:
- 90分×2コマの生成AI利活用授業の具体的な設計
- 2年間の実践で見えてきた成功と失敗（2023年度・2024年度）
- 学生の反応と成果物の変化
- 「知識重視」から「実践重視」への転換からの学び

**ペルソナ別の読みどころ**:
- **教員**: 2.1.2「90分×2コマの授業構成」→ そのまま使える授業設計
- **学生**: 2.3「学生の反応と成果」→ 他の学生の体験談
- **研究者**: 2.4「実践から得られた重要な気づき」→ 理論と実践の接続

## 2.1 授業の基本設計

### 2.1.1 授業全体の位置づけ

琉球大学で2019年度から開講している「総合特別講義Ⅴ：DX（デジタルトランスフォーメーション）による地域課題解決」は、初級地域公共政策士の資格科目として位置づけられています。筆者が生成AI利活用パートを担当し始めたのは2023年度からです。

**授業の基本情報**:
- **開講時期**: 後期（10月〜1月）
- **授業回数**: 全15回（90分×15回）
- **対象学生**: 学部2〜4年生（専攻不問）
- **履修者数**: 約40名（2024年度）
- **最終成果物**: 地域課題解決のための政策提案書
- **筆者担当パート**: 第4〜5回（90分×2コマ）の生成AI利活用

**授業全体の流れ**:
| 回 | 内容 | 担当 |
|----|------|------|
| 1-3 | DXと地域課題の基礎 | 主担当教員 |
| **4-5** | **生成AI利活用（本章の対象）** | **筆者** |
| 6-8 | 課題発見とリサーチ | 主担当教員 |
| 9-11 | データ収集と分析 | 主担当教員 |
| 12-14 | 政策立案と提案書作成 | 主担当教員 |
| 15 | 最終発表 | 全教員 |

筆者が担当する第4〜5回は、学生が地域課題解決のプロジェクトに取り組む**準備段階**です。この2コマで生成AIの基本的な活用方法を学び、その後の授業で実際のプロジェクトに応用します。

### 2.1.2 生成AI利活用パートの学習目標の変遷

**2023年度の目標と実践内容**:

2023年度は、「地域公共政策士が対話型生成AIを使っていくには」というテーマで、**AIはビジネスパートナーになりえるか？** という観点から授業を展開しました。

具体的な内容：
- 地域公共政策士を目指すことで身に付く能力
- 対話型生成AIは、地域公共政策士の仕事を支援する
- AI(人工知能)の歴史
- 生成AIとは
- 対話型生成AIとは
- Bing Chat と Chat GPT の違い
- 対話型生成AIを使ってみる

**2023年度の問題点**:

授業後のアンケートや観察から、以下の課題が明らかになりました。

> 「**生成AIをどのような場面でどう使えばいいのかわからない学生がほとんどでした**」

実際の学生の反応：
- 「AIが便利なのはわかったけど、実際にどう使えばいいのか...」
- 「プロンプトの書き方は学んだけど、いつ使うべきか判断できない」
- 「地域政策の立案にAIをどう活かせるか、イメージできない」

この設計では、**AIの知識・技術は学べても、実践的な活用方法が不明確**でした。技術論が中心で、「地域課題解決」という本来の目的との結びつきが弱かったのです。

**2024年度の目標（実践重視への転換）**:

2023年度の反省を踏まえ、学習目標とアプローチを大きく変更しました。

> 「**地域公共政策立案に生成AIを使えば、どのようなことができるかを理解する**」
>
> 「**仮想プロジェクトで実際に生成AIを利用して、政策立案を行う**」

**アプローチの転換**:

| 観点 | 2023年度 | 2024年度 |
|------|---------|---------|
| 焦点 | AIの知識・技術 | 実践的な活用方法 |
| 方法 | 講義中心（AIとは何か） | 実習中心（AIで何ができるか） |
| シナリオ | 一般的なAI活用例 | 仮想プロジェクトでの実践 |
| 学生の学び | 「AIとは何か」を知る | 「AIをどう使うか」を体験する |

**具体的な学習内容**:
1. **地域公共政策立案のプロセスを理解する**
   - 問題発見 → 情報収集 → 分析 → 提案
   - 各プロセスでのAI活用の可能性

2. **仮想プロジェクトでAIを実際に使う**
   - 地域課題のリサーチにAIを活用
   - アンケート設計と分析にAIを活用
   - 政策提案書の作成にAIを活用

3. **「どのような場面でどう使えばいいか」を体験的に学ぶ**
   - いつAIを使うべきか/使うべきでないか
   - どうプロンプトを書けば効果的か
   - AI生成内容をどう検証・修正するか

4. **批判的検証の重要性を理解する**
   - AIの回答を鵜呑みにしない
   - 出典を確認する
   - 目的に照らして評価する

**この転換の意義**:

2023年度は「知識」重視で、学生は**何ができるか**がわかりませんでした。2024年度は「実践」重視にすることで、学生が**実際にAIを使いながら**、その可能性と限界を体験的に学べるようにしました。

この転換は、本書の核心でもあります。

### 2.1.3 90分×2コマの授業構成（進化の過程）

**2023年度の構成（知識重視）**:

2023年度は「地域公共政策士が対話型生成AIを使っていくには」というテーマで、**AIの基礎知識**を中心に構成しました。

| 回 | テーマ | 内容 |
|----|-------|------|
| 第1コマ | 対話型生成AIの基礎 | ・地域公共政策士を目指すことで身に付く能力<br>・対話型生成AIは地域公共政策士の仕事を支援する<br>・AI(人工知能)の歴史<br>・生成AIとは<br>・対話型生成AIとは<br>・Bing Chat と Chat GPT の違い |
| 第2コマ | 対話型生成AIの実践 | ・対話型生成AIを使ってみる<br>・簡単な演習 |

**問題だった点**:
- 講義が中心で、実習時間が不足
- AIの「知識」は得られるが、「活用方法」が不明確
- 地域政策立案との結びつきが弱い
- 学生は「どう使えばいいかわからない」と感じていた

**学生の典型的な反応**:
> 「AIの種類や歴史は理解できたけど、実際に政策立案のどの場面で使えばいいのか、イメージできなかった」

**2024年度の構成（実践重視）**:

2023年度の反省を踏まえ、「仮想プロジェクトで実際に政策立案を行う」アプローチに変更しました。

**重要な変更点**:
- 講義時間を削減、実習時間を大幅に増加
- 「AIとは何か」から「AIで何ができるか」へ
- 仮想の地域課題を設定し、実際に政策立案プロセスを体験
- 各プロセスでAIをどう使うかを実践的に学ぶ

**第1コマ（90分）: 地域課題解決のための情報収集とAI活用**

| 時間 | 内容 | 活動 | 設計意図 |
|------|------|------|---------|
| 0-15分 | 導入 | ・本日の目標：「仮想プロジェクトで政策立案を体験」<br>・地域課題の提示<br>・プロセス全体像の説明 | **「何ができるか」を体験すると明示** |
| 15-30分 | 講義 | ・政策立案プロセスの基礎<br>・各プロセスでのAI活用の可能性<br>・実践的なプロンプト例の紹介 | **必要最小限の講義**<br>（実践に必要な知識のみ） |
| 30-80分 | 実習 | **仮想プロジェクト実践**<br>①地域課題のリサーチ（AIを使ってみる）<br>②情報の整理と分析<br>③政策アイデアの創出<br>④批判的検証 | **実際に手を動かす**<br>AIで何ができるかを体験 |
| 80-90分 | まとめ | ・振り返り：「AIで何ができたか？」<br>・「どの場面で役立ったか？」 | **体験からの学び** |

**第2コマ（90分）: データに基づく政策立案とAI協働**

| 時間 | 内容 | 活動 | 設計意図 |
|------|------|------|---------|
| 0-10分 | 復習 | ・前回の振り返り共有<br>・AIで何ができたかの確認 | 連続性を意識 |
| 10-25分 | 講義 | ・アンケート設計の基本<br>・データ分析へのAI活用<br>・協働作業でのツール活用（Microsoft Loop） | 実践に必要な知識のみ |
| 25-70分 | グループ実習 | **仮想プロジェクト続き**<br>①グループでアンケート設計<br>②AIを活用したデータ分析<br>③政策提案のブラッシュアップ | **グループで協働しながらAI活用**<br>実際の政策立案を体験 |
| 70-85分 | 発表 | ・各グループの成果発表<br>・AIをどう使ったかの共有 | 他グループの活用方法から学ぶ |
| 85-90分 | まとめ | ・2回を通しての振り返り<br>・「どのような場面でどう使えるか」の理解確認 | **体験を言語化** |

**2024年度設計の核心**:

1. **「知識」から「体験」へ**
   - 2023年度：AIについて学ぶ
   - 2024年度：AIを使って実際に政策立案する

2. **「一般論」から「具体的シナリオ」へ**
   - 2023年度：AIの一般的な説明
   - 2024年度：仮想プロジェクトで実践

3. **「理解する」から「できるようになる」へ**
   - 2023年度：理解したが使えない
   - 2024年度：実際に使いながら理解する

4. **評価軸の明確化**
   - 「AIの知識」ではなく「AIで何ができたか」

## 2.2 生成AIツールの活用方法

### 2.2.1 使用するツールと選定理由

**主要ツール**:
1. **Microsoft Edge Copilot**
   - 選定理由：大学のライセンスで全学生が使用可能
   - 用途：リサーチ、データ分析、アンケート設計支援

2. **Microsoft Loop**
   - 選定理由：Microsoft 365の一部、共同編集に最適
   - 用途：グループワークでの協働作業

**ツール選定の基準**:
- 大学のライセンスで使用可能（コスト面）
- 学生のプライバシー保護（個人情報の扱い）
- 操作が比較的簡単
- 授業外でも継続して使える

**他のツールを使わない理由**:
- ChatGPT Plus：学生が個人で契約する必要がある（経済的負担）
- Claude：日本語対応が限定的（当時）
- Gemini：授業開始時点で機能が不十分

### 2.2.2 リサーチフェーズでのAI活用（2024年度の実践）

**活用場面**: 地域課題に関する背景情報の収集

**2024年度のアプローチ：「まず使ってみる」体験重視**

2024年度は、学生が「生成AIで何ができるか」を実際に体験することを最優先しました。「使う/使わない」の判断力は、まず使ってみて、その効果と限界を体験して初めて身につくと考えたからです。

**具体例：沖縄県の公共交通問題のリサーチ**

**導入（教員から課題提示）**

教員が仮想プロジェクトとして具体的な課題を提示：

```
【今日のプロジェクト】
「沖縄県の路線バスが減少している問題について調べ、
高齢者の移動支援策を提案してください」

【調べるべきこと】
・現状：どれくらい減っているか
・原因：なぜ減っているか
・影響：誰が困っているか
・対策：他地域の事例はあるか

【使うツール】
・Edge Copilot（リサーチ）
・Microsoft Loop（グループでの情報共有）
```

**実習：AIを使ってリサーチしてみる（30分）**

学生に、まずAIを自由に使わせます。

**学生Aが実際に使ったプロンプト（初回）**:
```
沖縄県の路線バスについて教えてください
```

**Copilotの回答（要約）**:
```
沖縄県の路線バスは、主に沖縄本島で運行されています...
（一般的な情報が続く）
```

**問題点**: 質問が漠然としすぎている。知りたいことが得られない。

**教員の介入**:
筆者が巡回中に気づき、声をかけます。

> 教員：「何を知りたかったんだっけ？」
> 学生A：「廃止路線数と理由です」
> 教員：「じゃあ、それを明確にプロンプトに書いてみて」

**学生Aが実際に使ったプロンプト（改善版）**:
```
沖縄県で過去10年間に廃止された路線バス路線の数と、
廃止の主な理由を教えてください。
可能であれば、データの出典も示してください。
```

**Copilotの回答（改善版、要約）**:
```
沖縄県では過去10年間で約XX路線が廃止されました。
主な理由：
1. 利用者減少（少子高齢化、自家用車の普及）
2. 運転手不足
3. 運営コストの増加

出典：沖縄県交通政策課「令和○年度バス路線維持調査報告書」
```

**学生Aのワークシート**:
```
【AI活用】
プロンプト1回目：沖縄県の路線バスについて教えてください
→ 一般的な情報しか得られず

プロンプト2回目：（改善版、上記）
→ 具体的な数値と理由が得られた

【批判的検証】
・出典が示されたので、沖縄県のHPで確認した → 正しかった
・ただし、「約XX路線」の具体的な数値は不明確
・追加で県のHPで正確な数値を確認する必要がある
```

**振り返り（10分）**

実習後、教員が問いかけます：

```
教員：「AIを使ってみて、何ができた？何ができなかった？」

学生Aの振り返り：
「統計データはすぐに見つかって便利だった。
でも、数字の意味や、なぜその問題が起きているかは、
自分で考えないといけないと思った」

学生Bの振り返り：
「最初のプロンプトがあいまいすぎて、
欲しい情報が得られなかった。
2回目で具体的に聞いたら、良い情報が出てきた」
```

**2024年度のねらい**:

この実習では、以下を体験させることを目的としました。

1. **AIで何ができるか**を実感する
   - 情報収集が速い
   - データを見つけやすい
   - 複数の視点を提示してくれる

2. **AIの限界**にも気づく
   - プロンプトが重要
   - 出典確認が必要
   - 最終的な判断は自分

3. **使いながら学ぶ**
   - 試行錯誤が重要
   - 失敗から学ぶ
   - 他の学生の使い方からも学ぶ

**2025年度への課題**:

この体験をベースに、次年度は「いつAIを使うべきか/使うべきでないか」の**判断力**を育てることが目標です。

### 2.2.3 アンケート作成とデータ収集

**活用場面**: 住民向けアンケートの設計

**第2コマのグループ実習での例**

**グループBの課題**: 「高齢者の公共交通利用実態を調査したい」

**AIを使わない場合の典型的な問題**:
- 質問が抽象的すぎる（「バスをよく使いますか？」）
- 選択肢が偏っている
- 二重質問（「バスと電車、どちらが便利ですか？」）

**AIを活用した場合**:

**グループBのプロンプト**:
```
沖縄県の高齢者（65歳以上）を対象とした、
公共交通利用実態に関するアンケートを作成したいです。

目的：
・どのような交通手段を使っているか
・公共交通を使わない理由
・改善してほしい点

10問程度の質問を作成してください。
選択式と自由記述を組み合わせてください。
```

**Copilotが生成したアンケート案（抜粋）**:
```
Q1. あなたの年齢を教えてください
□ 65-69歳 □ 70-74歳 □ 75-79歳 □ 80歳以上

Q2. 週に何回、外出しますか？
□ ほぼ毎日 □ 週3-4回 □ 週1-2回 □ ほとんど外出しない

Q3. 外出時に最もよく使う交通手段は？（複数選択可）
□ 徒歩 □ 自転車 □ 自家用車（自分で運転）
□ 自家用車（家族の送迎） □ 路線バス □ タクシー
□ その他（　　）

Q4. 路線バスを使わない主な理由は？
□ バス停が遠い □ 本数が少ない □ 料金が高い
□ 時刻表がわかりにくい □ 乗り降りが大変
□ 自家用車がある □ その他（　　）
...
```

**批判的検証演習（第2コマの65-80分）**:

教員が用意した「問題のあるアンケート」を提示：

```
【問題のあるアンケート例】
Q. 路線バスは便利だと思いますか？
□ はい □ いいえ

Q. 高齢者にとってバスとモノレール、どちらが使いやすいですか？
□ バス □ モノレール

Q. UDタクシーの利用経験は？
□ ある □ ない
```

**学生に問う**: 「このアンケートの問題点を5つ見つけてください」

**グループBの回答**:
```
1. Q1は誘導的（「便利だと思いますか？」と決めつけている）
2. Q1は「便利」の定義が不明確
3. Q2は二重質問（バスとモノレールを同時に聞いている）
4. Q2は前提が間違っている（地域によってはモノレールがない）
5. Q3の「UDタクシー」は専門用語で説明がない
```

**改善案をグループで議論**:
```
Q1改善案：
「あなたにとって、路線バスは使いやすいですか？」
□ 非常に使いやすい □ やや使いやすい □ どちらとも言えない
□ やや使いにくい □ 非常に使いにくい

Q2改善案：
「路線バスの使いやすさを教えてください」
「モノレールの使いやすさを教えてください」
（2つの独立した質問に分ける）

Q3改善案：
「ユニバーサルデザインタクシー（車椅子やベビーカーで乗りやすいタクシー）を
利用したことがありますか？」
```

**この演習から学生が学ぶこと**:
- AIは便利だが、生成物には問題がある
- 「目的」に照らして検証する必要がある
- 批判的に見る力が重要

### 2.2.4 データ分析と可視化

**活用場面**: アンケート結果の分析

**Edge CopilotのAdvanced Data Analytics機能**を使用します。

**実習の流れ**:

1. サンプルデータ（CSV）をアップロード
2. 「このデータを分析して、主要な傾向を教えてください」とプロンプト
3. Copilotがグラフを自動生成
4. 学生は結果を解釈し、課題解決に結びつける

**重要な注意点**:

教員が強調すること：
> 「AIはグラフを作ってくれるけど、それが何を意味するかは、あなたたちが考えること。グラフを見て『何が問題か』『どうすれば解決できるか』を議論してください」

## 2.3 学生の反応と成果

### 2.3.1 ポジティブな反応

**[学生向け]** 先輩たちの成功体験

**定量データ（2024年度授業アンケート、n=38）**:

| 質問項目 | 肯定的回答 |
|---------|-----------|
| 生成AIの活用方法が理解できた | 94.7% |

- AIをあまり使わないため、学生自身の発想で提案

**パターン2: 形式は完璧だが独自性が低下（2024年度の課題）**
- AIを積極活用し、形式的完成度が向上
- データも豊富で論理的な提案書に
- しかし、一般的な施策が増え、独自性がやや低下
- プレゼンで質問すると、答えられない学生が増加

**2024年度の向上**:

学習目標を再定義し、実践重視・「批判的検証」を強化した結果：
- ✅ 形式的完成度が大幅向上（3.5 → 4.3）
- ✅ 論理性が向上（3.2 → 4.0）
- ✅ データに基づく提案が大幅向上（2.8 → 4.2）
- ✅ 実現可能性の検討が改善（3.1 → 3.6）

**2024年度の課題**:

しかし、独自性がやや低下しました：
- ⚠️ 独自性・独創性（3.8 → 3.5）

この低下の原因は、AI依存により一般的な情報に頼りすぎたためと考えられます。

**定性分析（提案書の内容分析）**:

**2023年度の典型例（AIをあまり使っていない）**:
```
タイトル：「沖縄の『ゆいまーる精神』を活かした高齢者移動支援」

提案内容：
1. 地域の祭りやイベントと連動した乗り合い送迎
2. 若者と高齢者をつなぐ「送迎マッチング」
3. 既存の観光バスの空き時間活用

（特徴）
・沖縄の文化（ゆいまーる）を活かした独自の視点
・学生自身が地域住民にヒアリングした結果を反映
・独自性は高い（3.8点）
・ただし、形式的完成度は低い（3.5点）
・データ不足（2.8点）、論理的整合性にやや課題（3.2点）
```

**2024年度の典型例（AI依存が強い）**:
```
タイトル：「沖縄県における高齢者の移動支援システムの構築」

提案内容：
1. デマンド型交通の導入
2. 高齢者向け交通アプリの開発
3. ボランティア運転手の育成

（問題点）
・どれも他地域で実施済みの一般的な施策
・沖縄特有の視点がない
・AIで調べた情報をそのまま使っている印象
・形式的完成度は高い（4.3点）
・データも豊富（4.2点）
・しかし独自性は中程度（3.5点）
```

**考察：トレードオフの発生**

2024年度の実践重視アプローチにより：

**大きく向上したもの**:
- ✅ 形式的完成度（3.5 → 4.3）
- ✅ データに基づく提案（2.8 → 4.2）
- ✅ 論理性・整合性（3.2 → 4.0）
- ✅ 実現可能性の検討（3.1 → 3.6）

**やや低下したもの**:
- ⚠️ 独自性・独創性（3.8 → 3.5）

**なぜこのトレードオフが起きたのか**:

1. **体験重視の副作用**
   - 「AIで何ができるか」を体験させることに集中
   - 結果、AIに頼りすぎる学生が増加
   - 一般的な情報に依存

2. **判断力の欠如**
   - 2024年度は「使う/使わない」の判断をさせていない
   - すべてのプロセスでAIを使ってしまう
   - 自分で考える時間が減少

3. **AIの特性**
   - AIは一般的・標準的な情報を提示
   - 学生はそれを鵜呑みにし、地域特有の視点が失われる

**2025年度への課題**:

2023年度の独自性（3.8点）を回復しつつ、2024年度の向上（形式・データ・論理性）を維持するには：
- 「AIなしで考える時間」の設定
- 「使う/使わない」の判断力の育成
- 批判的検証の強化
- 地域特有の視点を引き出す工夫（フィールドワークの重視など）
- AIに頼らない独自発想の時間を確保

## 2.4 実践から得られた重要な気づき

### 2.4.1 「効率化」と「学習の深さ」のトレードオフ

**当初の期待（2023年度）**:

> 「生成AIを使えば、情報収集や文章作成が効率化される。その分、議論や分析に時間を使えるようになり、学習の質が向上するはずだ」

**実際の結果**:

- ✅ 作業時間は確かに短縮された（リサーチ時間が1/3に）
- ❌ しかし、**思考時間も短縮されてしまった**
- ❌ 「悩む時間」「試行錯誤する時間」が失われた
- ❌ 結果、学習の深さが損なわれた

**具体例：2つのグループの比較**

| 項目 | グループF<br>（AI積極活用） | グループG<br>（AI控えめ） |
|------|--------------------------|------------------------|
| リサーチ時間 | 15分 | 45分 |
| 議論時間 | 20分 | 60分 |
| 提案の独自性 | 2.5点 | 4.0点 |
| 学生のコメント | 「早く終わって楽だった」 | 「大変だったけど学びが多かった」 |

グループGの学生の振り返り：
> 「最初、情報が見つからなくて焦った。でも、色々調べているうちに、意外な発見があった。AIに頼っていたら、この発見はなかったと思う」

**気づき**:

「効率化」は諸刃の剣です。確かに時間は節約できますが、その過程で**試行錯誤という学習機会**が失われます。

教育において、「最短距離で答えに辿り着く」ことが常に正しいわけではありません。遠回りの中にこそ、深い学びがあります。

**2025年度への対応計画**:

- 実習の最初10分を「AIなしで考える時間」に設定
- 「効率化していい部分」と「時間をかけるべき部分」を明示
- 「使う/使わない」の判断をさせる演習を追加
- 評価でも「試行錯誤の痕跡」「自分で考えた痕跡」を重視

### 2.4.2 評価の難しさ

**2023年度の問題点**:

「提案書の質」を重視していたため：
- 学生はAIを使って「見た目の良い提案書」を作成
- しかし、**学習プロセス**は評価されていない
- 結果、学生は「AIを使って早く仕上げる」ことに注力

**教員の悩み**:

> 「成果物だけを見ると、立派な提案書。でも、学生は本当に理解しているのか？プレゼンで質問すると、答えられない。何を評価すればいいのか、わからなくなった」

**2024年度の転換：プロセス評価の強化**

評価の配分を変更：
- 成果物（提案書）: 30%（従来50%）
- **プロセス**: 40%（従来30%）
  - ワークシートの記録
  - 批判的検証の痕跡
  - 議論の深さ（議事録）
- メタ認知・振り返り: 30%（従来20%）

**プロセス評価の具体例（2024年度）**:

ワークシートで評価する項目：
```
□ プロンプトが改善されているか（試行錯誤の痕跡）
□ AIを使って何ができたかを説明できているか
□ AIの限界に気づいているか（振り返りの記述）
□ 「課題解決に近づいたか」の自己評価とその理由が具体的か
□ グループでの協働ができているか
```

**効果**:

学生の行動が変化：
- 「早く終わらせる」→「試行錯誤しながら学ぶ」
- 「AIに丸投げ」→「AIを使いながら工夫する」
- 「結果重視」→「プロセス重視」

**2025年度に向けた評価指標の開発**:

2024年度の体験をベースに、次年度はさらに深い評価が必要です：

1. **AI活用の判断力**（使うべき場面で使い、使うべきでない場面で使わない）
   - 2024年度は測定していない
   - 2025年度の重点課題

2. **批判的思考力**（AI情報を検証できる）
   - 2024年度は振り返りで部分的に評価
   - より体系的な評価方法が必要

3. **メタ認知能力**（自分の学習プロセスを振り返れる）
   - 振り返りシートで評価
   - さらに深い内省を促す工夫が必要

4. **自律的思考力**（AIなしでも考えられる）
   - 2024年度は測定していない
   - AIありとなしの両方で評価する必要

これらを定量的に測定する方法の開発が、2025年度の課題です。

### 2.4.3 教員の役割の変化

**従来の教員の役割**:
- 知識の提供者
- ファシリテーター（議論を促進）
- 評価者

**生成AI時代の教員の役割（再定義）**:

**1. メタ認知支援者**

学生に問い続ける：
- 「何のためにAIを使っているの？」
- 「その情報、課題解決に役立つ？」
- 「AIの回答、本当に正しい？」
- 「自分は何を学んだ？」

実際の教室での会話例：
```
学生H: 「先生、これ調べました」（AIの出力を見せる）
教員: 「で、これを読んで、あなたは何を考えた？」
学生H: 「え...（考え込む）」
教員: 「AIの回答をそのまま受け取るんじゃなくて、
       『自分はどう思うか』を考えてみて」
```

**2. 体験の促進者（2024年度）**

2024年度は、まず「AIで何ができるか」を体験させることに注力しました。

```
教員の働きかけ例：
「どんどん使ってみて。失敗してもいいから」
「他の人の使い方も見てみよう」
「何ができた？何ができなかった？」
```

**2025年度に向けて：判断基準の提示者へ**

2024年度の体験をベースに、次年度は「判断軸」を示すことが課題です：

| 場面 | 判断 | 理由 |
|------|------|------|
| 課題の明確化 | 使わない | 自分で考える必要がある |
| 背景情報の収集 | 使ってもいい | 効率化できる |
| データの解釈 | 使わない | 批判的思考が必要 |
| アイデア出し | 使ってもいい | 発散的思考の支援 |
| 最終判断 | 使わない | 自分で決める必要がある |

この判断力を育てることが、2025年度の目標です。

**3. 批判的思考の促進者**

「AIの回答を疑う」習慣をつけさせる：

実際の介入例：
```
グループI（実習中）:
学生I1: 「AIによると、この施策のコストは1000万円だって」
学生I2: 「安いね、これで提案しよう」

教員（巡回中）: 「ちょっと待って。1000万円の根拠は？」
学生I1: 「AIが計算しました」
教員: 「どういう前提で計算したの？人件費は？設備費は？」
学生I1: 「...書いてないです」
教員: 「じゃあ、自分たちで積算してみて。AIの数字は目安だけど、
       正確性は保証されてないよ」
```

**4. 「学習目標の再確認」役**

学生が「手段の目的化」に陥りそうになったら、軌道修正：

```
学生J: 「先生、プロンプトうまく書けました！」
教員: 「良かったね。で、課題解決には近づいた？」
学生J: 「え...（ハッとする）」
教員: 「プロンプトは手段。目的は課題解決だよね。
       得られた情報を使って、次は何をする？」
```

**教員自身の学び**:

2年間の実践を通じて、筆者自身も学びました。

> 「2023年度は『AIの知識を教える』ことが教員の役割だと思っていた。でも、本当に必要なのは『AIとどう向き合うか』を教えることだった。技術ではなく、思考法と判断力を育てることが、教員の役割だと気づいた」

## 2.5 最も重要な問い：学生の質は本当に上がったのか？

### 2.5.1 成果物の質と学生の成長のギャップ

2024年度の実践を振り返り、筆者が最も悩んでいるのは、この問いです。

**確かに向上したもの**:
- ✅ 最終発表の質（提案書の完成度、プレゼンの質）
- ✅ データに基づく提案の増加
- ✅ 形式的な体裁の改善
- ✅ 学生の満足度（「学べた」という実感）

**しかし、本当に重要な問い**:
- ❓ 学生の**思考力**は向上したのか？
- ❓ 学生の**批判的思考能力**は育ったのか？
- ❓ 学生は**AI なしでも**課題解決できるようになったのか？
- ❓ この授業での学びは、**長期的に**役立つのか？

### 2.5.2 教員としての不安

**観察された現象**:

2024年度の最終発表では、確かに提案書の質は高かった。しかし、発表後の質疑応答で：

```
評価者: 「この統計データの出典は？」
学生: 「えっと...AIが教えてくれたデータなので...」
評価者: 「信頼性は確認した？」
学生: 「...確認していません」

評価者: 「なぜこの政策が最適だと判断したの？」
学生: 「AIがいくつか案を出してくれて、その中で一番良さそうだったので...」
評価者: 「『良さそう』の判断基準は？」
学生: 「...（答えられない）」
```

このような場面が、2023年度よりも**増えた**ように感じます。

**筆者の内省**:

> 「2024年度の改善で、学生は確かにAIを使えるようになった。しかし、それは本当に『学び』なのか？
>
> 提案書は立派になった。でも、それは学生の力なのか、AIの力なのか？
>
> 『できる』ようになったが、『わかる』ようになったのか？
>
> **成果物の質と、学生の質は、別物だ**」

### 2.5.3 測定の難しさ

**従来の評価軸では捉えられない問題**:

| 評価項目 | 2023年度 | 2024年度 | 考察 |
|---------|---------|---------|------|
| 提案書の完成度 | 3.5 | 4.3 | 大幅向上 |
| 学生の満足度 | 3.8 | 4.5 | 向上 |
| 独自性・独創性 | 3.8 | 3.5 | やや低下 |
| **批判的思考力（質疑応答での評価）** | 3.6 | **3.2** | **低下？** |
| **自律的思考力（AIなし課題での評価）** | ? | ? | 測定していない |

問題は：
- 「批判的思考力」をどう測定するか？
- 「AI依存度」をどう定量化するか？
- 「長期的な学習効果」をどう追跡するか？

### 2.5.4 仮説：「見せかけの向上」の可能性

筆者が恐れているのは、**見せかけの向上**です。

**仮説1: 能力の外部化**
- 学生の能力が向上したのではなく、AIに依存しているだけ
- AIという「外部の脳」に頼ることで、表面的には成果が出る
- しかし、学生自身の思考力は育っていない

**仮説2: 評価指標の不適切さ**
- 「提案書の質」で評価しているが、それは成果物の評価
- 本来評価すべきは「学習プロセス」と「思考力の成長」
- 評価軸が間違っているから、真の学びが見えていない

**仮説3: 短期的効果 vs 長期的問題**
- 90分×2コマでは「AIの使い方」は学べる
- しかし、「AI依存からの脱却」「批判的思考の定着」には時間が不足
- 短期的には成果が出ても、長期的な問題が潜んでいる

### 2.5.5 2025年度への課題

**2024年度の到達点**:

- ✅ 学生は「AIで何ができるか」を体験できた
- ✅ AI活用の基本的なスキルは身についた
- ✅ 提案書の質は向上した

**しかし、まだ不足していること**:

- ❌ 「いつAIを使うべきか/使うべきでないか」の判断力
- ❌ 批判的思考の定着
- ❌ AI依存からの脱却
- ❌ 自律的思考力の育成

**2025年度で実施したいこと**:

1. **AI活用の判断力を育てる**
   - 「使う/使わない」を判断させる演習を追加
   - 各プロセスでの判断基準を明示
   - 判断の理由を説明させる

2. **AIなし課題の追加**
   - 第3コマ以降で、AI使用禁止の課題を課す
   - 学生が自力で解決できるかを評価
   - AI依存度を測定

3. **批判的思考の評価方法の開発**
   - 質疑応答での評価を体系化
   - 「なぜ？」「根拠は？」に答えられるかを評価
   - ルーブリックの開発

4. **プロセス評価のさらなる強化**
   - 「AIなしで考える時間」の設定
   - 思考プロセスの可視化
   - 「試行錯誤の痕跡」「自己修正の過程」の評価

5. **長期的追跡調査の開始**
   - 卒業後のアンケート
   - 「この授業で学んだことが役立ったか？」
   - 「AIとの付き合い方は変わったか？」

**最も重要な問い（2025年度の挑戦）**:

> 「生成AI時代のPBLで、学生の**真の成長**をどう評価し、どう促進するか？」

2024年度は「体験」に焦点を当てました。2025年度は、その体験をベースに**判断力と思考力**を育てることが目標です。

この問いに対する答えを見つけることが、2025年度の最大の課題であり、本書執筆の最大の動機でもあります。
