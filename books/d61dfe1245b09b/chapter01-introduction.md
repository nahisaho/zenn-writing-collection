# 第1章 はじめに

## 1.1 Interactive Agentic Prompt（IAP）とは

**Interactive Agentic Prompt（IAP）** は、AIを単なる質問応答ツールから「専門家パートナー」へと変革する対話型プロンプト設計手法です。

従来のプロンプトエンジニアリングでは、ユーザーが完璧な指示を一度に与える必要がありました。しかしIAPでは、AIが主体的に質問を投げかけ、ユーザーとの対話を通じて真の目的を発見し、最適な解決策を導き出します。

### 1.1.1 IAPの3つの特徴

| 特徴 | 説明 |
|------|------|
| **Interactive（対話的）** | AIが一問一答形式で質問し、ユーザーの真のニーズを引き出す |
| **Agentic（エージェント的）** | AIが受動的な応答者ではなく、能動的なファシリテーターとして振る舞う |
| **Prompt（プロンプト）** | 体系化された設計パターンにより、再現性のある高品質な対話を実現 |

## 1.2 従来のプロンプトとの違い

### 1.2.1 従来のプロンプトの課題

```
ユーザー: マーケティング戦略を教えて
AI: マーケティング戦略には、4P分析、STP分析、SWOT分析などがあります...
    （一般的で汎用的な回答）
```

従来のアプローチでは：
- ユーザーが適切な質問を考える負担が大きい
- 文脈や背景が不足し、汎用的な回答になりがち
- 専門知識がないと深い議論に至らない

### 1.2.2 IAPによる対話

```
AI: マーケティング戦略についてお手伝いします。
    まず、どのような製品やサービスについてお考えですか？
ユーザー: B2B向けのSaaSプロダクトです
AI: ありがとうございます。そのSaaSの主なターゲット業界は？
ユーザー: 製造業の中小企業です
AI: 現在の主な課題は何でしょうか？
    1. 認知度向上　2. リード獲得　3. 解約率改善　4. その他
ユーザー: 2のリード獲得です
AI: 了解しました。ABM（アカウントベースドマーケティング）を軸に、
    製造業中小企業向けのリード獲得戦略を提案します...
    （具体的で実行可能な回答）
```

IAPでは：
- AIが主体的に必要な情報を収集
- ユーザーの認知負荷を軽減
- コンテキストに基づいた具体的な提案が可能

## 1.4 対象読者と前提知識

### 1.4.1 対象読者

本書は以下の方を主な対象としています：

- **ビジネスパーソン**: AIを業務効率化やコンサルティングに活用したい方
- **エンジニア**: プロンプトエンジニアリングのスキルを体系的に習得したい方
- **教育関係者**: AI教育や研修プログラムを設計したい方

## 1.5 KOTODAMAプロジェクトについて

本書の内容は、**KOTODAMAプロジェクト**の実践知見に基づいています。

KOTODAMAは、Interactive Agentic Promptを様々な専門分野に適用し、AIを専門家パートナーとして活用するためのテンプレート集です：

- **KOTODAMA4Biz**: ビジネス・経営分野向けIAPテンプレート
- **KOTODAMA4Edu**: 教育分野向けIAPテンプレート

これらのプロジェクトで蓄積された設計パターン、ベストプラクティス、失敗事例を本書で体系化しています。
