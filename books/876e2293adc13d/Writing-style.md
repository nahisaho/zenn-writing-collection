# 教育データ利活用ガイドブック - プロジェクト設定

## プロジェクトの目的
このプロジェクトは、初等・中等教育の教員向けに、教育データの適切な利活用方法をわかりやすく解説するガイドブックを作成することを目的としています。

## 執筆方針

### ターゲット読者（ペルソナ分析に基づく）

#### 主要読者層（80%）
- **小学校教員**（46.7%）：担任教員、特別支援コーディネーター、養護教諭
- **中学校教員**（33.3%）：教科担任、生徒指導主事、進路指導主事

#### ITスキルレベル分布
- **基礎レベル**（40%）：Excel基本操作、Google Classroom使用程度
- **中級レベル**（43%）：校務支援システム活用、簡単な統計処理
- **上級レベル**（17%）：プログラミング、データ分析、システム管理

#### 年齢・経験分布
- **20代**（13%）：新任・若手教員、理論と実践のギャップに悩む
- **30代**（43%）：中堅教員、実践力向上と組織的取り組みに関心
- **40代**（37%）：ベテラン教員、経験知とデータの融合を模索
- **50代**（7%）：管理職、組織運営とビジョン策定に重点

#### 関心事・課題別分類
- **個別支援・特別支援**：8名（27%）
- **生徒指導・いじめ予防**：7名（23%）
- **学力向上・授業改善**：6名（20%）
- **学校運営・組織マネジメント**：4名（13%）
- **ICT・情報教育**：3名（10%）
- **その他**（進路指導、健康管理等）：2名（7%）

### 文書作成の基本方針

#### 1. ITスキルレベル別アプローチ

##### 基礎レベル読者（40%）向け
- **専門用語は最小限**：IT用語には必ず平易な説明を併記
- **段階的解説**：「まずはここから」の明確な入口を設定
- **具体的手順**：画面キャプチャ付きの詳細ガイド
- **よくある失敗例**：「こんな時はどうする？」Q&A形式
- **用語集参照**：巻末用語集への誘導

##### 中級レベル読者（43%）向け
- **実践的内容重視**：すぐに使える具体的な手法
- **応用例の提示**：基本から一歩進んだ活用法
- **判断基準の明示**：「なぜそうするのか」の理論的背景
- **カスタマイズ方法**：学校の特性に合わせた調整法

##### 上級レベル読者（17%）向け
- **理論的背景**：システム思考、研究知見の提供
- **技術的詳細**：API活用、自動化の可能性
- **組織導入視点**：他教員への指導・支援方法

#### 2. 職種別重点ポイント

##### 担任教員向け
- **日常業務との関連**：出席簿、成績処理での活用
- **個別支援**：一人ひとりの子どもへの気づき
- **保護者連携**：データに基づく説明・相談

##### 生徒指導・特別支援担当向け
- **早期発見**：リスク信号の具体的指標
- **予防的アプローチ**：問題行動の予兆把握
- **組織的対応**：チーム学校での情報共有

##### 管理職向け
- **組織運営**：学校全体のデータ活用体制
- **説明責任**：保護者・地域への透明性確保
- **予算・人事**：効果的な資源配分の判断

#### 3. 実践的サポート要素の強化

##### 必須要素
- **チェックリスト**：各章末に実践確認項目
- **ワークシート**：すぐに使える記録・分析用紙
- **テンプレート集**：Excel、Word形式での提供
- **事例集**：成功例・失敗例の詳細解説

##### 視覚的理解促進
- **図表・イラスト**：概念図、フローチャート
- **画面キャプチャ**：操作手順の詳細解説
- **動画連携**：QRコードでの解説動画アクセス

#### 4. 文調・粒度の統一基準

##### 基本的な文調
- **敬語使用**：「です・ます」調で親しみやすく
- **具体的表現**：「〜することが重要」より「〜してください」
- **教育現場用語**：「生徒」「児童」「学級」等の正確な使い分け

##### 情報粒度の基準
- **基礎レベル**：1つの概念を3-5ステップで解説
- **中級レベル**：背景説明+実践方法+応用例
- **上級レベル**：理論+実装+評価改善の循環

#### 5. 法的・倫理的配慮の統一方針
- **個人情報保護法**：教育現場の文脈での解説
- **同意取得**：具体的な文書例・手続きフロー
- **データガバナンス**：学校組織での責任体制明示
- **リスク回避**：「してはいけないこと」の明確な提示

## Zenn記事の執筆設定

### GitHub連携手順
Zenn CLIを使用してGitHubと連携し、記事を管理します。

1. **リポジトリの作成**
   - GitHubで新規リポジトリを作成
   - リポジトリ名: `educational-data-guidebook`
   - 公開設定: Public（教育関係者が広くアクセスできるように）

2. **Zenn CLIのセットアップ**
   ```bash
   npm init --yes
   npm install zenn-cli
   npx zenn init
   ```

3. **記事の作成**
   ```bash
   npx zenn new:article
   ```

### Zenn Markdown記法の要点

#### 基本的な記法
- **見出し**: `#` で階層を表現（`#` が大見出し、`##` が中見出し）
- **強調**: `**太字**`、`*斜体*`
- **リスト**: `-` または `1.` で箇条書き
- **リンク**: `[表示テキスト](URL)`
- **画像**: `![代替テキスト](画像URL)`

#### 教育向け記事で有用な記法

##### メッセージボックス
```markdown
:::message
重要なポイントや補足説明をここに記載
:::

:::message alert
注意事項や警告をここに記載
:::
```

##### アコーディオン（折りたたみ）
```markdown
:::details クリックして詳細を表示
詳細な説明や補足情報をここに記載
:::
```

##### 数式
```markdown
$$
平均値 = \frac{合計}{データ数}
$$
```
