## なぜデータ分類が重要なのか

### 身近な例から理解する

#### こんな経験、ありませんか？

**小学校担任の佐藤先生のケース**
「家庭訪問で聞いた話をどこまで記録していいのか迷います。保護者から『この話は他の先生には内緒で』と言われたデータをどう扱えばいいでしょうか？」

**中学校生徒指導主事の田中先生のケース**
「いじめアンケートの結果を分析したいのですが、個人が特定される可能性があるデータをどの範囲まで共有していいか分からません」

**養護教諭の山田先生のケース**
「健康診断結果と保健室来室記録を組み合わせて分析したいのですが、どちらも個人情報なので慎重になってしまいます」

### データ分類の必要性

これらの悩みの根本原因は、**「すべての教育データを同じように扱ってしまう」** からです。

実際には、教育データには明確な分類があり、それぞれ異なる取り扱いルールがあります。

:::message
**💡 基礎知識ボックス**

- **公的教育データ**：法律に基づいて学校が管理すべきデータ  
- **個人データ**：個人を識別できる情報すべて  
- **センシティブデータ**：特に配慮が必要な個人データ

**重要な注意点**：
これらの分類は相互に排他的ではありません。一つのデータが複数の分類に該当することがあります。
例：成績データは「公的教育データ」であり、同時に「個人データ」でもあります。
健康診断結果は「公的教育データ」「個人データ」「センシティブデータ」すべてに該当します。

この重複する性質を理解することで、より慎重で適切なデータ活用が可能になります。
:::

## 公的教育データとは何か

### 定義と範囲

公的教育データとは、**学校教育法等の法令に基づいて学校が収集・管理する義務を負うデータ**です。

#### 法的根拠

[**学校教育法施行規則第28条**](https://laws.e-gov.go.jp/law/322M40000080011#Mp-At_28)に基づき、学校が備えなければならない表簿が規定されています。

1. 法令に関するもの
2. 学校の規則、日課表、教科用図書配当表、学校医等に関する記録、学校日誌
3. 職員の名簿、履歴書、出勤記録簿等
4. 指導要録・その写し・抄本、出席簿、健康診断に関する表簿
5. 入学者選抜・学習評価等に関するもの
6. 財産に関する帳簿、予算・決算書、教具・教材の目録
7. 文書処理簿

**参考リンク**：
- [e-Gov 法令検索（学校教育法施行規則）](https://laws.e-gov.go.jp/law/322M40000080011/)
- [文部科学省：学校教育法施行規則関連資料](https://www.mext.go.jp/)

#### データ保存期間（法令による規定）

- **指導要録（学籍部分）**: **20年間**保存
- **指導要録（指導部分）**: **5年間**保存  
- **出席簿**: **5年間**保存
- **健康診断簿**: **5年間**保存

**参考リンク**：
- [文部科学省：指導要録の取扱いについて](https://www.mext.go.jp/)
- [各自治体の教育委員会による具体的な保存期間規定を参照してください]

#### 基本的な公的教育データの種類

#### 1. 学籍情報（指導要録・学籍部分）
**内容**：
- 氏名、生年月日、性別
- 住所、保護者情報
- 入学・転校・卒業記録

**法的根拠**：[学校教育法施行規則第24条（指導要録の作成）](https://laws.e-gov.go.jp/law/322M40000080011#Mp-At_24)
**保存期間**：20年間
**特徴**：
- 法的に管理義務あり
- 基本的に誰でも扱える
- 長期保存が必要

**日常業務での活用例**：
- 学級名簿作成
- 保護者連絡
- 進路指導での基礎データ

#### 2. 成績・評価データ（指導要録・指導部分）
**内容**：
- 各教科の評定・評価
- 単元テスト結果
- 総合的な学習の時間の記録

**法的根拠**：[学校教育法施行規則第24条（指導要録の作成）](https://laws.e-gov.go.jp/law/322M40000080011#Mp-At_24)
**保存期間**：5年間
**特徴**：
- 教育上必要不可欠
- 担任・教科担任が主に管理
- 進路決定に直接影響

**活用上の注意点**：
- 個人情報でもあるため慎重な取り扱いが必要
- 保護者への説明責任あり
- データの正確性が極めて重要

#### 3. 出欠記録（出席簿）
**内容**：
- 出席・欠席・遅刻・早退記録
- 欠席理由
- 長期欠席の状況

**法的根拠**：[学校教育法施行規則第25条（出席簿の作成）](https://laws.e-gov.go.jp/law/322M40000080011#Mp-At_25)
**保存期間**：5年間
**データ活用の価値**：
- 不登校の早期発見
- 健康状態の把握
- 学習継続性の確認

**実例：出欠データの予防的活用**
```
【早期発見パターン】
・月曜日1限遅刻が3週連続 → 家庭環境要因の可能性
・体調不良での欠席が金曜日に集中 → 学校不適応の可能性
・欠席後の登校時間が遅い → 復帰への不安の可能性
```

#### 4. 健康診断結果（健康診断簿）
**内容**：
- 身体測定データ
- 健康診断結果
- 予防接種記録

**法的根拠**：[学校教育法施行規則第28条（学校が備えるべき表簿）](https://laws.e-gov.go.jp/law/322M40000080011#Mp-At_28)
**保存期間**：5年間
**管理者**：主に養護教諭
**活用場面**：
- 健康指導計画策定
- 特別な配慮が必要な児童生徒の把握
- 学校環境の健康影響評価

#### 5. 学習ログデータ（デジタル教材・学習ツール由来）
**内容**：
- デジタルドリルの学習進捗
- オンライン教材での正答率・所要時間
- 学習履歴・アクセスパターン
- つまづき箇所・学習方法の記録

**特徴**：
- 詳細で継続的なデータ収集が可能
- リアルタイムでの学習状況把握
- 個人の学習特性の詳細な分析が可能
- **複雑な所有・管理関係**（重要な注意点）

**分類上の位置づけ**：
- **基本的には「個人データ」** に分類
- 学習内容によっては「センシティブデータ」になる可能性
- 公的教育データではないため、より慎重な取り扱いが必要

### 公的教育データの特徴

#### ✅ メリット
1. **法的根拠が明確**：取り扱いに迷いが少ない
2. **継続性が高い**：長期的なデータ蓄積が可能
3. **標準化されている**：学校間での比較・分析が容易
4. **信頼性が高い**：正確性を重視した収集体制

#### ⚠️ 注意点
1. **個人情報でもある**：取り扱いには個人情報保護の配慮が必要
2. **更新頻度の制約**：法的手続きが必要な場合がある
3. **用途の制限**：教育目的以外での使用に制限
4. **長期保存義務**：適切な管理体制が必要

## 個人データ・センシティブデータの取り扱い

### 個人データの定義

**個人情報保護法における定義**：
「生存する個人に関する情報であって、特定の個人を識別することができるもの」

### 教育現場での個人データ分類

#### レベル1：基本的個人データ
**例**：
- 氏名、住所（学籍情報として管理）
- 学年・クラス情報
- 一般的な学習記録
- 学習ログデータ（基本的な学習進捗）

**取り扱いレベル**：標準的な個人情報保護措置

**学習ログデータの注意点**：
```
【基本レベルの学習ログ例】
・算数ドリル：正答率80%、所要時間15分
・国語読解：進捗3/10課題完了
・英語学習：単語テスト平均スコア85点

→ 一般的な学習記録と同等の取り扱い
```

#### レベル2：センシティブな個人データ
**例**：
- 家庭環境に関する詳細情報
- 心理検査結果
- カウンセリング記録
- 特別支援に関する情報
- **詳細な学習ログデータ（学習困難の傾向を示すもの）**

**取り扱いレベル**：特別な配慮と厳重な管理が必要

**センシティブな学習ログデータの例**：
```
【注意が必要な学習ログ】
・読字障害の可能性を示唆する読解パターン
・注意欠陥の傾向を示すアクセス履歴
・学習回避行動を示す操作ログ
・極端に低い学習継続率

→ 個別支援の参考になる一方、
　 ラベリングや偏見につながる可能性
```

#### レベル3：特に配慮を要するデータ
**例**：
- いじめに関する記録
- 児童虐待の疑いに関する記録
- 医療的ケアに関する情報

**取り扱いレベル**：最高レベルの機密性維持が必要

### 実際の現場での判断例

#### ケース1：家庭環境情報の取り扱い

**状況**：家庭訪問で得た情報をどの範囲で共有するか

**❌ 不適切な例**
```
職員室での会話：
「A君の家は経済的に厳しいようで...」
（他の児童の保護者も聞いている場所での発言）
```

**✅ 適切な例**
```
関係者会議での記録：
「A君の学習環境改善のため、以下の支援を検討
・家庭学習支援の提案
・必要に応じた学用品の配慮」
（具体的な家庭事情は記録せず、支援内容のみ記録）
```

#### ケース2：心理検査結果の活用

**状況**：スクールカウンセラーの検査結果を教員間で共有したい

**判断基準**：
1. **本人・保護者の同意**：明確な同意が得られているか
2. **教育上の必要性**：なぜその情報が必要なのか明確か
3. **共有範囲の限定**：最小限の関係者に限定されているか
4. **守秘義務の確保**：受け取る側に守秘義務の理解があるか

**適切な共有例**：
```
【共有内容】
・対象：A君
・共有者：担任、特別支援コーディネーター、管理職
・共有情報：「学習支援において視覚的説明が効果的」
・共有目的：適切な学習支援の提供
・期間：今年度末まで
```

### センシティブデータ取り扱いの実践原則

センシティブデータは児童生徒の人権に直結する重要な情報です。これらのデータを扱う際は、以下の4つの原則を常に意識し、慎重かつ適切に取り扱う必要があります。教育的効果と個人の尊厳のバランスを保ちながら、子どもたちの最善の利益を追求することが重要です。

#### 原則1：最小必要性の原則
**必要最小限の情報のみ収集・利用**

教育目的達成に本当に必要な情報だけを扱うという基本原則です。「念のため」「将来使うかも」という理由での収集は避け、明確な必要性がある情報のみを対象とします。

**実例**：
- 支援計画作成時：症状名ではなく「必要な配慮内容」を中心に記録
- 会議資料：個人名は伏せ、事例として一般化して共有

#### 原則2：目的限定の原則
**収集時に明示した目的以外では利用しない**

データを収集する際に明確にした目的の範囲内でのみ利用するという原則です。目的外利用は信頼関係を損ない、法的問題にもつながる可能性があるため、厳格に守る必要があります。

**実例**：
- 健康調査：健康指導目的で収集→学習指導には使用しない
- 家庭環境調査：支援計画作成目的→成績評価には使用しない

#### 原則3：同意取得の原則
**利用前に適切な同意を取得**

センシティブデータを扱う前に、本人（年齢に応じて）および保護者から明確な同意を得るという原則です。同意は形式的なものではなく、十分な説明と理解に基づく真の同意である必要があります。

:::message
**📋 詳細解説**
同意取得の重要性、具体的な手順、法的要件、実践的なポイントについては、第3章で詳しく解説します。
:::

**同意取得の実例**：
```
【保護者向け説明文例】
「お子様の学校生活をより良く支援するため、
以下の情報を担任および特別支援コーディネーターで
共有させていただきたく、ご同意をお願いいたします。

共有情報：学習特性に関する観察記録
共有目的：個別の学習支援計画作成
共有範囲：担任、特別支援コーディネーター、管理職
利用期間：今年度末まで

※ご不明な点がございましたら、いつでもお気軽にご相談ください」
```

#### 原則4：安全管理の原則
**技術的・組織的安全管理措置の実施**

センシティブデータの漏洩や不正利用を防ぐため、技術面と組織面の両方から適切な安全管理措置を講じる原則です。データの重要性に応じて、通常の個人情報より高いレベルの保護措置が求められます。

**技術的措置**：
- パスワード保護
- アクセス制限
- バックアップ体制
- 暗号化（必要に応じて）

**組織的措置**：
- 取り扱い責任者の明確化
- アクセス権限の適切な設定
- 定期的な監査・点検
- 事故時の対応手順整備

## データの所有権と利用権限

教育データの「誰のものか」「誰が使えるのか」という問題は、学校現場で最も混乱しやすい領域の一つです。一般的なビジネスの世界とは異なり、教育データには複数の関係者が複雑に絡み合っており、それぞれが異なる権利と責任を持っています。ここでは、実際の場面で判断に迷わないよう、具体的な事例を交えながら所有権と利用権限について解説します。

### 教育データの所有関係

#### 複雑な所有関係の理解

教育データの所有関係は一般的なビジネスデータより複雑です。なぜなら、データの主体である児童生徒は未成年であり、学校は教育機関として特別な責任を負い、保護者には法定代理人としての権利があるからです。

**関係者とその立場**：
- **児童生徒本人**：データの主体
- **保護者**：未成年者の法定代理人として権利を持つ
- **学校**：データの管理者として責任を持つ
- **教育委員会**：学校の設置者として監督責任
- **国・地方自治体**：法制度の枠組みを提供

### 具体的な権限関係

それぞれのデータタイプについて、実際の現場で判断しやすいよう、所有者と利用権限を整理しました。これらを理解することで、日常的な業務での適切な判断が可能になります。

#### 1. 学籍データ
**所有者**：学校（教育委員会）
**利用権限**：教育目的での利用に限定
**保護者の権利**：閲覧・訂正請求権

#### 2. 成績データ
**所有者**：学校
**作成者権限**：担当教員
**保護者の権利**：結果の通知を受ける権利、説明を求める権利

#### 3. 個人的な観察記録
**作成者**：個人教員
**管理者**：学校
**利用制限**：教育目的、かつ適切な同意のもとでの利用

#### 4. 学習ログデータ（デジタル教材・学習ツール）
**特殊な所有関係**：
- **データ収集者**：教材提供事業者
- **データ管理者**：学校（契約により異なる）
- **データ主体**：児童生徒本人
- **利用権者**：学校、教員（契約の範囲内）

**重要な注意事項**：
```
【契約形態による違い】

■ 学校契約型
・学校がデータの管理権を持つ
・教育目的での利用が比較的柔軟
・ただし事業者の技術的制約あり

■ 個人契約型（家庭利用）
・データの利用権が複雑
・学校での活用には保護者同意が必要
・事業者の利用規約に注意が必要

■ 自治体一括契約型
・統一的なデータ管理が可能
・学校間でのデータ活用も視野
・ただし契約条件の制約が大きい
```

### 実践的な権限判断

理論だけでは実際の現場で迷うことが多いため、よくある具体的な場面での判断例を示します。これらの Q&A を参考に、類似の状況での適切な判断を行ってください。

#### よくある質問と回答

**Q1**：「担任が作成した個別指導記録を、次年度の担任に引き継いでもいいですか？」

**A1**：
- ✅ **適切**：教育的継続性のための引き継ぎは適切
- ⚠️ **注意点**：センシティブな内容は保護者同意を確認
- 📋 **方法**：引き継ぎ時に必要な情報のみを整理して提供

**Q2**：「保護者から子どもの学校でのデータを全て開示してほしいと言われました」

**A2**：
- ✅ **原則**：保護者には開示請求権がある
- ⚠️ **制限**：他の児童に関する記録は除外
- 📋 **手続き**：学校として統一した開示手続きに従って対応

**Q3**：「研究のため、匿名化した学習データを大学に提供したいのですが？」

**A3**：
- ⚠️ **慎重検討必要**：匿名化でも個人情報に該当する可能性
- 📋 **手続き**：保護者への説明と同意取得が原則
- ✅ **代替案**：統計データや一般化された傾向データでの提供を検討

**Q4**：「デジタルドリルの学習ログを他の教科指導に活用してもいいですか？」

**A4**：
- ✅ **原則可能**：教育目的の範囲内での活用は適切
- ⚠️ **契約確認**：デジタル教材の利用規約・契約内容を確認
- 📋 **注意点**：
  - 本来の収集目的（算数）を超えた利用（生活指導等）は慎重に
  - 学習困難の傾向が見える場合は、センシティブデータとして扱う
  - 保護者への事前説明があると安心

**Q5**：「家庭で使用している学習アプリのデータを学校で参考にしたいのですが？」

**A5**：
- ❌ **原則困難**：個人契約のデータは学校利用に制約が大きい
- 📋 **必要な手続き**：
  - 保護者の明確な同意取得
  - 事業者の利用規約の確認
  - 学校での取り扱い方法の明文化
- ✅ **代替案**：家庭学習の様子を保護者から聞き取り、参考情報として活用

## 教育データの特殊性と配慮事項

教育データは他の分野のデータとは根本的に異なる特殊性を持っています。なぜなら、データの主体が「成長途中の子どもたち」であり、そのデータが「将来にわたって影響を与える可能性」があるからです。また、学校は単なるサービス提供機関ではなく、子どもたちの人格形成に深く関わる教育機関としての責任を負っています。これらの特殊性を理解せずにデータを扱うと、子どもたちに予期しない不利益をもたらす可能性があります。

以下では、教育現場で特に重要となる配慮事項について詳しく解説します。

## Microsoft Purview による教育データの保護

### Microsoft Purview Information Protectionで実現する情報分類

**教育現場における意図しない情報漏洩を防ぎ、適切なデータ保護を自動化する重要なソリューション**

教育現場では多忙な日常業務の中で、どのデータがどのレベルの機密性を持つのかを常に意識してデータを扱うことは困難です。「このファイルは保護者に見せても大丈夫だろうか」「この資料をメールで送信しても問題ないか」といった判断を、個々の教職員が毎回行うのは現実的ではありません。Microsoft Purview Information Protection は、こうした人的ミスによる意図しない情報漏洩を防止し、データの機密レベルに応じた適切な保護を自動的に適用します。

**なぜ自動分類が重要なのか：**
- **人的ミスの防止**：忙しい教育現場で見落としがちな機密情報を自動検出
- **統一基準の確保**：個人の判断に依存せず、組織全体で一貫した保護レベルを適用
- **業務効率の向上**：教職員が保護レベルを意識せずとも、システムが適切に判断・保護
- **法的コンプライアンスの確保**：個人情報保護法等の要求事項を自動的に満たす仕組み

Microsoft Purview は、教育データを適切に分類・保護・管理するための包括的なソリューションを提供します。

#### 自動分類ラベルの設定例

**公開データラベル（緑）**：
```
対象: 学校便り、行事予定、給食献立
設定: 暗号化なし、外部共有可能
適用例: SharePointの公開フォルダに自動適用
```

**内部限定ラベル（黄）**：
```
対象: 成績一覧、出席簿、学級名簿
設定: 暗号化あり、校内のみ共有可能
適用例: 「成績」「出席」キーワードで自動検出
```

**機密ラベル（赤）**：
```
対象: 特別支援記録、いじめ記録、健康情報
設定: 強力な暗号化、限定メンバーのみアクセス可
適用例: 特定フォルダへの保存時に自動適用
```

Microsoft Purview コンプライアンスポータルは、教育機関のデータガバナンス要件に特化した包括的なコンプライアンス管理プラットフォームです。教育現場では、学生の個人情報保護と教育サービスの向上という、一見相反する要求を同時に満たす必要があります。このポータルは、複雑な法的要件を自動化により管理し、教職員の負担を軽減しながら、適切なコンプライアンス体制を構築します。

**なぜ統合管理が重要なのか：**

### 教育現場特有の留意点

教育現場には、一般的な個人情報保護だけでは対応できない特殊な状況があります。集団生活での配慮、長期的な影響への責任、多様性の尊重など、教育機関ならではの複雑な課題に適切に対応する必要があります。

#### 1. 集団生活での配慮

**課題**：個人情報の保護と集団指導の両立

学校は集団生活の場であるため、個人への配慮が他の児童生徒にも影響を与えることがあります。個人情報を保護しながら、自然で効果的な集団指導を行う工夫が求められます。

**実践例**：
```
【配慮が必要な場面】
・座席配置：個別配慮の理由を他児に説明する際
・グループ分け：学習特性を考慮した編成の際
・発表順序：個人特性に配慮した指名の際

【適切な対応】
・表面上は公平に見える配慮方法の工夫
・事前の本人・保護者との相談
・他児への適切な説明（差別偏見防止）
```

#### 2. 長期的な影響への配慮

教育データは子どもたちの将来に長期間にわたって影響を与える可能性があります。一時的な状況や問題が、その後の教育機会や人生に不当な影響を与えないよう、慎重な配慮が必要です。

**中学校進学時の引き継ぎ**：
- 小学校時代の記録が偏見につながらないよう注意
- 成長・変化を前提とした情報提供
- 新しい環境での可能性を重視

**高校受験・就職時**：
- 不利益となる可能性のある記録の取り扱い
- 本人の努力や成長を適切に評価
- 将来への影響を慎重に考慮

#### 3. 多様性への配慮

現代の教育現場では、様々な背景を持つ子どもたちと家庭への配慮が求められます。データの収集や活用においても、多様性を尊重し、偏見や差別につながらないよう注意が必要です。

**家庭の多様性**：
- 単親世帯、国際結婚、里親等への配慮
- 家庭の価値観や文化的背景の尊重
- 経済状況に関する配慮

**個人の多様性**：
- 障害の有無に関わらない平等な取り扱い
- 性別、性的指向等への配慮
- 学習スタイルや得意分野の多様性尊重

## データガバナンスの基本

**組織全体で一貫したデータ管理を実現し、教育活動の質向上と個人情報保護を両立させる仕組み**

データガバナンスとは、組織全体でデータを適切に管理・活用するためのルール、体制、プロセスの総称です。教育現場では、多様な関係者（管理職、教職員、保護者、児童生徒）がそれぞれ異なる立場でデータに関わるため、明確な責任分担と統一された管理方針が不可欠です。適切なデータガバナンスにより、個人情報保護を確保しながら、教育データの価値を最大限に引き出すことができます。

### 学校組織での責任体制

#### 基本的な責任体制

**校長**：最終責任者
- データ管理方針の策定
- 重大事案の最終判断
- 対外的な説明責任

**教頭**：実務責任者
- 日常的なデータ管理の監督
- 教職員への指導・研修
- インシデント時の初動対応

**情報管理担当者**：技術面の責任者
- システムのセキュリティ管理
- バックアップ・復旧体制
- アクセス権限の管理

**各教員**：実務担当者
- 担当児童生徒のデータの適切な取り扱い
- 収集・記録の正確性確保
- 守秘義務の遵守

### 実践的なデータガバナンス

データガバナンスの実践では、理論だけでなく具体的な実装方法が重要です。学校では、複数の教職員が様々な教育データを扱うため、統一されたルールと体制が不可欠です。ここでは、実際の学校現場で導入しやすい、実践的なデータガバナンスの方法を紹介します。

#### 1. データ取り扱いルールの策定

学校全体で一貫したデータ取り扱いを実現するため、明文化されたルールが必要です。このルールは、日常業務で判断に迷った時の指針となり、トラブル防止にも役立ちます。

**基本方針文書の例**：
```
【○○学校データ取り扱い基本方針】

1. 目的
児童生徒の学習・生活支援のため、適切なデータ活用を行う

2. 基本原則
・教育目的に限定した利用
・最小必要性の原則に基づく収集
・適切な同意取得と説明責任
・技術的・組織的安全管理措置の実施

3. 禁止事項
・教育目的以外での利用
・無断での第三者提供
・不適切な場所での取り扱い
・セキュリティ対策の不備

4. 事故時の対応
・速やかな報告体制
・被害拡大防止措置
・関係者への適切な説明
・再発防止策の検討・実施
```

#### 2. 定期的な点検・監査

ルールを作っただけでは十分ではありません。定期的な点検・監査により、ルールが適切に守られているか、問題が発生していないかを確認し、継続的な改善を図ることが重要です。

**月次点検項目**：
- データアクセスログの確認
- 不適切な利用の有無確認
- セキュリティ設定の確認
- バックアップ状況の確認

**年次監査項目**：
- データ取り扱い方針の見直し
- 教職員の理解度確認
- システムのセキュリティ監査
- 保護者・地域からの意見収集

#### 3. インシデント対応体制

データに関する問題が発生した時に、迅速かつ適切に対応するための体制を事前に整備しておくことが重要です。レベル別の対応手順を明確にしておくことで、混乱を防ぎ、被害を最小限に抑えることができます。

**レベル1（軽微）**：個人の操作ミス等
- 担当者による記録・報告
- 必要に応じた当事者への説明

**レベル2（中程度）**：システム障害、小規模な情報漏洩等
- 管理職への報告
- 影響範囲の調査
- 再発防止策の検討

**レベル3（重大）**：大規模な情報漏洩、システム侵害等
- 教育委員会への即座の報告
- 外部専門家の助言要請
- 保護者・地域への説明
- メディア対応の検討

### 継続的な改善体制

データガバナンスは一度構築すれば終わりではありません。教育環境や技術の変化、新たな課題の発見に応じて、継続的に改善していく必要があります。PDCAサイクルを活用した体系的な改善アプローチが効果的です。

- 目標設定と指標の明確化

**Do（実行）**：
- 計画に基づくデータ活用の実施
- 教職員研修の実施
- システム・体制の運用

**Check（評価）**：
- 定期的な効果測定
- インシデントの分析
- 教職員・保護者の意見収集

**Act（改善）**：
