# 条件付きアクセスポリシー15項目詳細設定

## はじめにで約束した「条件付きアクセスポリシー15項目の詳細内容」

以下の15項目の条件付きアクセスポリシーを必須として調達仕様書に記載すること。

### 1. 基本多要素認証ポリシー
- **対象**: すべてのユーザー
- **条件**: 任意の場所からのサインイン
- **制御**: MFA必須
- **例外**: なし

### 2. 管理者アカウント強化ポリシー
- **対象**: 全管理者ロール
- **条件**: 任意の場所・デバイス
- **制御**: MFA + 準拠デバイス必須
- **セッション**: サインイン頻度 4時間

### 3. 高リスクサインイン阻止ポリシー
- **対象**: すべてのユーザー
- **条件**: サインインリスク = 高
- **制御**: アクセス拒否
- **例外**: IT部門のみパスワード変更で許可

### 4. 高リスクユーザー保護ポリシー
- **対象**: すべてのユーザー
- **条件**: ユーザーリスク = 高
- **制御**: パスワード変更必須
- **監視**: 24時間継続監視

### 5. 地理的制限ポリシー
- **対象**: すべてのユーザー
- **条件**: 日本国外からのアクセス
- **制御**: アクセス拒否
- **例外**: 事前承認済み出張者のみ

### 6. 非準拠デバイス制限ポリシー
- **対象**: すべてのユーザー
- **条件**: 非準拠デバイス
- **制御**: アクセス拒否
- **適用**: 校務データへのアクセス時

### 7. ゲストアクセス制限ポリシー
- **対象**: ゲストユーザー
- **条件**: 任意の場所・デバイス
- **制御**: 指定アプリケーションのみ許可
- **セッション**: 8時間で再認証

### 8. レガシー認証ブロックポリシー
- **対象**: すべてのユーザー
- **条件**: レガシー認証プロトコル
- **制御**: アクセス拒否
- **例外**: なし（完全ブロック）

### 9. 校務時間外アクセス制限ポリシー
- **対象**: 教職員
- **条件**: 平日18時-翌8時、土日祝日
- **制御**: 管理者承認必須
- **監視**: 時間外アクセスログ記録

### 10. 機密データアクセス強化ポリシー
- **対象**: すべてのユーザー
- **条件**: 成績・個人情報アクセス時
- **制御**: MFA + 準拠デバイス + 承認済み場所
- **セッション**: 継続サインイン無効

### 11. モバイルデバイス制限ポリシー
- **対象**: すべてのユーザー
- **条件**: iOS/Android デバイス
- **制御**: アプリ保護ポリシー必須
- **要件**: Intune 登録済みデバイスのみ

### 12. SharePoint/OneDrive 制限ポリシー
- **対象**: すべてのユーザー
- **条件**: SharePoint/OneDrive アクセス
- **制御**: 準拠デバイス必須
- **セッション**: ダウンロード制限有効

### 13. Teams 会議セキュリティポリシー
- **対象**: すべてのユーザー
- **条件**: Teams 外部会議参加時
- **制御**: MFA + ロビー待機強制
- **監視**: 外部参加者ログ記録

### 14. 一括データ操作制限ポリシー
- **対象**: すべてのユーザー
- **条件**: 大量データダウンロード検知時
- **制御**: 管理者承認必須
- **しきい値**: 100ファイル以上または100MB以上

### 15. 緊急時アクセス管理ポリシー
- **対象**: 緊急アクセスアカウント
- **条件**: 緊急時のみ有効化
- **制御**: 管理者2名承認 + 時間制限
- **監視**: 全操作ログ記録 + リアルタイム通知

## 調達仕様書への記載例

```
【条件付きアクセス要件】
Microsoft 365環境において、以下の15項目の条件付きアクセスポリシーを実装すること。

1. 基本多要素認証ポリシー：全ユーザーMFA必須
2. 管理者アカウント強化ポリシー：MFA + 準拠デバイス必須
3. 高リスクサインイン阻止ポリシー：自動ブロック
4. 高リスクユーザー保護ポリシー：パスワード変更強制
5. 地理的制限ポリシー：日本国外アクセス拒否
6. 非準拠デバイス制限ポリシー：非準拠端末拒否
7. ゲストアクセス制限ポリシー：限定アプリのみ許可
8. レガシー認証ブロックポリシー：完全ブロック
9. 校務時間外アクセス制限ポリシー：承認制アクセス
10. 機密データアクセス強化ポリシー：多層認証
11. モバイルデバイス制限ポリシー：Intune管理下のみ
12. SharePoint/OneDrive制限ポリシー：準拠デバイス必須
13. Teams会議セキュリティポリシー：外部参加者制限
14. 一括データ操作制限ポリシー：大量操作の承認制
15. 緊急時アクセス管理ポリシー：2名承認 + 時間制限

各ポリシーの詳細設定値、適用対象、例外条件を仕様書に明記すること。
```
