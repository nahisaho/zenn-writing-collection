# NIST SP800-207準拠チェックリスト
## 教育機関向け Zero Trust Architecture 実装確認表

### 使用方法
- 各項目について現状を確認し、✅（実装済み）、⚠️（部分実装）、❌（未実装）で評価
- すべての項目が✅になるまで実装を継続
- 定期的（四半期ごと）に再評価を実施

---

## 🎯 **原則1：すべてのデータソースとコンピューティングサービスをリソースとみなす**

### 1.1 リソース識別・分類
- [ ] 校務用端末すべてをアセット台帳に記録している
- [ ] プリンター・複合機を管理対象に含んでいる
- [ ] ネットワーク機器（ルーター、スイッチ、AP）を管理している
- [ ] 校務支援システムの全コンポーネントを管理している
- [ ] Microsoft 365のすべてのアカウントを管理している
- [ ] クラウドサービス（SaaS、PaaS）を管理対象に含んでいる

### 1.2 リソース監視
- [ ] 未登録デバイスの自動検出機能が動作している
- [ ] 未承認デバイスのネットワーク接続を自動遮断している
- [ ] アセット台帳の更新頻度が日次以上である
- [ ] 台帳と実際の差分を自動検出している
- [ ] 新規デバイス接続時の承認フローが定義されている

### 1.3 ライフサイクル管理
- [ ] 端末廃棄時のデータ完全消去手順が確立されている
- [ ] 退職者の端末・アカウント削除手順が自動化されている
- [ ] 定期的なアセット棚卸し（年2回以上）を実施している
- [ ] ソフトウェアライセンス管理が適切に行われている

## 🌐 **原則2：ネットワークの場所に関係なく、すべての通信を保護する**

### 2.1 通信暗号化
- [ ] すべてのネットワーク通信でTLS 1.3以上を使用している
- [ ] 内部ネットワーク通信も暗号化している
- [ ] VPN接続でIPsec または同等の暗号化を使用している
- [ ] Wi-Fi通信でWPA3を使用している
- [ ] メール通信でS/MIMEまたはPGP暗号化を実装している

### 2.2 ネットワークセグメンテーション
- [ ] 校務ネットワークと学習系ネットワークを分離している
- [ ] マイクロセグメンテーションを実装している
- [ ] VLAN分離が適切に設定されている
- [ ] ゲストネットワークを分離している
- [ ] IoTデバイス専用セグメントを設けている

### 2.3 トラフィック監視
- [ ] すべてのネットワークトラフィックを監視している
- [ ] 異常トラフィックの自動検知機能がある
- [ ] DPI（Deep Packet Inspection）を実装している
- [ ] ログの7年間保存を実施している
- [ ] リアルタイム脅威検知システムが稼働している

**評価スコア: ___/15項目**

## 🔐 **原則3：企業リソースへのアクセスをセッション単位で許可する**

### 3.1 セッション管理
- [ ] すべてのセッションで多要素認証（MFA）を強制している
- [ ] セッションタイムアウト設定が適切である（8時間以内）
- [ ] 同時セッション数を制限している
- [ ] 休眠セッションを自動終了している
- [ ] セッション情報を暗号化している

### 3.2 条件付きアクセス
- [ ] Microsoft Entra ID条件付きアクセスで15ポリシー以上を設定している
- [ ] デバイス準拠性を確認している
- [ ] 地理的制限を設定している（日本国外からの制限）
- [ ] 時間外アクセス制限を設定している
- [ ] リスクベースアクセス制御を実装している

### 3.3 最小権限アクセス
- [ ] Just-In-Time（JIT）アクセスを実装している
- [ ] 特権アクセス管理（PAM）システムを導入している
- [ ] アクセス権の定期的な見直しを実施している（四半期ごと）
- [ ] 未使用アカウントの自動無効化を実施している
- [ ] 緊急時アクセス手順が整備されている
