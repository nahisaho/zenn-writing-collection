# Microsoft Secure Score改善項目チェックリスト

## 教育機関向けセキュリティスコア向上の完全ガイド

### 使用方法
- 現在のSecure Scoreを確認し、目標スコアを設定
- 各改善項目について実装状況をチェック（✅実装済み / ⚠️部分実装 / ❌未実装）
- 優先度と実装難易度を考慮して改善計画を策定
- 段階的な実装により継続的なスコア向上を実現

## 📊 **Microsoft Secure Score基本情報**

### スコア概要
- **スコア範囲**: 0-100点（小数点表示）
- **更新頻度**: リアルタイム更新、日次同期
- **算出方法**: 実装済み推奨アクションの割合に基づく
- **カテゴリ**: Identity（ID管理）、Data（データ保護）、Apps（アプリケーション）、Devices（デバイス）、Infrastructure（インフラストラクチャ）

### 教育機関推奨目標スコア
- **小規模教育機関（職員数50名以下）**: 50-60点
- **中規模教育機関（職員数50-200名）**: 60-70点
- **大規模教育機関（職員数200名以上）**: 70-80点
- **研究機関・大学**: 75-85点

## ⚠️ **実装時の重要な注意事項**

### 技術的制限・前提条件

#### MFA・認証関連
- **認証強度と従来MFA**: 同一ポリシーで併用不可
- **パスワードレス認証**: Windows Hello、FIDO2キー、Microsoft Authenticatorアプリが必要
- **条件付きアクセス**: Entra ID P1以上必須

#### デバイス管理関連
- **BitLocker要件**: UEFI BIOS、TPM 2.0必須
- **Windows要件**: Windows 10 Pro以上、Windows 11
- **コンプライアンス測定**: デバイス再起動が必要な場合あり
- **MDM共存**: 既存のGPOとの設定競合に注意

#### メール保護関連
- **Safe Attachments**: 添付ファイル検査により配信遅延の可能性
- **Safe Links**: URL書き換えによるユーザビリティ影響
- **DLP**: 誤検知による業務メール阻害のリスク

### 運用上の考慮事項

#### ユーザー影響
- **MFA導入**: 段階的展開と十分なユーザー教育が必要
- **デバイス制限**: 私用デバイスの業務利用制限
- **メール制限**: 正当な添付ファイル・URLの阻害リスク

#### 管理負荷
- **スコア更新**: リアルタイム更新・日次同期を考慮
- **継続的監視**: 設定ドリフト防止のための定期確認
- **ユーザーサポート**: 新機能に関する問い合わせ増加
