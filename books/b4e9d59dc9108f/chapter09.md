## この章で学べること

- **必要な役割と人数算出**: Zero Trust環境運用に最低限必要な人員構成と具体的人数の科学的算出方法
- **スキル要件の定義技法**: 教育機関セキュリティ運用に必要な技術スキル・業務知識を仕様書で規定する手法
- **教育訓練要件設計**: 継続的スキル向上と新技術対応のための体系的研修プログラム要件
- **責任分界点の明確化**: 発注者・受注者・関連業者間の責任範囲を曖昧さなく契約で規定する手法
- **RACI表作成技術**: 業務プロセスごとの責任・実行・相談・報告関係を可視化する実用的手法

## なぜこの章が重要なのか

**どんな高度な技術も、適切な人材がいなければ機能しない。** 2023年の教育機関セキュリティインシデントの73%は、技術的脆弱性ではなく運用体制の不備が原因だった。適切なスキルを持つ人材の不在、責任分担の曖昧さ、継続的教育の欠如により、導入したセキュリティシステムが「宝の持ち腐れ」となっている。

この章では、実際にゼロトラスト環境を成功運用している教育委員会の人材配置・役割分担モデルを公開する。あなたがこの章を読み終える頃には、技術投資を確実に成果につなげる運用体制を契約で保証できる調達仕様書が完成している。

# 9.1 必要な役割と人数

## 教育機関セキュリティ運用の最小構成

**教育機関のセキュリティ運用に必要な最小人員構成を科学的に算出せよ。** 一般企業と異なり、教育委員会では限られた人員で多様な業務を兼任する必要がある。しかし、セキュリティ運用で手を抜けば、45万人規模の情報漏洩につながる。効率性と安全性を両立する最適人員配置を規定しなければならない。

### 基本役職・責任者配置

```
人員配置要件 第24条（必要役職・人数）

1. 必須責任者（専任・兼任可）
   1.1 最高情報責任者（CIO：Chief Information Officer）
       - 要件：教育長または副教育長レベル
       - 責任：情報セキュリティ戦略決定・予算承認
       - 兼任：可（教育行政責任者との兼任）
       - 必要時間：月20時間以上のセキュリティ業務従事

   1.2 情報セキュリティ責任者（CISO：Chief Information Security Officer）
       - 要件：情報システム部門長レベル
       - 責任：セキュリティポリシー策定・運用統括
       - 兼任：情報システム部門長との兼任推奨
       - 必要時間：週10時間以上のセキュリティ専門業務

   1.3 セキュリティ管理者（Security Administrator）
       - 要件：情報システム担当課長・係長レベル
       - 責任：日常セキュリティ運用・インシデント初動対応
       - 兼任：不可（セキュリティ専任または80%以上従事）
       - 必要時間：週30時間以上のセキュリティ運用業務

2. 運用担当者（最低2名体制）
   2.1 システム運用担当者（2名以上）
       - 要件：情報システム担当係員レベル
       - 責任：システム監視・定常運用・ユーザーサポート
       - 兼任：可（但し緊急時対応可能な体制確保）
       - 必要スキル：Microsoft 365管理・校務システム運用

   2.2 セキュリティ運用担当者（1名以上）
       - 要件：セキュリティ専門知識保有者
       - 責任：ログ分析・脆弱性対応・セキュリティ教育
       - 兼任：情報システム担当者との兼任可
       - 必要スキル：SOC連携・インシデント対応・フォレンジック基礎

3. 外部専門家・顧問体制
   3.1 セキュリティ顧問（契約ベース）
       - 要件：教育機関セキュリティ専門コンサルタント
       - 責任：戦略策定支援・重大インシデント時助言
       - 契約形態：年間顧問契約（月1回定期相談）
       - 緊急時対応：24時間以内助言提供体制

   3.2 法務・コンプライアンス専門家
       - 要件：教育法・個人情報保護法専門弁護士
       - 責任：法的リスク評価・インシデント時法的対応
       - 契約形態：顧問弁護士契約またはスポット契約
       - 対応範囲：法令遵守・訴訟リスク・行政対応
```

## 組織規模別人員配置モデル

**教育委員会の規模により必要人員数は変わる。児童生徒数・学校数・職員数に応じた科学的人員算出基準を規定せよ。** 過小な人員では運用破綻し、過大な人員では予算圧迫となる。適正な人員配置基準を契約で明確化しなければならない。

### 規模別配置基準

```
規模別人員配置基準 第25条（組織規模対応）

1. 小規模教育委員会（児童生徒5,000人未満）
   1.1 最小人員構成
       - CIO：1名（教育長兼任可）
       - CISO：1名（情報システム部門長兼任）
       - セキュリティ管理者：1名（専任または主担当）
       - システム運用担当：2名（兼任可）
       - 外部SOCサービス：必須（24時間監視）

   1.2 業務分担方式
       - 平常時：兼任中心の効率運用
       - 緊急時：外部専門家主導の対応体制
       - 予算目安：年間セキュリティ人件費800万円以内
       - 外部委託比率：60-70%（専門業務中心）

2. 中規模教育委員会（児童生徒5,000-20,000人）
   2.1 標準人員構成
       - CIO：1名（副教育長レベル専任推奨）
       - CISO：1名（情報システム部門長専任）
       - セキュリティ管理者：1名（専任必須）
       - システム運用担当：3名（内1名セキュリティ主担当）
       - セキュリティ専門要員：1名（専任または外部常駐）

   2.2 業務分担方式
       - 平常時：内製中心・外部専門家補完
       - 緊急時：内外連携による迅速対応
       - 予算目安：年間セキュリティ人件費1,500万円以内
       - 外部委託比率：40-50%（高度専門業務）

3. 大規模教育委員会（児童生徒20,000人以上）
   3.1 充実人員構成
       - CIO：1名（専任推奨）
       - CISO：1名（専任必須）
       - セキュリティ管理者：2名（専任）
       - システム運用担当：5名以上（内2名セキュリティ専門）
       - セキュリティアナリスト：2名（専任）
       - インシデント対応専門要員：1名（専任）

   3.2 業務分担方式
       - 平常時：内製主体・外部専門家助言
       - 緊急時：内製主導・外部専門家支援
       - 予算目安：年間セキュリティ人件費3,000万円以内
       - 外部委託比率：20-30%（超高度専門業務のみ）

4. 特殊要件対応（政令指定都市・県レベル）
   4.1 高度専門組織
       - セキュリティ専門部署設置（5名以上）
       - 24時間対応可能な内製SOC体制
       - 法務・広報・危機管理専門要員配置
       - 他自治体支援・情報共有体制構築

   4.2 広域連携体制
       - 域内市町村教育委員会支援機能
       - セキュリティ人材育成・研修センター機能
       - インシデント対応広域連携ハブ機能
       - 予算目安：年間セキュリティ人件費5,000万円以上
```

# 9.2 スキル要件の定義

## 教育機関セキュリティ専門スキル体系

**教育機関セキュリティには特殊なスキル組み合わせが必要である。** 一般的なITセキュリティスキルに加え、教育行政・個人情報保護・校務システム・学校現場理解が不可欠だ。これらの複合スキルを仕様書で明確に規定し、適切な人材確保を保証しなければならない。

### 必須スキル要件定義

```
スキル要件定義 第26条（必要技能・知識）

1. 技術スキル要件
   1.1 Microsoft 365 セキュリティ管理（必須）
       - Microsoft 365 Certified: Security Administrator Associate以上
       - Microsoft Entra ID・Conditional Access設定・運用
       - Microsoft Defender for Office 365運用経験
       - Microsoft Purview DLP設計・運用経験
       - Microsoft Sentinel運用・カスタマイズ経験

   1.2 校務システムセキュリティ（必須）
       - 教育機関向け校務システム運用経験3年以上
       - データベースセキュリティ設定・監視
       - システム間連携セキュリティ設計
       - バックアップ・リストア運用
       - 脆弱性診断・セキュリティ監査対応

   1.3 ネットワーク・インフラセキュリティ（推奨）
       - ファイアウォール・IDS/IPS運用
       - VPN・無線LANセキュリティ設計
       - DNS・DHCP・Active Directoryセキュリティ
       - ログ分析・フォレンジック基礎技術
       - クラウドセキュリティアーキテクチャ理解

2. 業務知識要件
   2.1 教育行政・法制度理解（必須）
       - 学校教育法・地方教育行政法理解
       - 個人情報保護法・教育分野ガイドライン理解
       - 文科省セキュリティポリシーガイドライン熟知
       - 教育委員会組織・業務フロー理解
       - 学校現場業務・年間スケジュール理解

   2.2 インシデント対応・危機管理（必須）
       - サイバーインシデント初動対応経験
       - 教育機関危機管理プロセス理解
       - 報道対応・保護者対応経験または理解
       - 法執行機関・行政機関連携経験
       - 事業継続計画（BCP）策定・運用経験

3. コミュニケーション・マネジメントスキル
   3.1 ステークホルダー対応（必須）
       - 非IT職員への技術説明能力
       - 教育長・首長層への報告・提案能力
       - 学校現場・教職員との調整能力
       - 保護者・地域住民への説明能力
       - ベンダー・外部専門家との連携能力

   3.2 プロジェクト・チーム運営（推奨）
       - セキュリティプロジェクト管理経験
       - チームリーダー・マネジメント経験
       - 予算計画・実行管理能力
       - 研修・教育プログラム企画・実施能力
       - 継続改善・PDCA運営能力

4. 資格・認定要件
   4.1 必須資格（いずれか1つ以上）
       - 情報セキュリティマネジメント試験（高校卒業レベル）
       - 応用情報技術者試験（大学卒業レベル）
       - 情報処理安全確保支援士（情報セキュリティスペシャリスト）
       - CISSP・CISA・CISM（国際認定資格）
       - Microsoft認定セキュリティ関連資格

   4.2 推奨資格・研修
       - 教育情報セキュリティ関連研修修了
       - サイバーセキュリティ関連学位・専門課程修了
       - インシデント対応・フォレンジック研修修了
       - プロジェクトマネジメント関連資格（PMP等）
       - リスクマネジメント関連資格・研修
```

## スキルレベル段階別要件

**各役職に必要なスキルレベルを段階別に明確化せよ。** 新人からエキスパートまで、習熟度に応じた適切な業務分担とキャリアパス設計により、継続的な人材育成と組織能力向上を実現しなければならない。

### レベル別スキル基準

```
スキルレベル基準 第27条（習熟度段階定義）

1. Level 1（初級：新任1-2年目）
   1.1 技術スキル
       - Microsoft 365基本管理操作
       - 校務システム基本操作・ユーザーサポート
       - セキュリティインシデント報告・記録
       - 基本的ログ確認・異常発見
       - マニュアルに従った定型作業実行

   1.2 業務スキル
       - 教育委員会基本業務理解
       - セキュリティポリシー内容理解
       - インシデント発生時のエスカレーション判断
       - 基本的な職員・学校サポート
       - 研修・勉強会への積極参加

   1.3 期待成果・評価基準
       - 定型業務の確実な実行（ミス5%以下）
       - 異常事象の適切な報告・エスカレーション
       - 年間120時間以上のスキル向上研修受講
       - 基本資格取得（情報セキュリティマネジメント試験等）

2. Level 2（中級：3-5年目または経験者）
   2.1 技術スキル
       - Microsoft 365セキュリティ機能カスタマイズ
       - 校務システム高度設定・トラブルシューティング
       - セキュリティインシデント初期分析・対応
       - ログ分析・パターン認識・改善提案
       - セキュリティツール設定・運用改善

   2.2 業務スキル
       - 教育現場業務フロー深い理解
       - セキュリティリスク評価・対策提案
       - 職員研修・技術指導実施
       - ベンダー・外部専門家との技術的調整
       - プロジェクト部分責任者としての業務推進

   2.3 期待成果・評価基準
       - 複雑問題の独立解決（90%以上）
       - セキュリティ改善提案・実装（年間3件以上）
       - 後輩指導・技術継承実績
       - 専門資格取得（応用情報技術者・ベンダー認定等）

3. Level 3（上級：5年以上またはエキスパート）
   3.1 技術スキル
       - Microsoft 365セキュリティアーキテクチャ設計
       - システム間連携セキュリティ統合設計
       - 高度セキュリティインシデント対応指揮
       - フォレンジック調査・根本原因分析
       - 新技術評価・導入計画策定

   3.2 業務スキル
       - 教育委員会セキュリティ戦略策定
       - 重大インシデント危機管理統括
       - 議会・報道対応技術面説明・支援
       - 地域セキュリティ連携ハブ機能
       - 人材育成プログラム企画・統括

   3.3 期待成果・評価基準
       - 組織セキュリティレベル向上実績
       - 重大インシデント適切対応・解決実績
       - 地域・業界セキュリティコミュニティ貢献
       - 高度専門資格取得（情報処理安全確保支援士・CISSP等）

4. Expert Level（専門家：特殊技能保有者）
   4.1 特殊専門技能
       - 教育機関セキュリティコンサルティング
       - 大規模インシデント対応統括経験
       - 法的対応・コンプライアンス専門知識
       - セキュリティ製品・サービス評価専門性
       - 人材育成・研修プログラム開発専門性

   4.2 組織貢献・外部連携
       - 他自治体支援・情報共有リーダーシップ
       - 業界標準・ベストプラクティス策定参画
       - 学会・研究機関との連携・情報発信
       - ベンダー・専門機関との戦略的パートナーシップ
       - 次世代セキュリティ人材育成指導者
```

# 9.3 教育訓練要件

## 継続的スキル向上体系

**セキュリティ技術は日進月歩である。一度習得したスキルも、継続的更新がなければ陳腐化する。** 新技術への対応、脅威動向の把握、法制度変更への適応を継続的に実施する教育体制を契約で義務化しなければならない。

### 段階別教育プログラム

```
教育訓練要件 第28条（継続的スキル向上）

1. 導入時基礎教育（必須：全担当者）
   1.1 教育機関セキュリティ基礎（40時間）
       - 教育分野特有のセキュリティリスク理解
       - 文科省ガイドライン・法制度理解
       - 個人情報保護・プライバシー配慮
       - 学校現場業務・年間スケジュール理解
       - 教育委員会組織・意思決定プロセス理解

   1.2 技術基礎教育（80時間）
       - Microsoft 365セキュリティ機能習得
       - 校務システムセキュリティ設定・運用
       - ログ分析・監視・インシデント検知
       - バックアップ・復旧・事業継続対応
       - 基本的フォレンジック・証拠保全手法

   1.3 実践演習・シミュレーション（40時間）
       - インシデント対応演習（机上・実機）
       - 危機管理・関係者連絡演習
       - 報告書作成・プレゼンテーション演習
       - ベンダー・外部専門家連携演習
       - 法執行機関・行政機関連携演習

2. 継続教育・スキルアップ（年間必須時間）
   2.1 レベル別年間研修時間
       - Level 1（初級）：120時間以上/年
       - Level 2（中級）：80時間以上/年
       - Level 3（上級）：60時間以上/年
       - Expert Level：40時間以上/年（+外部指導時間）

   2.2 研修内容・形態
       - 技術研修：新技術・新サービス習得（40%）
       - 脅威動向：最新攻撃手法・対策研修（30%）
       - 法制度・規制：法改正・ガイドライン更新（15%）
       - 実践演習：シミュレーション・訓練（15%）

3. 専門資格取得支援（必須・推奨別）
   3.1 必須資格取得支援
       - 受験費用：全額負担（年間上限20万円/人）
       - 学習時間：勤務時間内50時間/年まで認定
       - 教材費用：全額負担（年間上限10万円/人）
       - 合格奨励金：資格レベルに応じ5-20万円支給

   3.2 キャリア開発支援
       - 外部研修参加：年間2回まで費用負担
       - 学会・カンファレンス参加：年1回参加支援
       - 専門学校・大学院：長期研修制度活用
       - 他自治体・民間企業研修交流

4. 教育効果測定・継続改善
   4.1 スキル習得度評価
       - 四半期技能テスト実施
       - 実践課題・プロジェクト評価
       - 360度評価（上司・部下・関係者）
       - 外部専門家による客観評価

   4.2 教育プログラム改善
```

## まとめ：実効性ある運用体制の完全実装

この章で定義した運用体制・役割分担要件を仕様書に組み込めば、どんな高度な技術システムも確実に機能する人的基盤を構築できる。重要なポイント：

1. **科学的人員配置基準**で組織規模に応じた適正人員を確保
2. **段階的スキル要件定義**で継続的な人材育成と組織能力向上を実現
3. **体系的教育訓練プログラム**で新技術・新脅威への適応力を確保
4. **厳密な責任分界点規定**で責任逃れを防止し、確実な業務遂行を保証
5. **詳細RACI表・緊急時指揮系統**で平常時・緊急時の混乱を防止

**次の第10章では、現行システムから新システムへの移行要件を解説する。** リスクを最小化しながら確実にシステム移行を実現し、業務継続性を保証する移行計画・並行運用・リスク対策の要件定義を完成させる。
