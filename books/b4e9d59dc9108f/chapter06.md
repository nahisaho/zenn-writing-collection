**この章で学べること**：
- Microsoft Intuneを活用した教育機関向けデバイス管理の完全要件定義
- Microsoft Defender for Endpointの教育現場特化設定要件
- BYOD（私物端末持込）環境での安全性確保要件とポリシー設計
- パッチ管理とソフトウェア配布の自動化要件
- エンドポイント設定の具体的数値要件とセキュリティ基準値

**なぜこの章が重要なのか**：
第5章でMicrosoft 365のクラウド要件を定義したが、エンドポイント（PC・タブレット・スマートフォン）のセキュリティが脆弱では、クラウドの防御は無意味となる。教育機関情報漏洩の87%がエンドポイント経由で発生している現実を直視せよ。本章で学ぶエンドポイント要件の完全定義こそが、ゼロトラストの最前線防御を実現する。

# 6.1 Microsoft Intune 必須設定要件

## 「MDMは設定しています」では子どもたちを守れない

**多くの教育委員会が陥る罠**：
- Intune で MDM 登録だけ実施
- 基本的なポリシーのみ適用
- 教育機関特有の要件を無視
- 設定の継続的管理を怠る
- 効果測定を実施しない

**現実を知れ**：MDM登録率100%でも、不適切な設定により個人情報漏洩は起き続けている。

# 6.2 Microsoft Defender for Endpoint 要件

## EDRなくしてゼロトラストなし

**従来型アンチウイルスの限界**：
- 既知マルウェアの検出のみ
- ふるまい分析の精度不足
- ネットワーク攻撃の見逃し
- インシデント対応情報の不足
- 横展開攻撃の検出困難

**Microsoft Defender for Endpoint が必須な理由**：リアルタイムの行動分析とクラウドAIによる未知脅威検出が、教育機関を標的とする高度な攻撃を阻止する唯一の手段である。

### EDR（Endpoint Detection and Response）要件

**調達仕様書記載例**：
```
【必須要件】
Microsoft Defender for Endpointを以下により実装すること。

■ 基本機能要件

- ふるまいベース検出：有効必須
- 機械学習検出：有効必須
- ネットワーク保護：ブロックモード必須
- 制御されたフォルダーアクセス：有効必須

■ 高度脅威対策
【次世代保護】
- クラウド配信保護：有効・高速化設定
- Microsoft Defender SmartScreen：すべてのアプリで有効
- Microsoft Defender Application Guard：Edge・Office統合
- Microsoft Defender Credential Guard：対応端末で有効

【エンドポイント検出・応答】
- 自動調査・修復：完全自動化

- Deep Analysis：疑わしいファイル自動送信

■ Microsoft Defender XDRとの統合
- Microsoft 365 Defender：統合ダッシュボード

# 6.3 BYOD対応要件

## 私物端末と業務データの完全分離

**BYOD導入で陥る致命的な誤解**：
「個人の端末だから、そこまで厳しく管理できない」

**現実を直視せよ**：私物端末経由の情報漏洩は、組織支給端末の3.7倍発生している。「管理しにくい」は理由にならない。完全に管理できない端末は、校務データにアクセスさせてはならない。

### BYOD許可基準の厳格化

**調達仕様書記載例**：

■ 端末許可基準

- OS：iOS 16.0/iPadOS 16.0以降
- 管理：Supervised Mode必須
- ストレージ：暗号化有効必須
- 脱獄：検出した場合即座アクセス禁止

- TPM：2.0以降搭載必須

- 警察届出：義務化

# 6.4 パッチ管理要件

## 「自動更新ON」では教育現場は守れない

**教育機関特有のパッチ管理課題**：
- 授業中の自動再起動による授業中断
- 夏休み等長期休暇中のパッチ適用遅れ
- 校務システムとの互換性問題
- 限られたメンテナンス時間窓
- IT管理者不在時の対応困難

**解決策**：Microsoft Intune の高度なパッチ管理機能により、教育現場の制約を考慮した計画的パッチ適用を実現する。

### Windows Update の教育機関最適化

# 6.5 設定値一覧：具体的な数値要件

## 曖昧な「適切に設定」を数値化せよ

**多くの仕様書が犯す致命的ミス**：
「セキュリティを適切に設定すること」
「十分なレベルのパスワードを設定すること」
「必要に応じてタイムアウトを設定すること」

**数値なき要件は要件にあらず**。ベンダーの主観に委ねた瞬間、セキュリティホールが生まれる。

### パスワード・認証設定値

**調達仕様書記載例**：
```
【必須要件】
認証設定を以下の数値により実装すること。

■ パスワード要件
【Windows端末】
- 最小長：12文字以上
- 複雑性：大小英字・数字・記号必須
- 履歴：過去24個記録・再利用禁止
- 有効期限：90日間
- アカウントロックアウト：5回失敗で30分間

【モバイル端末PIN】
- 最小長：6桁以上
- 複雑性：同一数字3連続禁止
- 有効期限：180日間
- 失敗回数：10回でワイプ実行
- 生体認証併用：推奨

■ セッション・タイムアウト設定
- 非アクティブ時間：15分でロック
- セッションタイムアウト：8時間で強制ログアウト
- スクリーンセーバー：5分で起動・パスワード要求
- USB Auto Play：完全無効
- ネットワーク共有：管理者許可のみ

■ 暗号化設定値
- BitLocker：AES 256bit・TPM+PIN
- FileVault：AES 256bit・リカバリキー管理
- Android暗号化：AES 256bit強制
- SSL/TLS：TLS 1.3以降のみ許可
- VPN暗号化：AES 256bit・Perfect Forward Secrecy
```

### ネットワーク・ファイアウォール設定値

**調達仕様書記載例**：
```
【必須要件】
ネットワークセキュリティを以下の数値設定で実現すること。

■ ファイアウォール設定
【Windows Defender Firewall】

- Private Profile：有効・ブロック既定
- Public Profile：有効・ブロック既定
- 着信接続：明示許可のみ
- 発信接続：ホワイトリスト方式

【許可ポート（最小限）】
- HTTP：80番（リダイレクトのみ）
- HTTPS：443番（校務・Microsoft 365）
- DNS：53番（組織管理サーバーのみ）
- NTP：123番（組織タイムサーバーのみ）

■ 禁止プロトコル・サービス
- FTP：21番完全禁止
- Telnet：23番完全禁止
- SMTP：25番（直接送信禁止）
- POP3：110番（暗号化なし禁止）
- SNMP：161番（v1/v2c禁止）
- NetBIOS：137-139番禁止

■ 無線LAN設定値
【WPA3 Enterprise必須】
- 暗号化：WPA3-Enterprise・AES-256
- 認証：802.1X・EAP-TLS
- 証明書：組織CA発行必須
