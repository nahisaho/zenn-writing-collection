# はじめに

このテンプレート集は、教育理想タイプ別・校種別に整理されたAI活用プロンプトを提供します。コピー&ペーストで使用できるよう、実用性を重視して作成されています。

### 使い方

1. **自分の理想タイプと校種に該当するセクションを確認**
2. **目的に応じてテンプレートを選択**
3. **【　】内を具体的な内容に置き換える**
4. **AIツール（ChatGPT、Claude、Copilot等）にコピー&ペースト**
5. **結果をもとに授業や指導に活用**

```

```
