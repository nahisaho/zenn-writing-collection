# Writing Style Guide - 教師の理想を形にする

## 対象読者プロファイル

### 主要読者層
- **小学校教員**: 6-12歳の児童を指導、基礎教育と人格形成に携わる
- **中学校教員**: 13-15歳の生徒を指導、思春期の生徒と向き合う
- **高等学校教員**: 16-18歳の生徒を指導、進路指導と専門教育を担当

### 読者の特徴
- 教育現場での実践経験を持つ
- 日々の業務に追われ、まとまった読書時間が限られている
- 理論より実践的な知識を求める傾向がある
- 生徒の成長と変化を最優先に考える
- テクノロジーへの習熟度には個人差がある

## 文章スタイルガイドライン

### 1. 基本原則

#### 1.1 共感と尊重
- 教師の日常的な悩みや課題に寄り添う表現を使用
- 「～すべきである」より「～することができます」という可能性を示す表現
- 教師の専門性と経験を尊重した書き方

#### 1.2 具体性と実践性
- 抽象的な理論は必ず具体的な教室場面と結びつける
- 「例えば、〇年生の授業で...」という具体例を多用
- 明日から使える実践的なヒントを各節に含める

#### 1.3 段階的アプローチ
- 初心者から経験者まで対応できる多層的な内容構成
- 「まずは...」「次に...」「さらに...」という段階的な説明
- スモールステップで実践できる内容を重視

### 2. 文体の制約

#### 2.1 使用する文体
- **敬語**: 丁寧語を基本とし、読者を尊重する姿勢を示す
- **例**: 「～できます」「～でしょう」「～かもしれません」
- **親しみやすさ**: 堅すぎず、かといってくだけすぎない中間的な文体

#### 2.2 避けるべき表現
- ❌ 上から目線の断定的表現（「～しなければならない」）
- ❌ 専門用語の羅列（使用する場合は必ず平易な説明を付加）
- ❌ カタカナ語の過度な使用（必要最小限に留める）
- ❌ 否定的・批判的な表現（建設的な代替案を示す）

#### 2.3 推奨する表現
- ✅ 「～という方法もあります」（選択肢の提示）
- ✅ 「多くの先生方が～と感じています」（共感の表現）
- ✅ 「実践してみると～ということがわかりました」（経験の共有）
- ✅ 「一緒に考えてみましょう」（協働的な姿勢）

### 3. 構造的な制約

#### 3.1 章の構成
```
1. 冒頭：現場の声や共感できるエピソードから始める
2. 理論：必要最小限の理論的背景を平易に説明
3. 実践：具体的な実践方法を段階的に提示
4. 事例：実際の教室での成功事例・失敗事例を紹介
5. まとめ：要点整理と次のステップへの橋渡し
```

#### 3.2 段落の長さ
- 1段落は3-5文程度に収める
- 長い説明は箇条書きや図表を活用
- 視覚的な読みやすさを重視

#### 3.3 見出しの付け方
- 疑問形を効果的に使用（「なぜ〜なのか？」）
- 行動を促す表現（「〜を始めよう」）
- 期待感を持たせる表現（「〜で変わる教室」）

### 4. 具体例とエピソード

#### 4.1 教室場面の描写
- 学年と教科を明示した具体的なシーン
- 生徒の反応や変化を含める
- 失敗例も恐れずに共有（学びのポイントとして）

#### 4.2 会話例の使用
```
教師：「今日は新しい方法で授業をしてみようと思います」
生徒A：「先生、それって難しそう...」
教師：「大丈夫、一緒にやってみましょう」
```

### 5. 専門用語の扱い

#### 5.1 教育用語
- 初出時は必ず説明を付加
- 可能な限り日常的な言葉に置き換える
- 用語集を章末または巻末に配置

#### 5.2 AI・技術用語
- 最小限の使用に留める
- 比喩や例えを用いて説明
- 「プロンプト」→「AIへの指示文」のように言い換え

### 6. 視覚的要素

#### 6.1 図表の活用
- 複雑な概念は図解で説明
- ビフォー・アフターの比較表
- チェックリストやワークシートの提供

#### 6.2 強調表現
- **重要ポイント**: 太字で強調
- 💡 **ヒント**: アイコンを使った視覚的な区別
- 📝 **実践メモ**: 実践のポイントを枠で囲む

### 7. 配慮事項

#### 7.1 多様性への配慮
- 様々な学校規模・地域性を考慮
- ICT環境の差を前提とした代替案の提示
- 特別支援教育の視点も含める

#### 7.2 現実的な制約の認識
- 時間的制約を考慮した提案
- 予算的制約に配慮した選択肢
- 段階的導入を前提とした計画

### 8. 各章での注意点

#### 8.1 理論章（第2章など）
- 理論は最小限に、すぐに実践例へ
- 難解な概念は身近な例で説明
- 「なぜこの理論が役立つのか」を明確に

#### 8.2 実践章（第4-6章など）
- ステップ・バイ・ステップの詳細な手順
- つまずきポイントと対処法
- 「うまくいかない時は...」という代替案

#### 8.3 事例章（第6章など）
- 成功事例だけでなく試行錯誤も含める
- 異なる校種（小・中・高）の事例をバランスよく
- 追試可能な具体的な情報を提供

### 9. 文章のトーン

#### 9.1 励ましと支援
- 「一緒に」「共に」という協働的な表現
- 小さな成功を認める表現
- 挑戦を後押しする前向きなメッセージ

#### 9.2 現実的な期待値
- 「すぐに効果が出る」という過度な期待を避ける
- 「徐々に」「少しずつ」という現実的なペース
- 個人差があることを前提とした表現

### 10. チェックリスト

執筆時の最終確認項目：
- [ ] 専門用語に説明はついているか
- [ ] 具体的な教室場面が含まれているか
- [ ] 実践可能なステップが明確か
- [ ] 異なる校種への配慮があるか
- [ ] 読者への敬意が感じられるか
- [ ] 前向きで建設的なトーンか
- [ ] 視覚的にわかりやすいか
- [ ] 明日から使える内容が含まれているか

## まとめ

この文書スタイルガイドは、教師読者が：
1. 共感を持って読み進められる
2. 実践への意欲が湧く
3. 無理なく段階的に取り組める
4. 自信を持って新しい挑戦ができる

このような読書体験を提供することを目的としています。常に「読者である教師の立場」に立ち、実践的で温かみのある文章を心がけてください。
