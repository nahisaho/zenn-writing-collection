# AI依存度セルフチェックリスト

:::message alert
このチェックリストは、あなたや生徒のAI依存度を客観的に把握するためのツールです。
「依存」は恥ずべきことではなく、認識することが改善への第一歩です。
定期的にチェックし、健全なAI活用への道筋を見つけましょう。
:::

# 1. 教師用AI依存度チェックリスト

## A. 授業準備における依存度チェック

### チェック項目（各項目 はい=2点、時々=1点、いいえ=0点）

#### 【教材作成】
```markdown
□ 授業プリントの作成をほぼ全てAIに任せている
□ 発問・課題をAIが提案したものをそのまま使用している
□ 評価基準の設定をAIの提案に依存している
□ 授業の流れ（指導案）をAIに作成させている
□ 生徒への配布資料の文章をAIに書かせている
```

#### 【内容理解】
```markdown
□ 教える内容の理解をAIの説明に依存している
□ 専門外の内容はAIの解説をそのまま信じている
□ 生徒の質問への回答準備をAIに頼っている
□ 教科書の内容解釈をAIに任せている
□ 最新の教育動向の把握をAIだけに頼っている
```

#### 【評価・フィードバック】
```markdown
□ 生徒の提出物へのコメントをAIに作成させている
□ 成績評価の判断をAIに依存している
□ 保護者への連絡文書をAIに作成させている
□ 生徒の作品・レポートの評価基準をAIに決めさせている
□ 通知表の所見をAIに書かせている
```

### 判定基準（30点満点）

| 得点 | 依存度レベル | 状態 | 対応 |
|------|------------|------|------|
| 0-5点 | レベル0（健全） | AIを適切なツールとして活用 | 現状維持・他教師への模範 |
| 6-12点 | レベル1（軽度） | やや依存傾向あり | 意識的な自立実践 |
| 13-20点 | レベル2（中度） | 明確な依存状態 | 段階的な依存脱却プログラム |
| 21-30点 | レベル3（重度） | 深刻な依存状態 | 集中的な改善支援が必要 |

## B. 日常業務における依存度チェック

### チェック項目（各項目 はい=2点、時々=1点、いいえ=0点）

```markdown
【文書作成】
□ メール文面の作成を常にAIに依頼している
□ 会議資料の作成をAIに依存している
□ 報告書の作成をAIに任せている

【問題解決】
□ 生徒指導の対応方法をAIに相談することが多い
□ 保護者対応の方法をAIの提案に従っている
□ 学級経営の問題解決をAIに頼っている

【自己研鑽】
□ 研修レポートをAIに書かせている
□ 教育書の要約をAIだけで済ませている
□ 授業改善のアイデアをAI提案のみに頼っている
```

### あなたの依存パターン診断

チェック結果から、以下のどのパターンに当てはまるか確認してください。

**パターンA：効率追求型依存**
- 時間短縮のためにAIに頼りすぎている
- 「楽になるから」が主な動機
- 改善策：意図的に「非効率な思考時間」を設ける

**パターンB：自信欠如型依存**
- 自分の判断に自信が持てずAIに確認
- 「AIの方が正しい」という思い込み
- 改善策：小さな成功体験を積み重ねる

**パターンC：無自覚型依存**
- 依存している認識がない
- 「これが普通」と思っている
- 改善策：AIなし週間を設けて違いを体感

# 2. 生徒用AI依存度チェックリスト（中高生版）

## A. 学習場面でのチェック

### チェック項目（はい=2点、時々=1点、いいえ=0点）

#### 【宿題・課題】
```markdown
□ 宿題を始めるとき、まずAIに聞くのが習慣になっている
□ 数学の問題は、自分で考える前にAIで解き方を調べる
□ 作文や感想文をAIに下書きしてもらっている
□ 英語の和訳・英訳をすべてAIに任せている
□ 調べ学習の内容をAIの回答をコピペしている
```

#### 【テスト勉強】
```markdown
□ テスト勉強の計画をAIに作ってもらっている
□ 暗記事項の覚え方をAIに頼っている
□ 問題の解説を自分で考えずAIの説明で済ませている
□ わからない問題があると、すぐにAIに答えを聞く
□ テスト前日はAIのまとめだけで勉強している
```

#### 【授業中】
```markdown
□ 先生の質問に答える前に、こっそりAIで調べている
□ グループ学習で自分の意見を言う前にAIに相談している
□ ノートのまとめ方をAIに聞いている
□ 発表資料の内容をAIに作ってもらっている
□ 実験レポートの考察をAIに書いてもらっている
```

### 判定と君へのメッセージ

**0-8点：AI使いこなしマスター！**
```
君はAIを道具として上手に使えています。
この調子で、自分の頭で考えることを大切にしよう！
```

**9-16点：ちょっと頼りすぎかも？**
```
AIに頼る場面が増えてきているね。
「まず5分自分で考える」を習慣にしてみよう！
```

**17-24点：依存アラート発令中！**
```
AIがないと不安になっていない？
週に1日「AIなしデー」を作って、自力を取り戻そう！
```

**25-30点：今すぐ改善が必要！**
```
AIなしでは勉強できなくなっているかも。
先生や保護者と相談して、段階的に自立していこう！
```

# 4. 保護者用：子どものAI依存度チェック

## お子様の様子を観察してチェック

### チェック項目（よく見る=2点、時々見る=1点、見ない=0点）

#### 【学習行動の変化】
```markdown
□ 宿題を始めるとすぐにスマホやPCを開く
□ 「AIに聞けばいい」が口癖になっている
□ 自分で考える前に答えを検索している
□ 課題の提出物がAI特有の文体になっている
□ テスト結果と普段の理解度にギャップがある
```

#### 【思考力の変化】
```markdown
□ 「わからない」とすぐに諦めるようになった
□ 自分の意見を言えなくなってきた
□ 創造的な遊びや活動が減った
□ 本を読まなくなった
□ 集中力が続かなくなった
```

#### 【依存の兆候】
```markdown
□ AIが使えないと不安そうにする
□ AIの回答を疑わない
□ 友達との会話でAIの話題が多い
□ 一人で考える時間を嫌がる
□ AIなしでの学習を拒否する
```

### 保護者の方へのアドバイス

**0-10点：健全な状態です**
- お子様は適切にAIを活用できています
- 現在の家庭でのルールを維持してください

**11-20点：注意が必要な段階**
- AI使用のルールを見直す時期です
- 「考える時間」を意識的に作りましょう

**21-30点：積極的な介入が必要**
- 学校と連携して改善策を検討しましょう
- 専門家のアドバイスも検討してください

### 家庭でできる改善アクション

```markdown
【すぐできること】
✓ AI使用前に5分間の「考えタイム」ルール
✓ 親子で一緒に問題を考える時間を作る
✓ AIの答えを必ず疑問視する習慣づけ

【1週間でできること】
✓ 「AIなしデー」を週1回設定
✓ 図書館に一緒に行く習慣
✓ 手書きの学習時間を確保

【1ヶ月でできること】
✓ 家族でのAI使用ルール策定
✓ 学校との連携強化
✓ 創造的活動の機会増加
```

# 6. AI依存からの脱却プログラム

## 段階的改善プラン

### Phase 1：認識期（1-2週間）
```markdown
【目標】依存の自覚と改善意欲の醸成

✓ 毎日のAI使用記録をつける
✓ AI使用前に「なぜ使うか」を書く
✓ 1日1回は「AIなし課題」に挑戦
```

### Phase 2：削減期（3-4週間）
```markdown
【目標】AI使用頻度の段階的削減

✓ AI使用を50%削減
✓ 「5分ルール」の徹底
✓ 代替方法の習得（辞書、参考書等）
```

### Phase 3：自立期（5-8週間）
```markdown
【目標】適切なAI活用能力の確立

✓ 必要最小限のAI活用
✓ 批判的AI活用の実践
✓ 他者への指導・支援
```

## 依存タイプ別改善戦略

### タイプA：即答依存型
**特徴**: すぐに答えが欲しい
**改善策**:
- プロセスを楽しむ活動を増やす
- パズル、推理ゲームなどで思考の楽しさを体感
- 小さな成功体験の積み重ね

### タイプB：自信喪失型
**特徴**: 自分の考えに自信がない
**改善策**:
- 間違いを恐れない環境づくり
- 部分的な成功を認める
- ピアサポートの活用

### タイプC：効率重視型
**特徴**: 時間をかけたくない
**改善策**:
- 思考の価値を実感する体験
- 長期的視点での利益を説明
- 時間制限のある思考ゲーム

# まとめ：健全なAI活用への道

## AI依存は「病気」ではなく「習慣」

:::message
AI依存は誰にでも起こりうる現象です。
大切なのは、現状を認識し、改善に向けて一歩踏み出すこと。
小さな変化の積み重ねが、大きな成長につながります。
:::

## 定期的なチェックの重要性

- **月1回の定期チェック**: 変化を早期発見
- **記録の蓄積**: 改善過程の可視化
- **共有と対話**: 一人で抱え込まない

## サポート体制の活用

```markdown
【学校でのサポート】
- 担任・教科担当への相談
- スクールカウンセラーの活用
- 保護者との連携

【家庭でのサポート】
- 家族でのルール作り
- 励まし合いの環境
- 成功体験の共有

【地域でのサポート】
- 学習支援団体の活用
- 図書館等の活用
- 同じ悩みを持つ仲間づくり
```

## 最後に：AIと共に成長する未来へ

AIは敵ではありません。適切に活用すれば、私たちの能力を拡張する素晴らしいパートナーとなります。このチェックリストを活用して、健全な関係を築いていきましょう。

**「AIに使われる」のではなく「AIを使いこなす」**

その第一歩が、このチェックリストです。
