# CPPD実践評価ルーブリック集

:::message
本ルーブリック集は、CPPD（認知保護型プロンプト設計法）の実践効果を客観的に評価するためのツールです。教師の自己評価、生徒の成長測定、学校全体の実践評価に活用してください。
:::

## 本ルーブリック集の使い方

1. **定期的な評価**: 月1回程度の定期的な評価により、進歩を可視化
2. **複数視点での評価**: 自己評価と他者評価を組み合わせて客観性を確保
3. **改善への活用**: 評価結果を次の実践改善に直接活用
4. **エビデンス蓄積**: 評価データを蓄積し、制度改革への根拠として活用

# 1. 教師用自己評価ルーブリック

## A. CPPD実践力評価ルーブリック

### 評価レベル
- **レベル4（優秀）**: 模範的実践者として他者を指導できる
- **レベル3（良好）**: 自律的にCPPD実践を展開できる
- **レベル2（発展途上）**: 基本的なCPPD実践ができる
- **レベル1（初期段階）**: CPPD実践を開始したばかり

### 評価項目と基準

| 評価項目 | レベル1（初期段階） | レベル2（発展途上） | レベル3（良好） | レベル4（優秀） |
|---------|-------------------|-------------------|---------------|---------------|
| **1. 事前思考確保の実践** | 時々思い出して実施（週1回未満） | 半分以上の授業で実施（週2-3回） | ほぼ全ての授業で実施（週4回以上） | 全授業で確実に実施し、質も高い |
| **2. メタメタプロンプト設計力** | テンプレートをそのまま使用 | テンプレートを少し改変して使用 | 独自のプロンプトを設計できる | 教科・単元特性に最適化した高度な設計 |
| **3. 批判的AI活用の指導** | AIの危険性を説明するのみ | 基本的な批判的視点を指導 | 多角的な批判的視点を育成 | 生徒が自律的に批判的活用できるよう指導 |
| **4. 統合的振り返りの実施** | 振り返り時間を設けるのみ | 簡単な振り返り活動を実施 | 構造化された振り返りを実施 | メタ認知を促進する深い振り返りを実施 |
| **5. 生徒のAI依存度把握** | 依存状況を把握していない | 大まかな傾向を把握 | 個別生徒の状況を把握 | データに基づく詳細な把握と個別対応 |
| **6. 保護者との連携** | 連携なし | 基本的な情報提供のみ | 定期的な情報交換 | 協働的な家庭実践の推進 |
| **7. 同僚との協働** | 個人実践のみ | 情報共有程度 | 実践の相互観察・改善 | チームでの体系的実践 |
| **8. 実践データの蓄積** | データ収集なし | 断片的なメモ程度 | 体系的な記録 | 分析可能なデータベース構築 |

### 使用方法
1. 各項目について、自分の現在のレベルをチェック
2. 合計点を算出（32点満点）
3. 弱点項目を特定し、改善計画を立案
4. 1ヶ月後に再評価し、進歩を確認

### 評価後のアクション
- **24点以上**: リーダーとして他者支援へ
- **16-23点**: 継続的改善と実践深化
- **8-15点**: 基礎固めと研修参加
- **8点未満**: メンター支援を要請

# 2. 生徒のAI依存度測定ルーブリック

## A. 行動観察によるAI依存度評価

### 評価レベル
- **依存度0（自律的）**: AIを適切なツールとして活用
- **依存度1（軽度）**: 時々AIに頼りすぎる傾向
- **依存度2（中度）**: 頻繁にAIに依存
- **依存度3（重度）**: AIなしでは学習困難

### 評価項目と判定基準

| 観察項目 | 依存度0（自律的） | 依存度1（軽度） | 依存度2（中度） | 依存度3（重度） |
|---------|------------------|----------------|----------------|----------------|
| **1. 問題着手時の行動** | 必ず自分で考えてから着手 | 多くの場合自分で考える | 半分はすぐAIに聞く | ほぼ常にAIから始める |
| **2. AI使用の頻度** | 必要最小限（20%以下） | やや多い（20-40%） | 頻繁（40-70%） | ほぼ常時（70%以上） |
| **3. AI回答への態度** | 常に批判的に検証 | 時々疑問を持つ | ほとんど鵜呑み | 完全に信頼 |
| **4. 思考プロセスの説明** | 明確に説明できる | 大体説明できる | 部分的にしか説明できない | 説明できない |
| **5. AIなしでの課題遂行** | 問題なく遂行可能 | 少し時間がかかるが可能 | かなり困難 | ほぼ不可能 |
| **6. 学習への主体性** | 高い探究心と意欲 | 普通の学習意欲 | 受動的な学習態度 | 学習意欲の喪失 |
| **7. 創造的課題への対応** | 独創的なアイデア創出 | ある程度の創造性 | 創造性の低下 | 創造的思考の欠如 |
| **8. 協働学習での貢献** | 積極的に貢献 | 普通に参加 | 消極的参加 | ほとんど貢献なし |

### 使用方法
1. 2週間の観察期間を設定
2. 各項目を日常的に観察・記録
3. 最も多い依存度レベルを特定
4. 個別指導計画を立案

### 依存度別対応指針
- **依存度0**: 現状維持と更なる向上支援
- **依存度1**: 予防的指導と意識化
- **依存度2**: 積極的介入と依存脱却プログラム
- **依存度3**: 集中的支援と保護者連携

## B. 生徒用セルフチェックシート（中高生用）

### チェック項目（はい=1点、いいえ=0点）

```markdown
□ 宿題を始めるとき、まず自分で5分以上考えてからAIを使う
□ AIの答えを見た後、なぜその答えになるか説明できる
□ AIが間違っている可能性を考えたことがある
□ AIを使わずに問題を解くことに自信がある
□ 友達にAIの答えをそのまま教えることはしない
□ AIを使った後、必ず自分の言葉でまとめ直す
□ 1日の勉強時間のうち、AI使用は30%以下である
□ テスト勉強でAIに頼らず自力で理解しようとする
□ 創作課題（作文、アート等）は自分のアイデアから始める
□ AIなしで1週間勉強することができると思う
```

### 判定基準
- **8-10点**: 健全なAI活用（依存度0）
- **5-7点**: 注意が必要（依存度1）
- **3-4点**: 依存傾向あり（依存度2）
- **0-2点**: 深刻な依存状態（依存度3）

# 3. 授業のCPPD準拠度評価基準

## A. 授業観察用ルーブリック

### 評価の視点
授業全体を通じてCPPD原則がどの程度実現されているかを評価

### 評価項目と配点

| 評価領域 | 評価項目 | 配点 | 観察ポイント |
|---------|---------|------|------------|
| **事前思考確保（30点）** | 思考時間の確保 | 10点 | 5分以上の個人思考時間が確保されているか |
| | 思考の質的支援 | 10点 | 思考を促す発問・ワークシートが準備されているか |
| | 思考の共有機会 | 10点 | ペア・グループでの思考共有が行われているか |
| **批判的AI活用（30点）** | AI活用の目的明確化 | 10点 | なぜAIを使うのか生徒が理解しているか |
| | 批判的検証の指導 | 10点 | AI出力を検証する活動が組み込まれているか |
| | 複数視点の確保 | 10点 | AI以外の情報源との比較が行われているか |
| **統合的振り返り（30点）** | プロセスの振り返り | 10点 | 学習プロセス全体を振り返る時間があるか |
| | メタ認知の促進 | 10点 | 自己の思考を客観視する機会があるか |
| | 次回への接続 | 10点 | 学びを次に活かす視点が示されているか |
| **全体的な質（10点）** | CPPD理念の一貫性 | 5点 | 授業全体でCPPD理念が貫かれているか |
| | 生徒の主体性 | 5点 | 生徒が主体的に思考・活動しているか |

### 評価基準
- **90点以上**: 模範的なCPPD実践授業
- **70-89点**: 良好なCPPD実践授業
- **50-69点**: 改善余地のあるCPPD実践授業
- **50点未満**: CPPD原則の再確認が必要

## B. 授業設計チェックリスト

### 事前準備段階

```markdown
【メタメタプロンプト設計】
□ 単元目標に対応したメタメタプロンプトを作成した
□ 生徒の発達段階に適したプロンプトレベルを選択した
□ 教科特性を考慮したカスタマイズを行った

【教材・ワークシート準備】
□ 事前思考記録シートを準備した
□ AI活用ガイドラインを明示した
□ 振り返りシートを準備した

【評価計画】
□ CPPD観点を含む評価規準を設定した
□ 形成的評価の方法を計画した
□ 生徒の自己評価機会を設定した
```

### 授業実施段階

```markdown
【導入（5-10分）】
□ 本時の目標とAI活用の位置づけを説明した
□ CPPD3ステップの確認を行った
□ 生徒の既有知識を活性化した

【展開1：事前思考（10-15分）】
□ 個人思考の時間を十分確保した
□ 思考を支援する発問を行った
□ ペア・グループでの思考共有を実施した

【展開2：AI活用（15-20分）】
□ AI活用の目的を再確認した
□ 批判的にAI出力を検証する活動を行った
□ 複数の視点から情報を検討した

【まとめ：統合的振り返り（10-15分）】
□ 学習プロセス全体を振り返った
□ メタ認知を促す問いかけを行った
□ 次時への課題を明確化した
```

# 4. 学校全体のCPPD実践成熟度評価

## A. 組織的実践評価ルーブリック

### 成熟度レベル
- **レベル5（最適化段階）**: 継続的改善と革新
- **レベル4（管理段階）**: 定量的管理と制御
- **レベル3（定義段階）**: 標準化された実践
- **レベル2（反復可能段階）**: 基本的実践の確立
- **レベル1（初期段階）**: 場当たり的実践

### 評価領域と判定基準

| 評価領域 | レベル1 | レベル2 | レベル3 | レベル4 | レベル5 |
|---------|---------|---------|---------|---------|---------|
| **組織体制** | 個人任せ | 推進チーム設置 | 全校体制確立 | PDCAサイクル確立 | 継続的革新体制 |
| **教師の実践率** | 10%未満 | 10-30% | 30-60% | 60-90% | 90%以上 |
| **研修体制** | 研修なし | 単発研修 | 定期研修 | 体系的研修プログラム | 自律的学習組織 |
| **カリキュラム統合** | 統合なし | 部分的試行 | 教科別統合 | 教科横断的統合 | 完全統合・最適化 |
| **評価システム** | 評価なし | 主観的評価 | 基準明確化 | データ基盤評価 | 予測的評価 |
| **保護者連携** | 連携なし | 情報提供 | 双方向連携 | 協働的実践 | コミュニティ形成 |
| **データ活用** | データなし | 断片的収集 | 体系的収集 | 分析的活用 | AI活用分析 |
| **外部連携** | 連携なし | 情報収集 | 他校交流 | 地域ネットワーク | 国際連携 |

### 使用方法
1. 各領域について現在のレベルを評価
2. レーダーチャートで可視化
3. 弱点領域の強化計画立案
4. 半期ごとに再評価

### 成熟度別発展戦略
- **レベル1→2**: 推進体制構築と基礎研修
- **レベル2→3**: 全校展開と標準化
- **レベル3→4**: データ駆動型改善
- **レベル4→5**: イノベーションと対外発信

# まとめ：評価から改善への循環

## 評価の目的を見失わないために

:::message alert
評価は「ランク付け」ではなく「成長支援」のためのツールです。
常に「この評価が実践改善にどう活きるか」を意識して活用してください。
:::

## 小さな改善の積み重ね

- **完璧を求めない**: レベル1からレベル2への進歩も立派な成長
- **部分的改善**: すべてを一度に改善せず、焦点を絞る
- **成功の共有**: 小さな成功事例も積極的に共有
- **失敗から学ぶ**: うまくいかなかった実践も貴重な学び

## 継続的な評価文化の構築

評価を特別なイベントではなく、日常的な改善活動の一部として定着させることが、CPPD実践の持続的発展につながります。

**「測定できるものは改善できる」**

このルーブリック集を活用し、客観的データに基づく継続的改善を通じて、AI時代の教育改革を着実に前進させていきましょう。
