# 概要：なぜガードレールが必要なのか

CPPD（認知保護型プロンプト設計法）を実践する際、教師や学習者が無意識のうちに依存促進的なプロンプトを作成してしまうリスクがあります。このガードレールシステムは、プロンプト実行前にCPPD原則への準拠性をチェックし、問題がある場合は実行を停止して改善点を指摘します。

## システムの必要性

### 教師側で起こりがちな問題

1. **善意の依存促進**: 「わかりやすく教えて」という親切心が依存を助長
2. **無意識の手抜き**: 忙しさから「答えを教えて」に頼ってしまう
3. **段階的劣化**: 最初は適切でも徐々に依存的なプロンプトに変化
4. **技術的複雑さ**: メタメタプロンプトの高度さが適切な設計を困難にする

### 学習者側で起こりがちな問題

1. **即答要求**: 「早く答えを教えて」という結果重視の姿勢
2. **思考回避**: 考える前にAIに頼る習慣の形成
3. **依存の無自覚**: 自分が依存していることに気づかない
4. **段階的退化**: 最初は考えていても徐々に思考しなくなる

### ガードレールの革新的価値

- **予防的介入**: 問題が起こる前に未然防止
- **教育的指導**: 単なる拒否ではなく改善方法を具体的に提示
- **段階的成長**: 使用者のレベル・年齢に応じた支援
- **システム学習**: 蓄積データによる継続的改善
- **双方向保護**: 教師・学習者両方の認知能力を同時保護
