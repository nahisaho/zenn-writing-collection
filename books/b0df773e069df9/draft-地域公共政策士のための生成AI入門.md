# Book Draft - 地域公共政策士のための生成AI入門

## 基本情報
- **タイトル**: 地域公共政策士のための生成AI入門
- **対象読者**: 琉球大学で地域公共政策士資格を目指す学部生（主に3-4年生）および社会人学生（主に沖縄県自治体職員）
- **書籍概要**: 沖縄の地域特性を踏まえた地域公共政策士として必要な生成AI活用スキルを体系的に学ぶ教科書。認知負債を避けた健全なAI活用を基盤とし、離島特性や観光産業、基地問題等の沖縄特有課題への対応を含む産官学民連携やセクター間調整に生成AIを活用する方法を、演習とケーススタディを通じて実践的に習得。

## 琉球大学混合クラスに対応した学習設計

本書は琉球大学の特殊な教育環境、すなわち学部生（18名、60%）と社会人学生（主に沖縄県自治体職員、12名、40%）が同じ教室で学ぶ混合クラスでの効果的な学習を目指して設計されています。また、30名の琉球大学特化ペルソナ分析（適合度平均4.6/5.0）に基づき、地域公共政策士を目指す学生の多様なニーズに対応しています。

### 第3章: 沖縄の地域課題分析手法 - リサーチから政策立案まで
**目的**: 生成AIを活用した体系的な地域課題分析から政策立案までの全プロセス習得
**概要**: 記述式→マークシート式の段階的アンケート調査と生成AI分析による政策立案

#### 3.1 地域課題発見のための総合リサーチ手法
**目的**: 生成AIを活用した効率的な情報収集・整理技術
**内容**: 政策立案の基盤となる多角的リサーチ手法

##### 3.1.1 生成AIによる先行研究調査
- **Claude活用**: 学術論文の要約と比較分析
  - 離島振興、観光政策、基地問題等の研究動向整理
  - 複数の論文から共通論点と相違点を抽出
  - 研究のギャップ（未解決課題）の特定
- **ChatGPT活用**: 政策事例の幅広い収集
  - 国内外の類似課題解決事例の検索
  - 成功・失敗事例の分類と要因分析
  - 沖縄への適用可能性の初期検討

##### 3.1.2 統計データの生成AI分析
- **Microsoft 365 Copilot活用**: Excelデータの自動分析
  - 沖縄県統計データの傾向分析と可視化
  - 人口動態、経済指標、観光統計の相関分析
  - 他都道府県との比較レポート自動生成
- **分析支援プロンプト設計**:
  - 「このデータから読み取れる課題を3つ挙げて」
  - 「数値の変化から将来予測をしてください」
  - 「他地域と比べた沖縄の特徴を説明してください」

##### 3.1.3 ステークホルダー情報の整理
- **関係者マッピング**: 生成AIによる包括的リスト作成
  - 行政機関（県庁、市町村、国）
  - 民間団体（商工会、観光協会、NPO）
  - 住民グループ（自治会、年代別組織）
- **利害関係分析**: 各主体の立場・要求の構造化
- **情報収集計画**: 効率的なヒアリング・調査計画策定

#### 3.2 記述式アンケートによる地域課題の発見
**目的**: 住民の生の声から潜在的課題を発見する
**内容**: 生成AI支援による効果的なアンケート設計と実施

##### 3.2.1 記述式アンケート設計（生成AI支援）
- **質問項目の作成支援**:
  - 「沖縄県の○○地区住民向けの地域課題発見アンケートを作成してください」
  - バイアス回避のための中立的質問文作成
  - 回答しやすい質問順序の設計
  - 多様な住民層に配慮した表現調整

- **実際のアンケート例（宮古島離島振興）**:
  1. 「日常生活で最も困っていることを自由にお書きください」
  2. 「島の良いところ、大切にしたいところを教えてください」
  3. 「10年後の島はどうなっていてほしいですか」
  4. 「行政に最も期待することは何ですか」
  5. 「島外（本島・本土）との関係で改善したい点はありますか」

##### 3.2.2 回答収集と前処理
- **デジタル化支援**: 手書き回答のデジタル変換
- **匿名性確保**: 個人特定情報の除去プロセス
- **データクリーニング**: 記述内容の整理・統一

#### 3.3 記述式アンケート結果の生成AI分析
**目的**: 大量の記述データから課題の構造を把握
**内容**: テキストマイニングと質的分析の融合

##### 3.3.1 テキスト分析による課題抽出
- **頻出語分析**: よく言及される問題・要望の特定
  ```
  プロンプト例：
  「以下の住民アンケート回答から、最も頻繁に言及されている
  課題を5つ抽出し、それぞれの言及回数と具体例をまとめてください」
  ```

- **感情分析**: 住民の課題に対する切迫度・深刻度の測定
  ```
  プロンプト例：
  「各回答の感情的トーン（緊急性、不安度、期待度）を
  5段階で評価し、課題の優先度を判定してください」
  ```

##### 3.3.2 課題の分類と構造化
- **カテゴリー分類**: 
  - インフラ（交通、通信、上下水道）
  - 経済・雇用（産業、就職、所得）
  - 社会・福祉（医療、教育、高齢者）
  - 環境・防災（自然環境、災害対策）
  - 文化・コミュニティ（伝統、つながり）

- **課題間の関連性分析**:
  ```
  プロンプト例：
  「抽出された課題間の因果関係や相互影響を
  図式化し、根本原因と表面的症状を区別してください」
  ```

##### 3.3.3 住民ニーズの定量化準備
- **仮説設定**: 記述分析から導かれる検証すべき仮説
- **測定項目の特定**: 定量調査で確認すべき要素
- **ターゲット層の分析**: 課題認識の世代・属性別差異

#### 3.4 マークシート方式アンケートの作成
**目的**: 記述分析結果を踏まえた定量的検証
