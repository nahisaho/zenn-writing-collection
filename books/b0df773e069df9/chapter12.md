# 実践で学ぶ沖縄の政策課題解決 - ペルソナベース事例案集

本章は、これまで学んだ理論と技法を沖縄の具体的な地域課題に適用する実践的なケーススタディ案集です。琉球大学混合クラスの30名のペルソナ分析結果に基づき、各キャリア志向と背景に対応したオーダーメイドの事例案を提供します。沖縄の特殊な地域特性（離島性、基地問題、観光依存、文化的多様性）を踏まえた政策課題に、生成AIを活用しながら取り組む実際のプロセスを体験的に学習します。

## 12.1 キャリア志向別事例案紹介

各ペルソナのキャリア志向に対応した具体的な事例案を通じて、沖縄県内での各進路における地域公共政策士としての活躍イメージを具体化します。理論的学習を実際の職業生活につなげ、専門性を活かした社会貢献の道筋を明確化することで、学習のモチベーション向上と実践力の強化を図ります。

### 12.1.1 公務員キャリア

沖縄の公務員として活躍する地域公共政策士の実践事例案を紹介します。県庁から市町村、特殊法人まで、多様な公務員キャリアでの生成AI活用による政策立案・実施の革新的アプローチを学びます。

**事例案背景：多言語対応観光政策の立案**

```
課題設定：

・文化的配慮と正確性を両立した翻訳の必要性

Phase 1（現場理解・AI禁止期）：
「那覇空港、国際通り、首里城等で外国人観光客の困りごとを
直接観察・ヒアリングし、現状を把握してください」

観察結果例：
・案内標識の多言語対応不足
・緊急時の情報提供体制の不備
・琉球文化の説明における翻訳の不適切さ
・交通機関での情報提供格差

Phase 2（AI支援・データ分析期）：
「観光統計データと外国人観光客アンケート結果を分析し、
優先対応すべき課題を特定してください」

AI活用範囲：
・多言語アンケートデータの分析・可視化
・他県の多言語観光政策事例調査
・翻訳精度の比較検証
・コスト効率性の試算

Phase 3（政策立案・人間主導）：
分析結果を基に、沖縄の文化的特性を反映した
多言語観光政策を自分で立案
```

**政策提案：「おもてなしAI沖縄」システム**

```
Phase 4（実装計画・協働型）：

システム概要：

・観光スポット別カスタマイズ情報提供

1. パイロット地域（国際通り）での実証実験

期待される効果：
・観光客満足度の向上（目標：15%向上）
```
