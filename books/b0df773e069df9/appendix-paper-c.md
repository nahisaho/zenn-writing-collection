# 論文C: 住民参加型観光政策の評価（仮想文書）

**タイトル**: 「住民参加型観光政策の効果測定：久米島町における協働型観光計画策定プロセスの事例分析」

**著者**: 伊藤 次郎¹, 渡辺 さくら², 久保田 隆³
¹琉球大学法文学部, ²久米島町企画財政課, ³日本大学文理学部

**キーワード**: 住民参加, 協働型計画策定, 観光政策, ソーシャル・キャピタル, 合意形成

## 要旨

本研究は、久米島町で2021年から2023年にかけて実施された住民参加型観光計画策定プロセスを事例として、住民参加手法の有効性と政策効果を定量的に評価した。参加型手法として、住民ワークショップ（12回開催）、オンライン意見募集、高校生アイデアコンテストなど多様な参加チャネルを設置し、延べ1,247名（島民の13.2%）が参加した。

主要な成果として、(1)住民の観光政策に対する理解度が54%→89%に向上、(2)観光業に対する住民支持率が41%→78%に改善、(3)策定された計画の実行率が従来の行政主導型計画（47%）と比較して83%に達した。また、参加プロセスを通じて住民間のソーシャル・キャピタルが強化され、観光以外の地域課題への取り組みにも波及効果が確認された。

本研究は、小規模離島における住民参加型政策形成の有効性を実証し、持続可能な観光地域づくりにおける住民参加の重要性を示唆している。

## 1. はじめに

### 1.1 研究背景
久米島町（人口7,446人、2023年現在）は、沖縄本島西方約100kmに位置する離島で、「球美の島」と呼ばれる美しい自然環境を有している。しかし、人口減少（過去20年で28%減）と高齢化（高齢化率38.2%）が進行し、基幹産業である農業・漁業も低迷している。

観光業は地域活性化の切り札として期待されているが、年間観光客数は約8万人（2019年）に留まり、宮古島（117万人）や石垣島（140万人）と大きな格差がある。この背景には、交通アクセスの制約（1日3便の航空便、4便のフェリー）に加えて、住民の観光業に対する理解不足と協力体制の不備がある。

### 1.2 住民参加型政策形成の理論的背景
Arnstein (1969) の「参加の梯子」理論によれば、真の住民参加は単なる情報提供や意見聴取を超えて、政策決定への実質的関与と権限委譲を含むものである。観光政策においても、住民の「当事者意識」と「参加意欲」が政策の実効性を決定する重要な要因となる。

特に小規模離島では、限られた人的資源の効率的活用と住民合意の形成が政策成功の鍵となる。Reed (2008) は、住民参加が政策の正当性、実行可能性、持続可能性の3要素を向上させることを実証している。

### 1.3 研究目的
本研究は、久米島町における住民参加型観光計画策定プロセスを詳細に分析し、以下の研究課題に答えることを目的とする：
1. 住民参加手法の設計と実施過程の評価
2. 参加プロセスが住民意識に与える影響の測定
3. 策定された政策の実行効果の検証
4. 小規模離島における住民参加型政策形成の成功要因の特定

## 2. 調査地域の概況

### 2.1 久米島町の基本データ
**地理・人口**:
- 面積: 59.53km²
- 人口: 7,446人（2023年1月現在）
- 世帯数: 3,721世帯
- 人口密度: 125.1人/km²
- 高齢化率: 38.2%

**経済構造**:
- 主要産業: 農業（40%）、建設業（22%）、サービス業（18%）
- 観光業従事者: 約350人（就業者の8.7%）
- 年間観光消費額: 約12億円（町内総生産の4.2%）

**観光資源**:
- はての浜（東洋一美しいと称される砂州）
- 比屋定バンタ（断崖絶壁の景勝地）
- 久米島紬（伝統工芸品）
- 海洋深層水関連施設

### 2.2 観光の現状と課題
**観光客数の推移**:
- 2015年: 94,000人
- 2017年: 87,000人
- 2019年: 81,000人（コロナ前最新）
- 2021年: 34,000人（コロナ影響）
- 2023年: 67,000人（回復途上）

**主要課題**:
1. 知名度の低さ（沖縄県外での認知率12%）
2. 交通アクセスの制約（那覇空港から25分、運賃往復26,000円）
3. 宿泊施設の不足（総定員580人、稼働率43%）
4. 観光商品の多様性不足
5. 住民の観光業への理解不足

## 3. 住民参加型計画策定プロセス

### 3.1 計画策定の概要
**計画名称**: 「久米島町観光振興基本計画2024-2028」
**策定期間**: 2021年4月～2023年3月（24ヶ月）
**予算規模**: 1,200万円（うち住民参加関連600万円）
**目標設定**: 2028年までに観光客数12万人、観光消費額20億円

### 3.2 参加手法の設計

**基本方針**:
住民の多様性（年齢、職業、居住地区、観光業との関わり）を考慮し、複数の参加チャネルを設置。参加の「量」と「質」の両面を重視した設計とした。

**参加手法の構成**:

**1. 住民ワークショップ（全12回開催）**
- 参加者: 延べ623名（実人数247名）
- 開催方法: 地区別（6地区×2回）
- 時間: 各回3時間（19:00-22:00）
- 内容: 現状分析→課題抽出→解決策検討→計画素案作成

**2. オンライン意見募集**
- 専用ウェブサイト開設（3言語対応）
- 参加者: 412名
- 投稿意見数: 1,247件
- 分析: テキストマイニングによる定量分析

**3. 高校生アイデアコンテスト**
- 参加者: 久米島高校全校生徒（67名）
- 提案数: 23チーム、91件のアイデア
- 優秀提案の計画への反映

**4. 事業者ヒアリング**
- 対象: 観光関連事業者48社・団体
- 方法: 個別面談（各45分）
- 参加率: 91.7%

**5. 町民アンケート調査**
- 対象: 18歳以上全住民（5,234名）
- 回収: 2,847件（回収率54.4%）
- 実施時期: 計画策定前、中間、完了後の3回

### 3.3 ファシリテーション手法
**専門人材の配置**:
- 計画策定コーディネーター: 1名（琉球大学教員）
- 地区別ファシリテーター: 6名（NPO法人等）
- 記録・分析スタッフ: 4名（大学院生）

**合意形成技法**:
- KJ法による意見整理
- ワールドカフェ形式でのアイデア創出
- ドット投票による優先順位決定
- デルファイ法による専門事項の合意形成

## 4. 調査方法

### 4.1 評価指標の設定
住民参加型政策形成の効果を多面的に評価するため、以下の指標を設定した：

**参加プロセスの評価**:
- 参加の代表性（年齢、性別、職業、地区バランス）
- 参加の実質性（発言機会、意見反映率）
- 参加満足度（プロセス評価、結果評価）

**住民意識の変化**:
- 観光政策理解度（5段階評価）
- 観光業支持度（5段階評価）
- 地域愛着度（5段階評価）
- 政治効力感（5段階評価）

**政策実行効果**:
- 計画実行率（数値目標達成度）
- 住民協力度（ボランティア参加等）
- 新規事業創出数
- 観光客数・消費額の変化

### 4.2 データ収集方法
**量的調査**:
- 住民意識調査（n=2,847、3回実施）
- 参加者満足度調査（n=1,247）
- 観光客アンケート（n=800/年）
- 事業者調査（n=48）

**質的調査**:
- 参加観察（全ワークショップ）
- 深層インタビュー（重要人物15名）
- フォーカス・グループ・インタビュー（6グループ）
- 会議録・資料の内容分析

## 5. 結果

### 5.1 参加プロセスの実績

**参加者の特徴**:
年齢構成: 20代8%、30代17%、40代23%、50代28%、60代19%、70代以上5%
性別: 男性52%、女性48%
職業: 会社員28%、自営業22%、農林水産業18%、公務員12%、その他20%
居住地区: 各地区概ね人口比に応じた参加（偏差±15%以内）

**参加満足度**:
- 参加プロセス満足度: 4.2/5.0
- 意見反映満足度: 3.8/5.0
- 継続参加意向: 87%

### 5.2 住民意識の変化

**観光政策理解度**:
計画策定前: 2.7/5.0 → 計画完了後: 4.5/5.0 （+1.8ポイント）
参加者: 2.6/5.0 → 4.7/5.0 （+2.1ポイント）
非参加者: 2.8/5.0 → 4.2/5.0 （+1.4ポイント）

**観光業支持度**:
計画策定前: 2.1/5.0 → 計画完了後: 3.9/5.0 （+1.8ポイント）
「観光業が島の活性化に重要」と回答: 41% → 78%
「観光客増加に積極的」と回答: 34% → 69%

**地域への愛着・誇り**:
地域愛着度: 4.1/5.0 → 4.5/5.0 （+0.4ポイント）
「島の魅力を発信したい」: 52% → 76%
「島の将来に希望を持てる」: 31% → 58%

**政治効力感**:
「町政に意見を伝えることができる」: 23% → 67%
「住民の声が政策に反映される」: 18% → 61%
「地域の課題解決に参加したい」: 45% → 74%

### 5.3 ソーシャル・キャピタルの強化

**住民間ネットワーク**:
- 新規人的つながり: 参加者1人平均12.3人
- 異世代交流機会: 参加前「ほとんどない」63% → 参加後「よくある」47%
- 地区を超えた交流: 参加前「ほとんどない」71% → 参加後「よくある」39%

**集合的効力感**:
「住民が協力すれば地域課題を解決できる」: 34% → 78%
「住民同士の結束が強い」: 41% → 69%

### 5.4 計画の実行効果

**数値目標の達成状況**（2024年3月現在）:
- 観光客数: 67,000人 → 79,000人（+18%、目標達成度47%）
- 観光消費額: 12億円 → 15.8億円（+32%、目標達成度63%）
- 新規観光商品開発: 17件（目標10件）
- 観光ガイド養成: 23名（目標15名）

**住民の自発的取り組み**:
- 観光ボランティアガイド登録: 47名
- おもてなし講習会参加: 234名
- 花植え・清掃活動参加: 延べ567名
- 新規イベント企画: 8件

**政策実行への協力度**:
従来型計画の住民協力率: 23%
今回計画の住民協力率: 67%

### 5.5 波及効果

**他分野への影響**:
参加手法を応用した取り組みが観光以外にも波及：
- 教育振興計画策定（2023年度）
- 地域防災計画見直し（2024年度予定）
- 移住促進策検討（2024年度予定）

**行政への影響**:
- 職員の住民参加型政策立案スキル向上
- 情報公開・住民との対話機会増加
- 政策評価システムの導入

## 6. 考察

### 6.1 成功要因の分析

**1. 多様な参加チャネルの設置**
年齢、職業、ライフスタイルの違いに配慮した複数の参加手法により、幅広い住民の参画を実現。特に、従来の住民説明会では参加しにくい若年層や女性の参加を促進。

**2. 実質的な参加機会の保障**
単なる意見聴取でなく、政策の企画段階からの参画により住民の「当事者意識」を醸成。アイデアの計画への反映率71%を達成。

**3. 専門的ファシリテーションの導入**
中立的な立場の専門人材による合意形成支援により、建設的な議論と効率的な合意形成を実現。

**4. 継続的な情報共有**
計画策定後も進捗状況を定期報告（四半期ごと）し、住民の関心と参加意欲を維持。

### 6.2 課題と限界

**参加の偏り**:
- 高齢者（70歳以上）の参加が少ない（5%）
- 若年世代の継続参加率が低い（43%）
- 観光業無関係者の関心度が限定的

**コスト・時間の課題**:
- 参加型手法の実施コスト（600万円）
- 計画策定期間の長期化（24ヶ月）
- 職員の業務負担増加

**合意の質**:
- 専門的・技術的事項での住民意見の限界
- 長期的視点での判断の困難さ
- 利害対立する事項での合意形成の難しさ

### 6.3 小規模離島での住民参加型政策形成の特徴

**有利な条件**:
- 住民同士の顔が見える関係
- 地域課題の共有認識
- 行政と住民の距離の近さ
- 情報伝達の迅速性

**制約要因**:
- 人的資源の限界
- 専門人材の不足
- 合意形成の困難（利害関係の複雑化）
- 参加疲れのリスク

## 7. 結論と示唆

### 7.1 研究成果の要約
本研究により、小規模離島における住民参加型観光政策策定の有効性が実証された。特に以下の点が確認された：

1. **住民意識の向上**: 参加プロセスを通じて観光政策への理解と支持が大幅に改善
2. **政策実行力の向上**: 住民参加により策定された計画の実行率が従来比1.8倍に向上
3. **ソーシャル・キャピタルの強化**: 住民間ネットワークと集合的効力感が向上
4. **波及効果**: 観光分野での成功が他政策分野にも応用拡大

### 7.2 政策的含意
**小規模離島での住民参加促進策**:
1. 多様な参加チャネルの設置（年齢・職業・生活スタイル配慮）
2. 専門的ファシリテーション人材の活用
3. 参加の実質性確保（企画段階からの参画）
4. 継続的な情報共有・進捗報告
5. 参加者のスキル向上支援

**持続可能な参加システム構築**:
- 参加者の段階的な責任拡大
- 地域人材の育成・活用
- 参加疲れ防止の工夫
- 行政職員の能力向上

### 7.3 今後の研究課題
1. 長期的な政策効果の継続性検証
2. 他地域での再現可能性検討
3. デジタル技術活用による参加促進手法の開発
4. 住民参加と専門性のバランス最適化
