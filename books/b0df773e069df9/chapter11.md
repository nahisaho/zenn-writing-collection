# 学習の集大成 - 総合的政策立案実践

本章は本書で学んだすべての知識・スキルを統合し、実際の沖縄地域課題に対する包括的な政策提案を行う最終プロジェクトです。単なる課題解決提案ではなく、認知負債防止プロセスを徹底し、産官学民連携を視野に入れた実現可能性の高い政策立案を実践します。琉球大学混合クラスの特性を活かし、学部生の理論的思考と社会人学生の実務経験を融合した、真に価値のある政策提案を創出することを目指します。

## 11.1 プロジェクトテーマの選定と計画立案

最終プロジェクトの成功は、適切なテーマ選定と綿密な計画立案にかかっています。沖縄の実際の地域課題から社会的意義があり、かつ実行可能なテーマを選定し、認知負債を避けながら体系的なプロジェクト管理を行うことで、学習の集大成にふさわしい成果を創出します。

### 11.1.1 沖縄特有課題からのテーマ選定

沖縄の地域特性を深く理解し、真に解決が必要な課題を発見するため、認知負債防止プロセスを徹底的に実践します。現場での直接観察から始まり、段階的にAIの支援を活用しながら、最終的には自分自身の判断でプロジェクトテーマを決定する体系的なアプローチを実施します。

#### 認知負債防止による課題発見プロセス

**Phase 1（AI禁止・現場観察期）**：

```
Step 1：沖縄の地域課題を自分で観察・体験
期間：2週間
活動内容：
・地域住民との直接対話
・現地視察・フィールドワーク
・新聞・地域メディアの継続的チェック
・関係者（行政職員、事業者、NPO等）との面談

記録方法：
・手書きノートによる観察記録
・写真・動画による現状記録
・住民の生の声の記録
・自分なりの問題意識の整理

Step 2：課題の仮説設定
「現場観察から感じた課題を5つ挙げ、
それぞれについて『なぜこの問題が起きているのか』
自分なりの仮説を立ててください」

仮説設定例（石垣島観光問題）：
観察：「住民から『観光客多すぎ』『生活しづらい』の声多数」
仮説1：インフラが観光客増に対応できていない
仮説2：観光収益が地域住民に還元されていない  
仮説3：観光客のマナー・理解不足
仮説4：行政の観光政策が住民生活を軽視
仮説5：観光業界と住民の対話機会が不足

Step 3：課題の優先順位づけ
・緊急性（放置すると深刻化するか）
・重要性（多くの人々に影響するか）
・解決可能性（政策的対応が可能か）
・自分の関心・適性（取り組む意欲があるか）
```

**Phase 2（制限的AI活用・情報収集期）**：

```
Step 1：自分の仮説の検証
「私が立てた仮説について、客観的なデータや
他地域の類似事例を収集してください」

AI活用範囲：
・統計データの収集・整理
・学術論文の検索・要約
・他地域事例の調査
・関連制度・法律の情報収集

AI活用禁止範囲：
・仮説の修正・変更判断
・課題の重要度評価
・解決の方向性決定

Step 2：情報の批判的検証
収集した情報について：
・データの信頼性確認
・情報源の多様性チェック
・沖縄特有の文脈との整合性確認
・自分の現場観察との比較検討

Step 3：課題設定の精緻化
AI情報と現場観察を統合し：
・課題の本質的要因特定
・ステークホルダーの利害関係整理
・政策介入の可能性評価
```

**Phase 3（協働型・課題構造化期）**：

```
Step 1：複雑な課題構造の分析
「特定した課題について、因果関係や相互影響を
構造化して分析してください」

人間の役割：
・根本原因と表面的症状の区別
・価値判断を伴う要因の重み付け
・地域特性・文化的背景の考慮

AIの支援：
・要因間の論理的関係整理
・影響の波及経路の可視化
・複数要因の相互作用分析

Step 2：政策介入ポイントの特定
課題構造分析の結果から：
・最も効果的な介入ポイント特定
・実現可能性の高い対策領域選択
・短期・中長期対策の区別

Step 3：プロジェクトテーマの最終決定
「分析結果を踏まえ、自分が取り組む
最終プロジェクトのテーマを決定してください」

テーマ決定基準：
・課題の社会的重要性
・政策的解決可能性
・自分の専門性・関心との適合
・プロジェクト期間での実行可能性
・混合クラスでの協働効果期待
```

#### 具体的テーマ例と選定理由

**テーマ例1：「宮古島における持続可能な水資源管理政策」**

```
選定理由：
・緊急性：地下水塩水化の進行
・重要性：住民生活・観光業・農業すべてに影響
・解決可能性：技術・制度両面での対策が存在
・沖縄特有性：離島特有の水資源制約

Phase 1現場観察結果：
・住民：「井戸の水がしょっぱくなった」
・農家：「作物の収量が減っている」
・ホテル：「水質改善にコストがかかる」
・行政：「対策はしているが効果が見えない」

Phase 2情報収集結果：
・地下水位の継続的低下データ
・観光客増加と水使用量の相関
・他離島での成功・失敗事例
・水資源管理の法制度・予算措置

Phase 3構造化分析結果：
根本原因：需要増加 vs 供給限界
直接要因：観光客増、農業用水、生活用水増
間接要因：節水意識不足、料金体系、管理体制
政策介入ポイント：需要管理、供給確保、管理体制
```

**テーマ例2：「石垣市における住民参加型観光政策」**

```
選定理由：
・緊急性：オーバーツーリズムによる住民生活圧迫
・重要性：観光業と住民生活の持続的共存
・解決可能性：住民参加システムの構築可能
・協働効果：学部生の理論と社会人の実務経験融合

混合クラス特化の取り組み：
学部生貢献：
・最新の観光学理論適用
・デジタル技術活用提案
・他地域事例の体系的調査

社会人貢献：
・現実的制約・課題の指摘
・実現可能な制度設計提案
・関係者調整の実務知識

協働による付加価値：
・理論と実践の統合
・多世代の視点反映
・実現可能性の高い提案
```

### 11.1.2 プロジェクト計画書の作成

選定したテーマを成功に導くための詳細な計画書を作成します。認知負債を防ぎながらAIを効果的に活用し、限られた期間内で最大の成果を上げるための戦略的なプロジェクト管理手法を確立します。計画の段階から実現可能性を重視し、着実に成果につなげる実行力のある設計を行います。

#### 認知負債防止プロジェクト管理

**Phase 1（人間主導・基本設計）**：

```
プロジェクト基本情報の設定：

1. プロジェクト名
例：「宮古島水資源管理における住民参加型合意形成システムの構築」

2. プロジェクト期間
・全体期間：3ヶ月
・Phase別スケジュール設定

3. プロジェクト目標
・最終成果物：政策提案書（30-40頁）
・中間成果物：現状分析レポート、ステークホルダー分析
・プロセス目標：認知負債防止の実践、混合クラス協働

4. 成功指標
定量指標：
・関係者ヒアリング：最低10名
・データ分析：5年分の統計データ
・政策オプション：最低3案提示

定性指標：
・実現可能性：関係者から「実現可能」評価
・革新性：従来にない視点・手法の提示
・包括性：多様なステークホルダー視点の統合
```

**Phase 2（AI支援・詳細計画）**：

```
詳細スケジュール作成：

「以下の成果物を期限内に完成させるための
詳細スケジュールを作成してください」

Week 1-2：現状分析・課題整理
・現地調査・ヒアリング実施
・既存データ収集・分析
・先行研究レビュー
・問題構造の可視化

Week 3-4：ステークホルダー分析
・関係者マッピング
・利害関係分析
・対立点・共通点の整理
・合意形成戦略の検討

Week 5-6：政策オプション開発
・解決策のブレインストーミング
・政策手法の比較検討
・実現可能性評価
・効果予測・リスク分析

Week 7-8：統合・提案書作成
・最適政策案の設計
・実施計画の詳細化
・予算・体制計画
・評価指標設定

Week 9-10：発表準備・最終調整
・プレゼンテーション資料作成
・質疑応答準備
・提案書の最終調整

リスク要因と対策：
・データ入手困難：複数ルートでの情報収集
・関係者協力拒否：事前の十分な説明・調整
・分析の行き詰まり：指導教員・メンターとの相談
・時間不足：優先順位の明確化・効率化
```

**Phase 3（協働型・実行計画）**：

```
役割分担と協働体制：

個人プロジェクトの場合：
・自分の専門性・関心領域での主導
・AI支援範囲の明確化
・外部協力者（指導教員、実務家等）との連携

グループプロジェクトの場合：
混合チーム構成例：
・学部生2名：理論分析・技術活用担当
・社会人学生1名：実務調整・実現可能性評価
・全体リーダー：プロジェクト統括・最終判断

協働プロセス設計：
・週1回の定例会議
・役割分担の明確化
・成果物の相互レビュー
・意思決定プロセスの明文化

品質管理体制：
・中間発表での外部評価
・専門家レビューの組み込み
・認知負債防止チェック
・倫理・リスク評価
```

## 11.2 実践的政策研究の実施

テーマが決定したら、実際の政策研究を本格的に開始します。認知負債防止を徹底しながら、フィールドワーク、データ分析、ステークホルダー分析を通じて現状を多角的に把握し、課題の本質と構造を明らかにします。理論と実践を統合した高次の分析力を発揮する研究実施段階です。

### 11.2.1 現状分析と課題構造化

課題解決の前提となる現状の正確な把握と課題の構造化を行います。主観的な印象や先入観に頼らず、フィールドワークによる直接観察とデータ分析による客観的把握を組み合わせ、多面的かつ深層的な現状理解を実現します。

#### フィールドワークによる現状把握

**認知負債防止のフィールドワーク設計**：

```
Phase 1（人間主導・直接観察）：

現地調査計画：
期間：2週間（週末含む）
場所：対象地域の多様な場所
・住宅地域（朝・昼・夜の観察）
・商業地域（平日・休日の比較）
・観光地域（季節・時間による変化）
・行政機関（窓口業務の観察）

観察項目：
・住民の表情・行動パターン
・交通・混雑状況
・環境・景観の状況
・サービス提供の実態

記録方法：
・手書きフィールドノート
・写真・動画（許可を得て）
・住民との非公式対話内容
・自分の印象・感想

注意事項：
・先入観を排除した観察
・多様な時間・場所での観察
・異なる立場の人々との接触
・プライバシー・倫理への配慮
```

**ステークホルダー・ヒアリング**：

```
Phase 1（事前準備・人間主導）：

ヒアリング対象者の選定：
・行政関係者：担当課長・係長、現場職員
・事業者：組合代表、個人事業者
・住民：自治会長、一般住民、高齢者・若者
・専門家：研究者、コンサルタント
・その他：NPO代表、観光客等

ヒアリング質問設計：
基本方針：オープンエンドな質問中心
「現在の状況をどう感じていますか？」
「一番困っていることは何ですか？」  
「理想的にはどうなってほしいですか？」
「そのために何が必要だと思いますか？」

Phase 2（実施・記録）：
・1人あたり30-60分の面談
・ICレコーダー使用（許可を得て）
・その場でのメモ取り
・非言語情報（表情・声のトーン）の記録

Phase 3（整理・分析準備）：
・ヒアリング内容の文字起こし
・発言者別・テーマ別の整理
・共通点・相違点の抽出
・定量化可能な要素の特定
```

#### データ分析による客観的現状把握

**Phase 2（制限的AI活用・データ処理）**：

```
統計データ分析：

収集すべきデータ：
・人口動態（過去10年の推移）
・経済指標（観光収入、就業者数等）
・インフラ利用状況（交通量、水道使用量等）
・住民意識調査（既存アンケート結果）
・関連予算・事業実績

AI活用範囲：
・大量データの整理・集計
・トレンド分析・可視化
・統計的相関関係の計算
・グラフ・チャート作成

AI活用例：
「以下の宮古島観光データについて、
過去5年の傾向を分析し、グラフで可視化してください」
- 年別観光客数
- 月別観光客数分布  
- 観光消費額推移
- ホテル稼働率
- 交通量データ

人間が担当する分析：
・データの解釈・意味づけ
・異常値・変化要因の考察
・地域文脈での位置づけ
・政策的含意の抽出
```

**ヒアリング内容の質的分析**：

```
Phase 3（協働型・パターン分析）：

テキストマイニング活用：
AI支援作業：
・頻出語句の抽出・計数
・感情分析（ポジティブ・ネガティブ）
・発言内容のカテゴリー分類
・ステークホルダー間の意見相違点整理

人間主導作業：
・発言の背景・文脈理解
・言葉にされない想いの読み取り
・利害関係の深層分析
・政策ニーズの本質的把握

統合分析例：
「ヒアリング結果から、水資源問題に対する
各ステークホルダーの認識を整理してください」

住民：「水道料金は上がるが水質は改善しない」
事業者：「設備投資したいが将来が不安」
行政：「予算制約がある中で最善を尽くしている」
専門家：「技術的解決策はあるが合意形成が課題」

→ 各立場の論理・制約・要望を構造化
→ 対立点と合意可能点の特定
→ 政策介入の優先順位設定
```

### 11.2.2 政策オプションの開発と評価

現状分析の結果を踏まえ、課題解決のための具体的な政策オプションを開発・評価します。創造性と実現可能性のバランスを取りながら、多様な選択肢を生成し、科学的・合理的な評価基準に基づいて最適な政策案を選択します。AIの情報処理能力と人間の創造力・判断力を効果的に組み合わせます。

#### 創造的政策案の生成

**Phase 1（人間主導・アイデア創出）**：

```
ブレインストーミング・セッション：

Step 1：制約なし発想（30分）
「水資源問題を解決するアイデアを
実現可能性を考えずに自由に発想してください」

発想例：
・海水淡水化プラント建設
・雨水貯蔵システム全島展開
・観光客から水資源税徴収
・節水アプリで住民意識向上
・地下水使用量の完全管理制
・本島からの海底送水管
・人工降雨技術の導入

Step 2：制約条件の考慮（20分）
・予算制約：宮古島市の財政規模
・技術制約：現在の技術水準・維持管理能力
・社会制約：住民・事業者の受容性
・法制制約：関連法律・制度の制約
・時間制約：効果発現までの期間

Step 3：実現可能性評価（30分）
各アイデアについて：
・技術的実現可能性（1-5点）
・経済的実現可能性（1-5点）
・社会的受容性（1-5点）
・政策的実現可能性（1-5点）
・効果の確実性（1-5点）
```

**Phase 2（AI支援・政策手法研究）**：

```
他地域事例研究：

「水資源管理で成功している類似地域の
政策手法を調査し、宮古島への適用可能性を
分析してください」

調査対象例：
・沖縄本島：水資源管理システム
・小笠原諸島：離島水資源確保策
・バリ島：観光地での水資源管理
・シンガポール：水資源自給政策
・オーストラリア：干ばつ対策

分析観点：
・政策手法の種類（規制・誘導・情報提供等）
・実施体制・予算規模
・効果・成果の測定結果
・課題・失敗要因
・宮古島への適用可能性

AIの役割：
・大量の事例情報収集・整理
・政策手法の分類・体系化
・成功要因の抽出・分析
・適用条件の比較分析

人間の判断：
・地域特性との適合性評価
・政治的・社会的実現可能性判断
・優先順位・組み合わせの決定
```

**Phase 3（協働型・統合政策設計）**：

```
包括的政策パッケージ作成：

政策体系の設計：
1. 短期対策（1-2年）
・緊急性の高い課題への即効策
・既存制度の改善・強化
・住民意識啓発・行動変容促進

2. 中期対策（3-5年）
・インフラ整備・技術導入
・制度・体制の抜本的見直し
・財源確保・事業実施

3. 長期対策（5-10年）
・持続可能な管理システム確立
・地域経済・社会との統合
```
