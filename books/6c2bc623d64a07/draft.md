### 第6章　学びの質を高める評価革命（新規執筆）

#### 第1節　形成的評価の日常化
**主人公：早川先生（中学校5年目、数学科）**
**設定詳細：**
```
背景：「テストでしか生徒の理解度がわからない」という課題
課題：授業中のリアルタイム理解度把握の困難
現状：50分授業×6クラス、生徒180人の指導
目標：日常的な学習プロセス可視化システムの構築
```

**具体的シナリオ：**
1. **問題の具体化**
   - 定期テストで突然低得点を取る生徒の存在
   - 「わかった」と言いながら実際は理解していない現象
   - 授業後に「実はわからなかった」と相談に来る生徒

2. **AI活用システム構築**
```
プロンプト例：
「中学数学の授業で、生徒の理解度をリアルタイムで把握し、
即座にフィードバックできるシステムを設計してください。

【制約条件】
- 50分授業、35人クラス
- 1人1台タブレット環境
- 教師のスキル：一般的なICT活用レベル

【求める機能】
- 理解度の即座の可視化
- つまずきポイントの特定
- 個別フィードバックの自動生成
- 学習軌跡の記録・分析」
```

3. **効果測定と改善**
   - 理解度把握精度：従来20% → AI活用後85%
   - 生徒の質問率：授業中5% → 25%（心理的安全性向上）
   - 学習定着率：60% → 82%

#### 第2節　多面的評価システムの構築
**主人公：西田先生（小学校17年目、6年生担任）**

**設定の深化：**
```
背景：「テストの点数だけでは表せない生徒の良さ」への問題意識
具体例：
- 努力型のA子：テストは平均点だが、継続的な成長を見せる
- 創造型のB君：独創的なアイデアを持つが、記述式テストは苦手
- 協働型のC君：チームワークに長けるが、個人評価では見えない
```

**AIプロンプト活用例：**
```
「小学6年生30人に対して、テストでは測れない能力を
多面的に評価するシステムを提案してください。

【評価したい能力】
- 創造性・独創性
- 協働性・チームワーク
- 継続性・粘り強さ
- 批判的思考力
- コミュニケーション力

【利用可能なデータ】
- 日常の授業観察記録
- プロジェクト活動の成果物
- ポートフォリオ作品
- ピア評価結果
- 自己振り返り記録」
```

#### 第3節　21世紀型スキルの評価方法

従来評価の限界：

## 【執筆時の重要な注意点】

### 1. 既存章との整合性
- 登場人物の設定・性格を一貫させる
- 学校種・教科・経験年数などの設定を統一
- AIプロンプトの形式・品質レベルを合わせる
- 数値データの信憑性を保つ

### 2. 段階的成長ストーリー
- 各章で教師が段階的に成長する流れを描く
- 失敗→気づき→改善→成功のパターンを維持
- 小さな変化から大きな変革への発展を表現

### 3. 実践的価値の担保
- すべてのAIプロンプトは実際に使用可能なレベル
- 効果測定は現実的な数値範囲内
- 制約条件（時間・予算・スキル）を明確に設定

### 4. 希望と現実のバランス
- 課題提示→解決策提示→成果確認の構造
- 完璧な解決ではなく、改善・向上を目指す姿勢
- 読者が「自分にもできそう」と感じられる内容

### 5. 読者との距離感
- 教師の等身大の悩みと成長を描く
- 上から目線ではなく、寄り添う姿勢
- 専門用語は最小限に抑え、具体例で補強
