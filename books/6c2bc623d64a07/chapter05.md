# 第1節　PBL（問題解決学習）のAI支援設計

第4章で個別最適化学習システムの構築方法を学んだ先生方から、新たな相談が寄せられるようになりました。中学校9年目の内田先生(仮名)も、その一人でした。

第3章の診断で「創造性・協働型」の理想を持つことがわかった内田先生は、こう語っていました。

「個別最適化の実践で、一人ひとりの学習特性が見えてきました。でも私の理想は、それを活かしてみんなで一緒に創造的な問題解決に挑戦することなんです。個別最適化の次のステップとして、協働的で創造的な学びをどう実現すればいいでしょうか？」

内田先生が直面していたのは、多くの教師が経験するジレンマでした。個別最適化はうまくいった、でもその次のステップである「協働的で創造的な学び」をどう実現するか。これは、あなたもいずれ直面する課題かもしれません。

「地球温暖化をテーマにしたPBLを実施したが、生徒たちは情報収集に終始して、本当の問題解決に至らない。調べ学習の域を出ないし、深い思考や創造的な解決策が生まれない。PBLって、こんなに難しいものなのか？」

「PBLって理論的には素晴らしいんですが、実際の教室ではなかなか…」という内田先生の悩みは、まさに多くの教師が直面する現実でした。

もしかすると、あなたも同じような経験をお持ちではないでしょうか？「PBLやってみたいけど、どうやって始めればいいのかわからない」「調べ学習で終わってしまいそうで怖い」といった不安をお持ちかもしれません。

## 従来のPBL実践の課題

**よくある問題点**
- 問題設定が曖昧で生徒が混乱
- 情報収集活動に終始してしまう
- グループ内で役割分担が不均等
- 教師の適切な支援タイミングがわからない
- 評価基準が不明確で学習効果が測定できない

**生徒の反応**
- 「何をすればいいかわからない」
- 「調べただけで終わってしまう」
- 「みんなで同じ作業をしている感じ」
- 「本当に解決できている実感がない」

ここで、序論でお話しした「教育理論の実践化」が再び威力を発揮します。従来の「伝統的な授業」から「協働的で創造的な学び」への転換を、生成AIが可能にしてくれるのです。

内田先生は、私が研修で紹介した「構成主義学習理論」と「社会的学習理論」を実際の教室で実践するために、生成AIを活用した効果的なPBL授業設計に挑戦することにしました。

2. **複雑性**：技術・経済・社会的側面が絡む複合問題

**2. 表面的議論の深化支援**
```

深化技法：
- 根拠の明確化要求

「○○さんの意見は素晴らしいですね。今度は

「□□さんらしい視点での意見を聞かせてください」

- 役割ローテーション制の導入

**4. 方向性逸脱の修正支援**
```
診断指標：

「最初の問題設定を確認しましょう。今の活動は

「校長先生への提案として、これで説得力はありますか？」
「実際に実行するとしたら、何が障害になりそうですか？」

修正手法：
- 目標の再確認
- 成果物イメージの具体化
- 制約条件の再認識
- タイムライン見直し
```

**5. 創造性・深い思考の促進**
```
促進質問例：
「常識を疑ってみましょう。『当たり前』とされていることは
 本当に変えられないのでしょうか？」
「この問題を別の角度から見ると、どう見えますか？」
「100年後の人が見たら、どんな解決策を思いつくでしょう？」

このガイドにより、教師は学習の促進者として効果的に機能できます。」

# 第2節　探究学習の深化と成果創出

高校14年目の森川先生(仮名)は、「総合的な探究の時間」の責任者として、生徒たちの探究活動に大きな可能性を感じていた。しかし、同時に多くの課題も抱えていた。

「生徒たちの探究テーマは多様で興味深いものが多い。でも、多くが表面的な調査で終わってしまい、本当の『探究』になっていない。深い思考や新しい発見、価値創造につながる探究活動にするには、どうすればいいのだろう？」

森川先生の悩みは、全国の高校で共通する探究学習の課題だった。制度として導入された探究学習だが、その質的向上は大きな挑戦となっている。

## 探究学習の現状と課題

**よくある探究活動の問題**
- テーマ設定が漠然としている
- 既存情報の収集・整理に終始
- 仮説検証の方法論が不十分
- 個人作業で協働性が低い
- 成果の社会的インパクトが小さい

**生徒の声**
- 「何を探究すればいいかわからない」
- 「調べたことをまとめただけになってしまう」
- 「本当に新しいことを発見できるのか疑問」
- 「最終発表で終わってしまうのがもったいない」

森川先生は、生成AIを活用して探究学習の質的向上と成果創出を目指すことにした。

## 森川先生のAI活用探究学習深化実践

**STEP1：探究テーマの最適化**

```
プロンプト：
「高校生の探究学習で、以下の条件を満たすテーマ設定支援を行いたいです：

- 生徒の興味・関心と社会的意義の両立
- 高校生レベルで実行可能な研究方法
- 新しい発見や価値創造の可能性
- 地域・社会への具体的貢献
- 1年間で成果を出せる現実的スケール

以下の生徒の興味から、具体的な探究テーマを提案してください：

生徒A：「音楽と心理学に興味。人の気持ちに音楽がどう影響するか知りたい」
生徒B：「環境問題と技術に関心。身近なところから環境改善をしたい」
生徒C：「高齢者福祉に興味。おじいちゃんおばあちゃんの役に立ちたい」」
```

AIが提案した探究テーマ：

「各生徒の興味を社会的価値創造につなげる探究テーマを設計しました。
