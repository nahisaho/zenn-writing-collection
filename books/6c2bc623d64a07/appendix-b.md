# 付録B　キャリア段階別AI活用ガイド

## 付録Bの目的と構成

教師のキャリア段階によって、求められる能力や直面する課題は大きく異なります。本付録では、新任期から管理職まで、各段階に応じた最適なAI活用方法と成長支援を提供します。

各段階の特性を理解し、段階に応じた適切なAI活用により、教師としての専門性を効果的に発達させることができます。

---

## B-1　新任期（1-5年目）：基礎力構築とAI活用入門

### 新任期の特徴と課題
新任期は教師としての基礎を築く重要な時期です。多くの新しい経験に直面し、日々の業務に追われがちですが、この時期にAIを適切に活用することで、効率的な成長と確実な基礎力構築が可能になります。

### 段階的AI導入プログラム

#### 第1年目：観察とデータ収集の習慣化

**4-6月：基礎的な記録習慣の確立**
```markdown
【AI活用プロンプト例】
生徒: 田中太郎、授業中の様子: 数学の授業で手を挙げる頻度が低い、宿題提出率90%、友人関係は良好
この生徒の学習支援として考えられる方法を3つ提案してください。それぞれの方法について、実施手順と期待される効果も含めてください。
```

**7-9月：個別指導への基礎的AI活用**
```markdown
【学習支援プロンプト例】
小学3年生で掛け算の九九に苦手意識を持つ生徒への指導案を作成してください。
- 楽しく取り組める方法
- 段階的な習得プロセス
- 家庭でも実践できる方法
を含めてください。
```

**10-12月：授業改善への応用**
```markdown
【授業リフレクション支援】
今日の授業内容: 小数の足し算
生徒の反応: 理解できた生徒70%、質問が多かった内容: 小数点の位置
この授業の改善点と次回の授業でのフォロー方法を提案してください。
```

#### 第2年目：個別指導へのAI活用本格化

**個別の学習計画作成支援**
```markdown
【個別最適化プロンプト】
生徒プロフィール:
- 学年: 中学1年生
- 特徴: 理解は早いが集中力が続かない、視覚的学習が得意
- 現在の課題: 英語の文法理解
この生徒に適した1週間の学習計画を作成してください。
```

**保護者面談準備支援**
```markdown
【面談準備プロンプト】
生徒の状況:
- 学習面: 国語は得意、算数に苦手意識
- 生活面: 友達関係は良好、忘れ物が多い
- 行動面: 積極性はあるが、最後まで集中することが課題
保護者面談で話すべき内容とアドバイスを整理してください。
```

#### 第3年目：授業設計の高度化

**単元計画の体系的設計**
```markdown
【単元設計支援】

- 全8時間の授業構成
- 各時間の目標と活動
- 評価方法
- ICT活用のポイント
を含む単元計画を作成してください。
```
