# Copilot Chatへのアクセスと基本操作

## この章の目的

Copilot Chatへの安全なアクセス方法と基本的な操作方法を習得し、大学教員として適切に活用するための第一歩を踏み出します。本章では、技術的な詳細よりも実践的な使い方に焦点を当て、明日からすぐに教育・研究業務で活用できる基礎スキルの習得を目指します。

:::message
重要: 本章の内容は2025年1月時点の情報に基づいています。Microsoft 365 Copilot Chatは継続的に更新されているため、画面構成や機能の詳細は変更される可能性があります。最新情報は組織のIT部門にご確認ください。
:::

## 3.1 アクセスと基本操作

### 3.1.1 Copilot Chatへのアクセス方法

大学教員がCopilot Chatを利用する際は、必ず組織アカウントでアクセスすることが重要です。個人アカウントでのアクセスは、エンタープライズデータ保護（EDP）が適用されず、セキュリティリスクが生じるため避けてください。

#### Web版でのアクセス（推奨）

Web版は最も簡単で確実なアクセス方法です。特別なソフトウェアのインストールが不要で、どのパソコンからでも利用できます。

**アクセス手順**：
https://m365.cloud.microsoft.com/chat に直接アクセスし、組織アカウントでサインインしてください。このURLをブックマークに登録しておくと便利です。なお、https://office.com、https://portal.office.com、https://copilot.microsoft.com（旧URL）といったURLにアクセスした場合でも、すべて自動的にこのURLにリダイレクトされます。

**推奨ブラウザ**：
最も互換性が高いのはMicrosoft Edge（最新版）ですが、Google Chrome（最新版）、Firefox（最新版）、Mac利用者向けのSafari（最新版）でも快適にご利用いただけます。

:::message alert
Internet Explorer 11はサポート終了のため使用できません。必ず最新のブラウザをご利用ください。
:::

#### モバイルアプリでのアクセス

外出先や移動中でも利用できるモバイルアプリが提供されています。ただし、Intuneで管理されていない端末で研究データを扱う場合は、紛失・盗難リスクを考慮し、使用を控えることをお勧めします。

**インストール方法**：
iOSをご利用の場合はApp Store、Androidをご利用の場合はGoogle Playで「Microsoft 365 Copilot」を検索してください。なお、2025年1月に旧Microsoft 365アプリから名称変更されています。インストール後は必ず組織アカウントでサインインしてご利用ください。

#### Microsoft 365アプリ内でのアクセス（2025年5月以降）

2025年5月1日以降、段階的なロールアウトにより、Microsoft 365 Copilot Chat がMicrosoft 365 Copilotアプリ、Teams、Outlookのナビゲーションバーに既定でピン留めされます。2025年7月以降は、Word、Excel、PowerPoint、OneDrive等の他のMicrosoft 365アプリにも展開される予定です。これにより、作業中のアプリを離れることなくAI支援を受けられます。

### 3.1.2 画面構成と主要機能

Copilot Chatの画面は、シンプルで直感的に設計されています。初めて使用する方でも迷わず操作できる構成になっています。

#### 基本画面の構成要素

**1. チャット入力エリア（画面下部）**
ここに質問や依頼を入力します。文字数制限はライセンスや時期により変動する可能性があり、改行も使用できるため、複雑な指示も分かりやすく記述できます。制限に達した場合は、複数回に分けて送信してください。

**2. 会話表示エリア（画面中央）**
あなたの質問とCopilotの回答が時系列で表示されます。過去の会話を参照しながら、文脈を保った対話が可能です。

**3. セキュリティインジケーター（画面上部）**
緑色のシールドアイコンが表示されていれば、エンタープライズデータ保護（EDP）が有効です。このアイコンが表示されていることを必ず確認してください。

**4. 新しいチャットボタン**
新しい会話を開始する際に使用します。前の会話の文脈をリセットし、新たなトピックについて質問できます。

**5. 機能メニュー**
画面上部には各種機能メニューが配置されています。ファイルアップロード機能では、PDF、Word、Excel、PowerPointなどのファイルを分析できます。画像生成機能により、テキストから画像を生成することも可能ですが、著作権には十分注意してください。また、ContextIQという機能では「/」を入力すると、関連するファイルや人物を提案してくれます。

#### 重要な表示確認

教育・研究業務で使用する前に、必ず確認すべき表示があります。まず、緑色のシールドアイコンが表示されていることを確認してください。これはEDP（エンタープライズデータ保護）が有効であることを示しています。次に、組織名の表示を確認し、サインインしているアカウントの組織名が正しいかを確認してください。最後に、「保護されています」という文字が表示されていることで、データ保護が適用されていることを確認できます。

### 3.1.3 基本的な会話の流れ

効果的にCopilot Chatを活用するためには、適切な会話の進め方を理解することが重要です。AIとの対話は人間同士の会話とは異なる特性があり、それを理解した上で活用することで、より良い結果を得られます。

#### 効果的な会話開始の方法

**1. 明確な目的設定から始める**
最初に何を達成したいかを明確に伝えることで、的確な回答を得やすくなります。

良い例：
```
## あなたの役割
○○大学○○学部の教員として、1年生向けの基礎講義を担当する立場

## 作成内容
第1回授業のシラバス説明資料

## 対象・目的
- 対象：○○学部1年生
- 目的：授業の目標と学習内容の理解促進

## 含める要素
- 授業の目標・到達目標
- 各回の授業内容（15回）
- 評価方法・基準
- 教科書・参考書
- 履修上の注意事項

## スタイル
- トーン：新入生にも理解しやすく、学習への動機を高める
- 長さ：A4用紙2枚程度
- 形式：スライド形式（見出し・箇条書き）
```

避けるべき例：
```
授業資料作って
```

**2. 段階的な情報提供**
一度にすべての情報を詰め込むのではなく、段階的に情報を追加していくことで、より精度の高い結果を得られます。

初回の質問：基本的な要件を伝える
追加の指示：詳細な要件や修正点を伝える
最終調整：細かい表現や形式の調整

**3. 文脈を活用した継続的な対話**
Copilot Chatは会話の文脈を記憶しているため、前の回答を踏まえた追加質問や修正依頼が可能です。

例：
- 「先ほどの資料の専門用語をもう少し初学者向けに修正してください」
- 「3番目のセクションをもう少し詳しく説明してください」
- 「箇条書きの部分を文章形式に変更してください」

#### 会話終了時の重要な確認事項

**1. 個人情報の確認**
生成された内容に、意図せず個人情報が含まれていないか必ず確認してください。特に例示で使用した情報が残っていないか注意が必要です。

**2. 事実確認の必要性**
生成された内容の事実関係、特に日付、数値、制度名などは必ず原資料と照合してください。

**3. 保存と記録**
有用な回答は、適切な方法で保存してください：
- テキストファイルとして保存
- 学科共有フォルダーへの保管（個人情報を除去後）
- 今後の参考のためのプロンプト記録

## 3.2 効果的なプロンプトの基礎

プロンプトとは、AIに対する指示や質問のことです。プロンプトの質が、得られる回答の質を大きく左右します。ここでは、大学教員の業務に適した効果的なプロンプトの作成方法を学びます。

### 3.2.1 良いプロンプトの6つの要素

効果的なプロンプトには共通する6つの要素があります。これらを意識することで、期待する回答を得やすくなります。

#### 1. 明確な目的・ゴールの設定

何を達成したいかを具体的に記述することが最も重要です。曖昧な指示では、期待とは異なる回答が返ってくる可能性が高くなります。

**良い例**：
```
## あなたの役割
○○大学○○学部の教員として、研究方法論を教授し、学生の研究スキル向上を支援する専門家

## 作成文書
卒業論文テーマ選定ガイダンス資料

## 対象読者
学部4年生

## 含める項目
- テーマ選定の基本原則
- 研究可能性の評価基準
- 文献調査の重要性
- 指導教員との相談方法
- スケジュール管理のポイント

## 仕様
- 分量：A4用紙2枚以内
- 形式：見出し付きの説明文
- トーン：学術的だが親しみやすい
```

**改善が必要な例**：
```
論文の書き方を説明してください。
```

#### 2. 適切なコンテキスト（背景）情報の提供

AIは与えられた情報の中で最適な回答を生成します。背景情報を提供することで、より適切で実用的な回答を得られます。

**コンテキストに含めるべき情報**：
- 文書の対象者（学部生、院生、同僚教員、一般の方など）
- 使用場面（授業、ゼミ、学会発表、論文執筆など）
- 学部・学科の特性（理系・文系、研究分野の特徴など）
- 時期的な要因（学期初め、就職活動時期、卒論提出時期など）

#### 3. 具体的な指示と制約条件

実行してほしい作業を詳細に指定し、同時に避けてほしい内容も明示します。

**指示の例**：
```
## あなたの役割
○○大学○○学部の教員として、学生の学習意欲を高め、学術的思考力を育成する立場

## 作成文書
ゼミ発表評価シート

## 対象・条件
- 対象：学部3年生のゼミ発表
- 評価項目：5-7項目
- 各項目：4段階評価

## 必須項目
- 研究内容の理解度
- 発表構成・論理性
- 資料・スライドの質
- 質疑応答での対応
- 時間管理能力

## 制約事項
- 避ける：曖昧な評価基準、主観的すぎる項目
- トーン：建設的で学習改善に資する表現
- 形式：チェックシート（評価基準明記）
```

#### 4. 期待する品質と形式の明示

どのような形式で、どの程度の品質を求めているかを明確にします。

**形式指定の例**：
- 箇条書き形式
- 段落形式の説明文
- Q&A形式
- 表形式
- スライド形式（見出し、箇条書き、図表含む）

#### 5. 検証可能な出力仕様

生成された内容が要件を満たしているか確認できるよう、具体的な基準を設定します。

**検証基準の例**：
- 「必ず参考文献リストを含めてください」
- 「重要なポイントを太字で強調してください」
- 「全体を3つのセクションに分けてください」

#### 6. 出力サンプルの提示

期待する出力の具体例を示すことで、より意図に近い文書を作成できます。

**出力サンプル付きプロンプトの例**：
```
## 作成内容
学部生向けレポート課題説明文

## 出力サンプル
【課題名】現代社会における○○問題の分析

【目的】
本課題では、現代社会の具体的な問題を取り上げ、学術的な視点から分析・考察を行うことで、批判的思考力と論理的表現力を身につけることを目的とします。

【課題内容】
1. 問題の現状と背景の整理
2. 複数の観点からの分析
3. 解決策の提案と検討

【提出要件】
・文字数：2000-3000字
・提出期限：○月○日（○）23:59まで
・提出方法：学習管理システム経由

## 作成要件
- 上記サンプルの形式・構成に従う
- 具体的日付は「○月○日（○）」で表記
- 学習目標を明確に表現
- 学術的な課題設定を意識
```

### 3.2.2 大学教育・研究業務に特化したプロンプト作成法

大学という教育・研究機関特有の価値観や制約を踏まえたプロンプト作成が重要です。

#### 教育・研究機関としての配慮を含める

大学は教育・研究機関として、営利企業とは異なる価値観や使命を持っています。この点をプロンプトに反映させることで、より適切な回答を得られます。

**配慮すべき要素**：
- 学術的価値の重視
- 公平性・透明性の確保
- 多様性への配慮
- 学生の学習・成長支援の視点
- 研究倫理の遵守

**プロンプト例**：
```
## あなたの役割
○○大学○○学部の教員として、学生の学術的成長と批判的思考力の育成を使命とする専門教育者

## 作成内容
研究発表会での学生コメント・フィードバック

## 基本方針
教育機関として学生の学びと成長を最優先に支援する姿勢を表現

## 含める要素
- 発表の優れた点（具体的に）
- 改善提案（建設的に）
- さらなる発展のための助言
- 学術的探究心を刺激する質問

## 表現要件
- トーン：学生の自信を育てつつ、向上心を刺激する
- 必須項目：次のステップへの具体的提案
- 形式：個別フィードバック（各学生200字程度）
```

#### リスク回避のための制約設定

個人情報保護や法的リスクを避けるため、明確な制約を設定します。

**必須の制約事項**：
```
## 禁止事項
- 個人名、学籍番号の記載
- 具体的な成績情報の記載
- 「必ず」「絶対」等の断定的表現

## 避けるべき内容
- 法的助言と受け取られる表現
- 医学的助言と受け取られる表現
- 特定の政治的・宗教的立場

## 必須項目
- 最終判断は担当部署確認を促す文言
- 問い合わせ先の明記
```

### 3.2.3 プロンプトの改善と調整

初回のプロンプトで完璧な回答を得られることは稀です。段階的に改善・調整することで、より良い結果を得られます。

#### 段階的な改善アプローチ

**Step 1: 基本プロンプトで大枠を確認**
まず簡潔なプロンプトで基本的な回答を得て、方向性を確認します。

**Step 2: 詳細な要件を追加**
基本的な回答を見て、不足している要素や修正が必要な部分を特定し、追加指示を出します。

**Step 3: 細部の調整**
表現のトーン、専門用語の使用、文章の長さなど、細かい調整を行います。

**実例**：
```
初回：「研究倫理に関する授業資料を作成してください」
↓
追加：「学部2年生を対象とし、事例を含めて具体的に説明してください」
↓
調整：「もう少しインタラクティブな構成にして、グループディスカッション用の質問を3つ追加してください」
```

## 3.3 教員業務での初歩的な活用例

実際の教育・研究業務でよく使用される基本的な活用例を、具体的なプロンプトとともに紹介します。これらの例を参考に、自分の専門分野に応じたプロンプトを作成してみましょう。

### 3.3.1 授業準備・教材作成支援

授業資料や教材の準備は、Copilot Chatが得意とする分野の一つです。ただし、著作権のある資料や学生の個人情報は使用しないよう注意してください。

#### 講義資料の構成案作成

**プロンプト例**：
```
## あなたの役割
○○大学○○学部の教員として、学生の理解を深め、学術的興味を引き出す質の高い講義を提供する教育専門家

## 作成内容
「○○学概論」第5回講義の構成案

## 形式・制約
- 形式：90分講義の詳細構成（時間配分含む）
- 対象：学部1年生（専門知識は基礎レベル）
- テーマ：○○の歴史的発展と現代的意義

## 含める要素
- 導入（前回の復習・今回の位置づけ）
- 主要内容（3-4の柱立て）
- 学生参加型活動（グループディスカッション等）
- まとめ（次回への橋渡し）
- 時間配分（各セクション）

## 注意事項
- 専門用語は適切に説明
- 学生の関心を引く具体例を含める
- 理論と実践のバランスを考慮
```

**活用のポイント**：
- 授業の流れを時系列で明確に指定する
- 学生のレベルに応じた内容調整を依頼する
- インタラクティブな要素を必ず含める

### 3.3.2 学生へのフィードバック作成

学生のレポートや発表に対するフィードバック作成を効率化できます。

#### レポート評価コメントの改善

**プロンプト例**：
```
## あなたの役割
○○大学○○学部の教員として、学生の学術的成長を促し、建設的なフィードバックを通じて学習意欲を高める指導者

## 修正内容
学部生レポート評価コメントの改善

## 対象レポート
○○に関するレポート（2000字程度）

## 修正方針
- 優れた点を具体的に評価
- 改善点を建設的に指摘
- 今後の学習への動機づけ

## 現在のコメント案
「良く調べて書けています。ただし、論理構成に改善の余地があります。」

## 期待する改善点
- 具体的な評価ポイントの明示
- 改善方法の具体的提案
- 学習意欲を高める表現
```

**改善後の例**：
```
【優れている点】
○○についての文献調査が丁寧で、複数の観点から問題を整理できています。
特に△△の論点については、的確な分析ができており、この分野への理解の深さを感じます。

【改善提案】
論理構成について、以下の点を改善すると、より説得力のある論考になります：
1. 序論で全体の論理構造を明示する
2. 各段落の冒頭で段落の目的を明確化する  
3. 結論部で全体を通じた自分の見解を明確に述べる

【次へのステップ】
この分野への関心と理解力を活かして、次回は○○の観点からも検討してみてください。
きっと新たな発見があると思います。
```

### 3.3.3 研究支援での活用

研究計画の立案や文献整理などの研究活動を支援できます。

#### 研究計画の構成検討

**プロンプト例**：
```
## あなたの役割
○○分野の研究者として、学術的価値の高い研究を企画し、研究計画の論理的構成を支援する専門家

## 作成内容
研究計画書の構成案（競争的資金申請用）

## 研究テーマ
○○に関する実証研究

## 含めるセクション
1. 研究の背景と目的
2. 研究の学術的・社会的意義
3. 研究方法
4. 研究計画・スケジュール
5. 期待される成果

## 構成要件
- 各セクションの目的と主要な記載内容
```

## 3.4 基本操作における注意事項

### 3.4.1 してはいけないこと

Copilot Chatを安全に利用するため、以下の行為は絶対に避けてください。

#### 絶対に入力してはいけない情報

1. **個人を特定できる情報**
   - 学生の氏名、学籍番号
   - 教職員の個人情報
   - 研究参加者の連絡先

2. **研究・教育機密情報**
   - 未発表の研究データ
   - 学生の成績・評価情報
   - 教授会・委員会の非公開審議内容

3. **第三者の創作物**
   - 他大学の資料をそのままコピー
   - 書籍や論文の長文引用
   - 著作権で保護された画像やデータ

### 3.4.2 常に意識すべきセキュリティ

#### 利用前の確認事項

Copilot Chatを利用する前に確認すべき重要な点があります。まず、緑色のシールドアイコンが表示されているかを確認し、組織アカウントでサインインしているかを確かめてください。また、公共の場所では画面を他人に見られないよう注意することも重要です。

#### 利用後の確認事項

Copilot Chatを利用した後にも重要な確認作業があります。生成された内容に個人情報が含まれていないか、機密情報が意図せず含まれていないかを必ずチェックしてください。さらに、生成された内容を保存する場合は適切な場所に保管されているかも確認が必要です。

### 3.4.3 効果的な活用のためのヒント

#### 時間帯による使い分け

Copilot Chatの効果的な活用には時間帯による使い分けが有効です。朝の時間帯には1日の授業・研究計画やToDoリストの作成に活用し、日中は即座の文書作成や情報整理に役立てることができます。夕方には1日の振り返りや翌日の準備を行う際の支援ツールとして活用するのが効果的です。

#### プロンプトのテンプレート化

よく使用するプロンプトはテンプレートとして保存しておくと便利です。具体的には、授業資料作成用テンプレート、学生フィードバック用テンプレート、研究計画作成用テンプレートなどを事前に用意しておくことで、効率的な作業が可能になります。
