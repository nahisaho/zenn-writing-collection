# Book Draft - Agent AI プロトタイプ開発入門 - ローカル環境とオープンソースツールによる実践ガイド

## 基本情報
- **タイトル**: Agent AI プロトタイプ開発入門 - ローカル環境とオープンソースツールによる実践ガイド
- **対象読者**: AI開発に興味がある開発者、エンタープライズ環境でのAI活用を検討している技術者、プライバシーを重視したAI開発を行いたい方
- **書籍概要**: ローカル環境でAgent AIのプロトタイプを開発するための実践的なガイド。LM Studio、Dify、n8n、Dockerを活用し、Windows 11とWSL環境でセキュアなAI開発環境を構築する方法を解説。
