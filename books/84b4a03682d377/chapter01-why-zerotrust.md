# 教育機関を標的としたサイバー攻撃の実態

教育機関は、全業種の中でもっともサイバー攻撃を受けやすい組織の一つです。児童生徒の個人情報が大量に保存されている一方で、セキュリティ予算・人材が限られているため、攻撃者にとって「狙いやすい標的」となっています。

## 教育機関への攻撃の深刻化

**統計データ（警察庁・文部科学省調査より）**:

- 📊 **教育機関へのサイバー攻撃件数: 年間500件以上**（2023年度）
- 📊 **個人情報漏洩インシデント: 年間100件以上**
- 📊 **ランサムウェア攻撃による教育活動停止: 年間20件以上**
- 📊 **平均復旧期間: 2-4週間**（授業・校務システムが停止）
- 📊 **1件あたりの平均被害額: 500万円-2,000万円**

**なぜ教育機関が狙われるのか**:

1. **大量の個人情報**
   - 児童生徒の氏名、住所、成績、家庭環境等
   - 保護者の連絡先、職業情報
   - 教職員の個人情報
   - データの闇市場価値が高い

2. **セキュリティ対策の脆弱性**
   - 専任のセキュリティ担当者がいない（兼任が多い）
   - セキュリティ予算が限られている
   - システムの老朽化（レガシーシステムが多い）
   - 教職員のITリテラシーにばらつき

3. **攻撃者にとっての魅力**
   - 支払い能力がある（自治体予算）
   - 教育活動停止の社会的影響が大きい（身代金を払いやすい）
   - 政治的・社会的な注目を集めやすい

## 実際の攻撃事例

### 事例1: A市立図書館 ランサムウェア被害（2022年10月）

**被害の概要**:
- 攻撃手法: VPNファームウェアの脆弱性を悪用したランサムウェア感染
- 被害範囲: 図書館システム全体、バックアップを含むデータが暗号化
- 影響期間: 約2か月（システム完全復旧まで）

**具体的な影響**:
- 🚨 貸出サービスの一時停止
- 🚨 利用者データベースへのアクセス不可
- 🚨 バックアップも暗号化され復旧困難に
- 🚨 復旧・調査費用: 約1億円超

**事後対応**:
- システム全体の再構築
- VPNファームウェアの定期更新体制確立
- セキュリティ監視体制の強化
- 多要素認証の導入

**原因**:
- VPNファームウェアが定期的に更新されず、既知の脆弱性が放置
- バックアップがネットワークに接続されたままで同時に暗号化

### 事例2: B県立高校 個人情報漏洩（2024年）

**被害の概要**:
- 攻撃手法: 不正アクセス防止の措置が不徹底
- 漏洩情報: 生徒・保護者1万4,231名分の個人情報（氏名、住所、成績等）
- 発覚: セキュリティ監査により判明

**具体的な影響**:
- 🚨 個人情報保護委員会への報告義務
- 🚨 規定の期間内に詳細報告できず（体制不備）
- 🚨 全保護者への謝罪と説明
- 🚨 マスコミ報道による社会的信用の失墜
- 🚨 対応費用: 数百万円（調査、通知、対策含む）

**問題点**:
- 不正アクセス防止措置の徹底不足
- アクセス権限管理が不十分
- セキュリティ監視体制の未整備
- 個人情報保護委員会への報告プロセスが未確立

### 事例3: C大学 教職員アカウント侵害（2024年）

**被害の概要**:
- 攻撃手法: フィッシングメールによる教職員Microsoft 365アカウント侵害
- 被害: 侵害されたアカウントから大量のスパムメール・フィッシングメール送信
- 影響範囲: 学内外の複数の連絡先にフィッシングメールが拡散

**具体的な影響**:
- 🚨 侵害されたアカウントから数千通のスパムメール送信
- 🚨 学内の他のアカウントへの二次被害
- 🚨 大学の信頼性低下
- 🚨 メールシステムの一時停止
- 🚨 全学への注意喚起とパスワード変更指示

**問題点**:
- MFA（多要素認証）が全教職員に展開されていなかった
- フィッシング対策訓練が不十分
- アカウント侵害の早期検知機能なし
- メール送信の異常検知機能が未設定

## 教育現場の脆弱性

教育機関がサイバー攻撃の標的となりやすいのは、組織構造的な脆弱性が存在するためです。予算、人材、システムの3つの観点から、その実態を明らかにします。

### 予算の制約

#### IT予算におけるセキュリティ対策費の実態

多くの教育委員会では、IT予算全体の中でセキュリティ対策費が占める割合は5%程度に留まっています。これは同規模の一般企業（15%程度）と比較して著しく低い水準です。具体的な予算配分を見てみましょう。

**一般的な自治体教育委員会のIT予算配分**（教職員200名規模の例）:

| 項目 | 割合 | 年間予算 | 内訳・目的 |
|------|------|---------|-----------|
| ハードウェア更新 | 50% | 1,000万円 | PC更新、ネットワーク機器 |
| ソフトウェアライセンス | 30% | 600万円 | Office、校務支援システム |
| 保守・運用委託 | 15% | 300万円 | システム保守、ヘルプデスク |
| **セキュリティ対策** | **5%** | **100万円** | **ウイルス対策ソフトのみ** |
| **合計** | **100%** | **2,000万円** | |

**セキュリティ予算100万円の内訳**:
- ウイルス対策ソフトライセンス: 60万円
- ファイアウォール保守: 30万円
- セキュリティ診断（3年に1回）: 10万円
- **高度なセキュリティ対策: 0円** ← ここが問題

**企業との比較**（従業員200名規模）:

| 項目 | 教育委員会 | 一般企業 | 差異 |
|------|----------|---------|------|
| IT予算全体 | 2,000万円 | 3,000万円 | 1.5倍 |
| セキュリティ予算 | 100万円（5%） | 450万円（15%） | **4.5倍** |
| セキュリティ専任人員 | 0名 | 1-2名 | - |

→ **教育委員会のセキュリティ予算は、同規模の企業の約1/5**

#### なぜセキュリティ予算が不足するのか

セキュリティ予算が企業の1/5という低水準になってしまう背景には、教育委員会特有の組織文化と予算制度の課題があります。主な要因は以下の4つです。

**予算配分の背景**:

1. **教育活動が最優先**
   - 教材費、施設整備費、人件費が優先
   - セキュリティは「見えないコスト」として後回し

2. **セキュリティの重要性が理解されていない**
   - 「うちは攻撃されるほど大きな組織ではない」という誤解
   - インシデント発生まで危機感が薄い

3. **予算要求の根拠が示せない**
   - セキュリティ専門人材がいない
   - 費用対効果を数値化できない
   - 首長部局・議会への説明が困難

4. **単年度予算の制約**
   - 長期的なセキュリティ投資計画が立てにくい
   - 緊急対応的な予算確保しかできない

#### 予算不足の具体的影響

セキュリティ予算が100万円しか確保できない状況では、高度なセキュリティ対策の導入が事実上不可能です。具体的にどのような対策が実装できず、どのような影響があるのかを見てみましょう。

**実装できないセキュリティ対策**:

| 対策 | 必要予算 | 現状 | 影響 |
|------|---------|------|------|
| Microsoft 365 A5 | 400万円/年 | 未導入 | Identity Protection、Defender製品群が使えない |
| SIEM/SOC | 200万円/年 | 未導入 | 異常検知・監視ができない |
| セキュリティ人材育成 | 50万円/年 | 未実施 | 専門知識が蓄積されない |
| ペネトレーションテスト | 100万円/年 | 3年に1回 | 脆弱性の継続的発見ができない |

### 人材の不足

#### 教育委員会の人員体制の実態

教育委員会では、IT部門全体がわずか1〜2名の兼任職員で構成されているケースがほとんどです。セキュリティ専任の担当者がいる自治体はほぼ皆無という厳しい現実があります。

**典型的な教育委員会の情報担当体制**（市区町村レベル）:

```
教育委員会（職員50-100名）
├─ 教育総務課
│  └─ 情報担当係（1-2名）← ここだけでIT全体を担当
│     ├─ 校務システム運用
│     ├─ ネットワーク管理
│     ├─ ヘルプデスク対応
│     ├─ セキュリティ対策 ← 専門知識不足
│     └─ GIGA端末管理
└─ **セキュリティ専任: 0名**（ほぼ100%の自治体）
```

**情報担当職員の実態**:
- 配属: 異動により突然担当になることが多い
- 経験: IT・セキュリティの専門教育を受けていない
- 兼務: 他の業務と兼任（例: 総務、施設管理等）
- 任期: 2-3年で異動（知識が蓄積されない）
- 負荷: 日常業務に追われ、セキュリティ対策の時間がない

#### 企業との人材体制比較

教育委員会の人材不足がどれほど深刻かを理解するため、同規模の一般企業と比較してみましょう。IT部門の人数は5〜10倍、セキュリティ体制は雲泥の差があります。

**従業員200名規模の組織比較**:

| 項目 | 教育委員会 | 一般企業 | 差異 |
|------|----------|---------|------|
| IT部門人数 | 1-2名 | 5-10名 | 5-10倍 |
| セキュリティ専任 | 0名 | 1-2名 | - |
| IT部門専門性 | 異動による配置 | 専門職採用 | - |
| 外部委託 | 保守のみ | 設計・運用含む | - |
| セキュリティ訓練 | なし | 年2-4回 | - |

#### 人材不足の具体的影響

専任のセキュリティ担当者がいないという人材不足は、日常的なセキュリティ業務の多くが手つかずになるという深刻な問題を引き起こしています。本来実施すべき5つの重要業務が放置されている実態を見てみましょう。

**対応できないセキュリティ業務**:

1. **セキュリティポリシーの策定・更新**
   - 現状: 数年前のポリシーがそのまま
   - 影響: クラウド化などの環境変化に対応できない

2. **脅威情報の収集・分析**
   - 現状: 情報収集する時間がない
   - 影響: 最新の攻撃手法への対策が遅れる

3. **ログの監視・分析**
   - 現状: ログを見る時間がない
   - 影響: 侵害に数か月気づかない

4. **インシデント対応**
   - 現状: 対応手順が未整備
   - 影響: 被害拡大、復旧遅延

5. **セキュリティ教育・訓練**
   - 現状: 年1回の講習会のみ
   - 影響: 教職員の意識向上が進まない

#### 外部委託の限界

人材不足を補うために外部委託を活用している教育委員会も多いですが、現実には予算制約により基本的な保守業務のみの委託に留まっています。セキュリティの中核となる設計・監視業務は委託できていないのが実情です。

**現在の外部委託の実態**:

| 委託内容 | 委託状況 | 課題 |
|---------|---------|------|
| システム保守 | 委託済み | 定型作業のみ、セキュリティ設計は対象外 |
| ヘルプデスク | 委託済み | パスワードリセット等の基本対応のみ |
| **セキュリティ設計** | **未委託** | **予算不足で委託できない** |
| **SOC/監視** | **未委託** | **予算不足で委託できない** |
| インシデント対応 | スポット委託 | 発生時のみ、平時の準備なし |

### システムの老朽化

#### 老朽化したシステムの実態

全国の教育委員会では、導入から10年以上経過したシステムが約40%を占め、約20%の自治体ではサポートが終了したOSを使い続けているという深刻な状況です。文部科学省・総務省の調査データから実態を見てみましょう。

**全国の教育委員会システム老朽化状況**（文部科学省・総務省調査より）:

| システム | 導入から10年以上 | サポート切れOS | 課題 |
|---------|----------------|--------------|------|
| オンプレミス校務支援システム | 約40% | 約20% | Windows Server 2012等 |
| 教育ネットワーク機器 | 約35% | 約15% | ファームウェア未更新 |
| 学校PC | 約30% | 約10% | Windows 7/8.1 |

**セキュリティパッチ適用状況**:

| パッチ種別 | 適用率 | 未適用の理由 |
|-----------|--------|------------|
| 緊急パッチ | 約70% | 業務影響を懸念して適用を見送り |
| 重要パッチ | 約50% | テスト環境がなく影響が予測できない |
| オプションパッチ | 約30% | 適用する人員・時間がない |

→ **約30%の自治体で重要なセキュリティパッチが未適用**

#### 老朽化システムによるリスク

システムの老朽化は単なる使い勝手の問題ではなく、セキュリティパッチが適用できない、最新の防御機能が使えないといった、攻撃者に付け入る隙を与える深刻なリスクを生み出します。4つの典型的なリスクとその影響を見てみましょう。

**具体的なリスク例**:

1. **サポート切れOSの継続利用**
   - リスク: セキュリティパッチが提供されない
   - 事例: Windows Server 2012を使用中の20%の自治体
   - 影響: 既知の脆弱性を悪用した攻撃に無防備

2. **ファームウェア未更新のVPN機器**
   - リスク: 既知の脆弱性を悪用したランサムウェア攻撃
   - 事例: 那覇市立図書館の事例（前述）
   - 影響: システム全体の暗号化

3. **レガシーシステムの継続利用**
   - リスク: 最新のセキュリティ機能に対応できない
   - 例: TLS 1.0/1.1のみ対応、MFA未対応等
   - 影響: クラウドサービスと連携できない

4. **バックアップシステムの老朽化**
   - リスク: ランサムウェア攻撃時にバックアップも暗号化
   - 例: ネットワーク接続されたバックアップ
   - 影響: 復旧不能、多額の復旧費用

#### システム更新が進まない理由

老朽化したシステムが放置され続けるのには構造的な理由があります。予算、リスク、人材、組織調整という4つの高い壁が、システム更新を阻んでいます。

**更新の障壁**:

1. **予算の制約**
   - システム更新には数千万円～数億円必要
   - 単年度予算では確保困難
   - 優先順位が低い（教育活動優先）

2. **移行リスクへの懸念**
   - 既存業務への影響が大きい
   - 教職員の研修コスト
   - 移行期間中の業務停止リスク

3. **専門人材の不足**
   - 移行計画を立案できる人材がいない
   - RFP（提案依頼書）を作成できない
   - ベンダー提案の適切性を判断できない

4. **首長部局との調整**
   - 自治体全体のIT投資計画との整合性
   - 議会承認のハードル
   - 他部局との予算の奪い合い

### 3つの脆弱性が重なる危険性

**予算不足 × 人材不足 × システム老朽化 = 攻撃者にとって最適な標的**

```
予算不足
  ↓ セキュリティ対策製品を導入できない
人材不足
  ↓ 脅威を検知・対応できない
システム老朽化
  ↓ 既知の脆弱性が放置される
  ↓
【攻撃成功率が極めて高い】
```

**この悪循環を断ち切るために必要なのが、ゼロトラストアーキテクチャです。**

次のセクションでは、クラウド移行によって生じる新たなリスクと、従来型のセキュリティモデルの限界について解説します。

# クラウド型校務支援システムとセキュリティリスク

## クラウド移行のトレンド

文部科学省「GIGAスクール構想」やデジタル庁「自治体DX推進計画」により、教育委員会のクラウド移行が加速しています。

**クラウド型校務支援システム導入状況**:
- 2020年: 約15%の自治体が導入
- 2023年: 約45%の自治体が導入済み・導入中
- 2025年目標: 約70%の自治体で導入予定

## 境界防御モデルの限界

クラウド移行により、学校内ネットワークという「境界」で守る従来型のセキュリティモデルが通用しなくなっています。自宅や出張先など、あらゆる場所からクラウドサービスにアクセスする現在、境界の内側を「安全」とみなす考え方そのものが崩壊しています。

### 従来型（オンプレミス）のセキュリティモデル

```
[学校内ネットワーク]
├─ ファイアウォール（境界）
└─ 内部は「信頼された」ネットワーク
   → 内部からのアクセスは基本的に許可
```

**問題点**:
- ✕ 自宅からのアクセスができない（働き方改革に対応できない）
- ✕ VPN経由でも内部ネットワーク全体にアクセス可能（過剰な権限）
- ✕ 一度侵入されると内部で自由に動き回れる（ラテラルムーブメント）

### クラウド型での新たなリスク

クラウド型校務支援システムでは、職員室だけでなく教職員の自宅や出張先など、あらゆる場所からのアクセスが可能になります。この利便性の裏側で、アクセス元の多様化とデバイス管理の困難さという新たなセキュリティリスクが生まれています。

**アクセス元の多様化**:
- 学校の職員室
- 教職員の自宅
- 出張先のホテル
- カフェ等の公共Wi-Fi
- 私用デバイス（BYOD）

**課題**:
- 🚨 どこからでもアクセスできる = どこからでも攻撃される
- 🚨 ID・パスワードだけでは不十分（パスワードスプレー攻撃に脆弱）
- 🚨 デバイスのセキュリティ状態が不明（マルウェア感染端末からのアクセス）

## 児童生徒の個人情報がクラウドに保存されるリスク

クラウド型校務支援システムには、成績や家庭環境、健康情報など、教育委員会が保護すべき最も機密性の高い児童生徒の個人情報が保存されています。オンプレミスとは異なり、データの所在やアクセス権限の管理が複雑になり、新たな情報漏洩リスクが発生しています。

**クラウド上の機密データ**:
- 児童生徒の氏名、住所、生年月日
- 成績情報、出欠記録
- 健康診断結果、アレルギー情報
- 家庭環境、保護者情報
- いじめ・不登校対応記録

**クラウド特有のリスク**:
- データの所在が不明確（どこに保存されているか）
- 複数の教職員がアクセス可能（権限管理が不十分）
- 退職後もアカウントが残っている（権限の剥奪漏れ）
- 外部共有の誤操作（保護者に誤送信等）

# 教育機関におけるゼロトラストの価値

## ゼロトラストがもたらす5つの価値

これまで見てきた教育機関の脆弱性とクラウド移行に伴うリスクに対して、ゼロトラストアーキテクチャは具体的にどのような価値をもたらすのでしょうか。教育委員会の視点から、5つの重要な価値を解説します。

### 1. 児童生徒の個人情報保護の強化

教育委員会の最優先責務である児童生徒の個人情報保護において、ゼロトラストは従来の境界防御では実現できなかった高度な保護を提供します。すべてのアクセスを検証し、異常を即座に検知することで、情報漏洩リスクを大幅に削減できます。

**実現できること**:
- すべてのアクセスを検証（内部・外部を問わず）
- アクセス元のデバイス・場所・リスクレベルを評価
- 機密データへのアクセスを必要最小限に制限
- 異常なアクセスを自動検知・ブロック

**効果**:
- 個人情報漏洩リスク: 70%削減
- アカウント侵害の検知時間: 197日 → 5分以内
- データへの不正アクセス: 95%削減

### 2. 個人情報保護法・ガイドライン遵守

教育委員会は、個人情報保護法や文部科学省・総務省のガイドラインへの対応が法的に求められています。ゼロトラストアーキテクチャを導入することで、これらの要求事項を技術的に確実に満たすことができます。

**対応できる法令・ガイドライン**:
- 個人情報保護法（2022年改正）
- 教育情報セキュリティポリシーに関するガイドライン（文部科学省）
- 地方公共団体における情報セキュリティポリシーに関するガイドライン（総務省）

**具体的な対応項目**:
- ✅ アクセスログの記録・保存（6か月以上）
- ✅ 不正アクセスの検知と対応
- ✅ 個人情報へのアクセス制御
- ✅ 退職者・異動者の権限剥奪
- ✅ 監査証跡の提供

### 3. セキュリティインシデント防止によるコスト削減

セキュリティインシデントが発生すると、復旧費用だけでなく調査費用、対応費用、さらには信用失墜による無形損失まで、膨大なコストが発生します。ゼロトラストによるインシデント防止は、最も費用対効果の高い投資といえます。

**インシデント発生時のコスト**（平均値）:

| 項目 | 金額 |
|------|------|
| システム復旧費用 | 500万円-1,000万円 |
| 外部調査委託費用 | 200万円-500万円 |
| 個人情報漏洩対応（通知・謝罪） | 100万円-300万円 |
| 法的対応費用 | 50万円-200万円 |
| 信用失墜による無形損失 | 計測不能 |
| **合計** | **850万円-2,000万円** |

**ゼロトラスト導入による削減効果**:
- インシデント発生確率: 70%削減
- 期待値での年間コスト削減: 約600万円-1,400万円

### 4. 教職員の働き方改革（安全なテレワーク環境）

教職員の長時間労働が社会問題となる中、テレワークによる働き方改革が求められています。しかし、セキュリティを犠牲にしてはなりません。ゼロトラストは、安全性と柔軟な働き方の両立を可能にします。

**実現できる働き方**:
- 自宅からの安全な校務システムアクセス
- 出張先からの緊急対応
- 育児・介護との両立（フレキシブルな勤務）
- 感染症流行時の業務継続

**効果**:
- 時間外勤務: 月平均10時間削減
- 通勤時間削減: 週2日在宅勤務で年間約100時間削減
- 教職員満足度向上

### 5. 保護者・地域からの信頼確保

子どもの個人情報を預ける保護者にとって、教育委員会のセキュリティ対策は重大な関心事です。ゼロトラストの導入は、最先端のセキュリティ対策を実施している証明となり、保護者や地域からの信頼獲得につながります。

**保護者が求めるセキュリティ対策**（PTA調査より）:
- 「子どもの個人情報を適切に保護してほしい」: 95%
- 「セキュリティ対策の状況を説明してほしい」: 78%
- 「万が一の際の対応計画を知りたい」: 82%

**ゼロトラスト導入による信頼獲得**:
- 最先端のセキュリティ対策を実施している証明
- 保護者説明会での説得力ある説明が可能
- 自治体広報でのアピール材料
