# ゼロトラスト製品を購入しただけでは、ゼロトラストは実現できない

「Microsoft 365 A5を導入すればゼロトラストが実現できる」— そう考えて高額なライセンスを購入したものの、実際には何をどう設定すればよいのかわからず、結局はデフォルト設定のまま運用している教育委員会は少なくありません。

**本書を執筆した背景**:

クラウド型校務支援システムの導入が全国の教育委員会で進む中、セキュリティ対策としてMicrosoft 365 A5のライセンス購入を決定する自治体が増えています。しかし、A5には30以上のセキュリティ製品が含まれており、それぞれが高度な機能を持つ反面、**「どの機能を」「どの順番で」「どう設定すれば」教育現場でゼロトラストが実現できるのか**という実践的な設計ガイドは、ほとんど存在しませんでした。

その結果
- 🚨 **A5を購入したが、Identity Protectionなどの主要機能が未設定のまま**
- 🚨 **条件付きアクセスポリシーが未構成で、従来型の境界防御に依存**
- 🚨 **パスワードスプレー攻撃によるアカウント侵害が発生しても検知できない**
- 🚨 **高額なライセンス費用に見合う価値を発揮できていない**

このような状況が生まれています。

# この書籍が解決する課題

本書は、**Microsoft 365 A5のライセンスを購入済み、またはこれから購入を検討している教育委員会**が、実際にゼロトラストセキュリティを実現するための実践的な設計・構成・運用ガイドです。

**本書で得られること**:

1. **A5の30以上の製品を、教育現場で使える形に体系化**
   - ID管理、デバイス保護、情報保護、脅威対策の4領域に整理
   - 各製品の役割と導入優先順位を明確化
   - A3との機能差分とA5が必要な理由を理解

2. **教育機関特有の脅威への対策**
   - パスワードスプレー攻撃（教育機関への攻撃の70%）への防御方法
   - 児童生徒の個人情報保護に必要な具体的設定
   - 教職員の限られたITリテラシーでも運用可能な設計

3. **段階的な実装ロードマップ**
   - 最小限の設定で始める「クイックスタート」（1-3か月）
   - 優先度に応じた機能追加（3-12か月）
   - 限られた予算・人材での実装アプローチ

4. **実際に使える設定手順と運用方法**
   - Entra ID、Conditional Access、Intuneの具体的設定手順
   - セキュリティアラートの運用フロー
   - インシデント対応の実践的プロセス

# 対象読者

**主対象読者**:
- クラウド型校務支援システムの導入を推進する教育委員会の情報担当者・セキュリティ担当者
- A5を購入したが、十分に活用できていない自治体の担当者
- ゼロトラストの設計・構成を任されたが、何から始めればよいかわからない方

**副対象読者**:
- 導入の意思決定を行う教育長、教育委員
- セキュリティ投資の判断が必要な学校長、自治体首長部局のICT/セキュリティ責任者
- A3とA5の違いを理解し、適切な投資判断をしたい方

# 本書の特徴

**1. 教育現場に特化した実践的内容**
- 一般企業向けの解説ではなく、学校・教育委員会の実情に合わせた設計
- 教育機関で実際に発生したインシデント事例を基にした対策
- 児童生徒の個人情報保護、文部科学省ガイドライン対応

**2. ゼロから実装できる詳細手順**
- 「何を」「どの順番で」「どう設定するか」を具体的に解説
- スクリーンショット付きの設定手順（重要箇所）
- PowerShell/Graph APIを使った自動化手順も提供

**3. 限られたリソースでの実装を前提**
- 専任のセキュリティ担当者がいない前提での運用設計
- 外部委託とのバランスを考慮した体制設計
- 段階的な予算計画と費用対効果の試算

**4. A5製品群の全体像と関連性を理解**
- 30以上の製品がどう連携してゼロトラストを実現するかを図解
- どの製品がA5専用で、A3では実現できないかを明確化
- 製品選択の判断基準を提供

# 本書の構成

本書は6部、20章で構成されています。

**第1部: ゼロトラストの必要性（意思決定者向け）**
- なぜ教育機関にゼロトラストが必要なのか
- ゼロトラストの原則と実装アプローチ
- A5製品群の全体像とA3/SASEとの比較

**第2部: ID・アクセス制御**
- Entra IDによる教職員ID基盤の構築（パスワードレス認証含む）
- Conditional Accessによる校務システムへの安全なアクセス
- PIMによる管理者権限の適切な管理

**第3部: デバイス管理**
- Intuneによる校務用端末の統合管理
- Defender for Endpointによる脅威対策

**第4部: 児童生徒の個人情報保護**
- Information Protectionによるデータ保護
- DLPによる情報漏洩防止
- Insider Risk Managementによる内部不正検知
- 生成AI・Copilotのセキュリティガバナンス

**第5部: 脅威対策と継続的監視**
- Defender for Office 365によるメール保護
- Defender for Cloud Appsによるクラウドアプリ監視
- Defenderポータルでの統合セキュリティ運用

**第6部: ガバナンスと継続的改善**
- セキュリティガバナンスと組織体制
- 監視・ログ管理とインシデント対応
- 段階的導入ロードマップと予算計画
- 将来の展望と継続的改善

# 本書の使い方

**パターン1: これからA5を導入する教育委員会**
→ 第1部で全体像を理解 → 第4章でライセンス選択を判断 → 第19章でロードマップ作成 → 第2-5部で順次実装

**パターン2: A5を購入済みだが活用できていない教育委員会**
→ 第5章のアカウント侵害対策から着手（最優先） → 第6章で条件付きアクセス設定 → 第8-9章でデバイス管理

**パターン3: 意思決定者（教育長・首長部局）**
→ 第1部（第1-4章）で必要性と投資対効果を理解 → 第19章で予算・ロードマップを検討

**パターン4: すでにゼロトラストを運用中の教育委員会**
→ 第4部（情報保護）、第13章（AI/Copilot）で高度な機能を追加実装

---

それでは、教育機関でのゼロトラスト実現に向けた実践的なガイドを始めましょう。
